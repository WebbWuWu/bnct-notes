## 1. `lcg` 类和 `random()`（`rng.py` 第 19–31 行，10/30 写）

### 1.1 解决什么问题

蒙卡的每一个随机决定（飞多远、撞谁、往哪散射）都要一个 [0, 1) 上均匀分布的数 ξ。电脑没有真随机，只能用一个**确定的递推**造出「看起来随机」的序列：

  x_{n+1} = (a · x_n + c) mod m

这叫线性同余发生器（LCG）。x 叫**状态**，每调一次往前走一步。

为什么换成 m = 2⁶³（10/28 的事）：原来 m = 2³²，整个序列只有 4.3 × 10⁹ 个数。一个种子跑 2 万条历史要用约 2 × 10⁷ 个数，30 个种子里就有几对落进同一段序列，结果几乎一样。这就是「深处偏低 1%」的真正原因（10/31 结案）。2⁶³ ≈ 9.2 × 10¹⁸，大了 20 亿倍。

### 1.2 逐行

| 行 | 代码在做什么 | 意思 |
|---|---|---|
| 19–22 | `a`、`c`、`m`、`S` 四个常数 | 抄自 OpenMC 0.15.3 `random_lcg.h`。`S = 152917` 是每条历史分到的随机数个数（见第 2 节） |
| 25–26 | `__init__`：`self.state = seed` | 种子直接当 x₀ |
| 27–29 | `uint()`：走一步，返回新状态 | x → (a·x + c) mod m，一个 0 到 2⁶³ − 1 的整数 |
| 30–31 | `random()`：`(uint() >> 10) / 2**53` | 状态有 63 位，右移 10 位扔掉低 10 位，剩**高 53 位**，再除以 2⁵³ → [0, 1) |

**为什么取高位、为什么是 53 位**：
- LCG 的**低位**很不随机：模 2 的幂时，最低一位只是 0、1、0、1 交替。高位的周期长，质量好，所以扔低位、留高位。
- Python 的浮点数（double）有效数字正好 53 位。留 53 位，除以 2⁵³ 后每个数都能精确表示，最小间隔 2⁻⁵³ ≈ 1.1 × 10⁻¹⁶。
- 结果最大是 (2⁵³ − 1)/2⁵³ < 1，**取不到 1**，但**取得到 0**。所以飞行距离写成 s = −ln(1 − ξ)/Σ_t（`lesson07_freegas.py` 第 526 行）：1 − ξ ∈ (0, 1]，永远不会 ln(0)。

### 1.3 你 10/30 混过的
`*` vs `**`（`2*10` = 20）· `>>` 比 `/` 后算（要先砍位就加括号）· `/` 不扔位（`/2**10` ≠ `>>10`）· `>>` 不是减法（5000 >> 10 = 4，不是 3976）。

## 2. `jump(x0, n)`（`rng.py` 第 33–46 行，10/31 写）

### 2.1 解决什么问题

我们要第 i 条历史**从序列的第 i × S 个数开始**（`lesson07_freegas.py` 第 771 行：`rng.state = jump(seed, i*S)`）。好处：
1. 只要一条历史用的随机数不超过 S = 152917 个（平均才约 1000 个），**任意两条历史用的随机数互不重叠**。
2. 第 i 条历史的结果只取决于 i，和前面的历史跑没跑、跑了多少无关 → 将来 GPU 上「一个线程一条历史」，每个线程自己算自己的起点就行。

难点：i 到 10 万时，要走 1.5 × 10¹⁰ 步。一步一步走要几个小时。`jump` 用大约 **34 次**循环就算出来。

### 2.2 原理（讲义 `原理讲义_随机数_乙方案.md` 第 4 节的浓缩）

**一步是一个「线性映射」**：f(x) = a·x + c（mod m）。用一对数 (A, B) 表示「x → A·x + B」，一步就是 (a, c)。

**走两次 = 把两个映射拼起来**：先 (A₁, B₁) 再 (A₂, B₂)：
  x → A₂(A₁x + B₁) + B₂ = (A₂A₁)·x + (A₂B₁ + B₂)
所以拼起来是 **(A₂A₁, A₂B₁ + B₂)**。

**自己拼自己 = 步数翻倍**：(A, B) 拼 (A, B) = (A², AB + B) = **(A², (A + 1)·B)**。从 1 步出发，翻倍 → 2 步 → 4 步 → 8 步 …

**任意 n 步**：把 n 写成二进制，比如 n = 6 = 110₂ = 4 + 2。只要把「2 步」和「4 步」两个映射拼起来。n 有多少个二进制位，就循环多少次：1.5 × 10¹⁰ < 2³⁴，所以最多 34 次。

（同一个 f 的不同次幂，拼的先后顺序不影响结果，「可交换」—— 10/30 讲义订正过。）

### 2.3 逐行

| 行 | 变量 / 操作 | 意思 |
|---|---|---|
| 34–35 | `A_ans = 1`、`B_ans = 0` | 「答案」映射，开始是「走 0 步」= x → 1·x + 0 |
| 36–37 | `A_cur = a`、`B_cur = c` | 「当前这一档」映射，开始是「走 1 步」 |
| 38 | `while n > 0` | 每圈处理 n 的一个二进制位 |
| 39 | `if n & 1` | n 的最低位是 1 吗？是 → 这一档要算进答案 |
| 40–41 | `A_ans = A_cur·A_ans`、`B_ans = A_cur·B_ans + B_cur` | 把「当前档」拼到答案上（2.2 的拼接公式） |
| 42–43 | `B_cur = (A_cur + 1)·B_cur`、`A_cur = A_cur²` | 当前档自己拼自己 → 步数翻倍。**注意先算 B 再算 A**：B 的公式要用**旧的** A |
| 44 | `n = n >> 1` | 扔掉最低位，下一圈看下一位（10/31 错过：只写 `n >> 1` 没赋值，死循环） |
| 45 | `x0 = (A_ans·x0 + B_ans) mod m` | 用拼好的映射一次走到第 n 个 |

### 2.4 算例（小发生器，手能算：a = 5，c = 3，m = 16，x₀ = 7，n = 6）

**笨办法，一步一步走**：7 → 6 → 1 → 8 → 11 → 10 → **5**（例：(5×7 + 3) mod 16 = 38 mod 16 = 6）。

**`jump` 的三圈**（n = 6 = 110₂）：

| 圈 | n | 最低位 | 拼进答案后 (A_ans, B_ans) | 翻倍后 (A_cur, B_cur) = 几步的映射 |
|---|---|---|---|---|
| 开始 | 6 | — | (1, 0) | (5, 3) = 1 步 |
| 1 | 6 | 0，不拼 | (1, 0) | (25 mod 16, 6×3 mod 16) = **(9, 2)** = 2 步 |
| 2 | 3 | 1，拼 | (9·1, 9·0 + 2) = **(9, 2)** | (81 mod 16, 10×2 mod 16) = **(1, 4)** = 4 步 |
| 3 | 1 | 1，拼 | (1·9, 1·2 + 4) = **(9, 6)** | （不再用） |

最后 x = (9 × 7 + 6) mod 16 = 69 mod 16 = **5** ✅，和笨办法一样。
核对「2 步映射」：f(f(x)) = 5(5x + 3) + 3 = 25x + 18 → mod 16 是 (9, 2) ✅。

## 3. `show_angle(nuc)`（`explore\lesson12_elastic_angle.py` 第 27–59 行，11/1 写）

### 3.1 解决什么物理问题

中子和原子核**弹性散射**时，在**质心系**里往哪个方向飞出去，由角分布 p(μ_cm | E) 决定（μ_cm = 质心系散射角的余弦）。你的程序现在一律当成「各向同性」：μ_cm 在 [−1, 1] 上均匀，也就是 p = 1/2（近似 #4）。

**这个方向为什么影响剂量**：一次弹性碰撞后，中子能量剩下的比例是

  E′/E = (A² + 2A·μ_cm + 1) / (A + 1)²

对 μ_cm 求平均，每次碰撞**平均损失的能量份额**是

  ⟨ΔE/E⟩ = 2A·(1 − μ̄_cm) / (A + 1)²

（μ̄_cm 是平均余弦。推导：把 E′/E 里的 μ_cm 换成 μ̄_cm，再用 1 去减。）

算一下 O16（A ≈ 16），0.5 MeV：
- 各向同性（μ̄_cm = 0）：2 × 16 / 17² = **0.111**，每撞一次丢 11% 的能量
- 库里的真实值（μ̄_cm = 0.417，今天读出来的）：0.111 × (1 − 0.417) = **0.065**，每撞一次只丢 6.5%

真实情况下，中子每次撞 O 丢的能量少了约 40%，而且方向还偏向前。所以快中子能跑得更深、在深处保持更高的能量。你的程序当各向同性，就会**低估深处的快中子** → 深处快中子 kerma 偏低 5–9%（方案乙）。

### 3.2 库里怎么存（今天读出来的）

路径：`H1.h5` → `H1/reactions/reaction_002/product_0/distribution_0/angle`，下面两个数据集：

| 数据集 | 形状（H1） | 物理意义 |
|---|---|---|
| `energy` | (153,) | 153 个入射能量 Eᵢ（1e-5 eV – 20 MeV），每个配一张 μ_cm 表 |
| `mu` | (3, 507) | 三行：μ 值、pdf p(μ)、cdf。153 张表首尾接成 507 列 |
| `mu` 的属性 `offsets` | 153 个 | 第 i 张表从第几列开始 |
| `mu` 的属性 `interpolation` | 全是 2 | 线性-线性：相邻两点之间 pdf 是一条斜直线 |

`reaction_002` 的属性 `center_of_mass = 1` 说明 μ 是质心系的。**存法和 10/31 的 `energy_out` 完全一样**：一长条 + offsets 切开。

| 52–55 | 找离 E_tgt 最近的表 j，切出 `mu_v`、`mu_p`、`mu_c` | `b:e` 正好 n 个点（终点不含） |
| 57 | `norm` = 对 pdf 做梯形积分 | pdf 每段是直线，梯形法对直线是**精确**的 → 应该 = 1 |
| 58 | `mubar` = 辛普森公式 | 见下 |

**μ̄ 为什么不能用梯形法**：μ̄ = ∫ μ·p(μ) dμ。p 每段是直线，μ·p 就是**二次**曲线，梯形法（把曲线当直线）会算偏。辛普森公式 (b − a)/6 · [f(a) + 4f(中点) + f(b)] 对二次函数是精确的。中点处 p = (pₐ + p_b)/2，代进去整理：

  每一段的积分 = (b − a)/6 · [ (2a + b)·pₐ + (a + 2b)·p_b ]

`mu_v[:-1]` 是每段左端 a，`mu_v[1:]` 是每段右端 b，两个数组对齐后整体算，再 `np.sum`。

### 3.4 算例：H1 在 2 MeV（第 101 张，3 个点）

μ = −1、0、+1；p = 0.5016666、0.5001162、0.498101。
- 第一段 [−1, 0]：1/6 × [(−2 + 0)(0.5016666) + (−1 + 0)(0.5001162)] = 1/6 × (−1.5034494) = −0.2505749
- 第二段 [0, 1]：1/6 × [(0 + 1)(0.5001162) + (0 + 2)(0.498101)] = 1/6 × 1.4963182 = +0.2493864
- 加起来 μ̄ = **−0.0011885** ✅（程序输出 −0.001188533）

3 点的情况可以化简成 μ̄ = (p₂ − p₀)/3 = (0.498101 − 0.5016666)/3，同一个数。

### 3.5 读出来的结论

| μ̄_cm | 0.0253 eV | 10 keV | 0.5 MeV | 2 MeV |
|---|---|---|---|---|
| H1 | 0 | −1.1e-5 | −3.6e-4 | −1.2e-3 |
| O16 | 0 | −2.7e-3 | **+0.417** | **+0.121** |

**为什么 H1 到 2 MeV 还各向同性**：质心系里中子的约化德布罗意波长 ƛ = ħ/p = 6.4 fm，比核力力程（约 2 fm）大 3 倍。角动量 l 的中子碰撞参数 b ≈ l·ƛ：l = 0 正对着撞进去，能被核力散射；l = 1 在 6.4 fm 外擦过，几乎碰不到核力。只有 s 波（l = 0）被散射，而 s 波是球对称的，所以各向同性。要 l = 1 也进来，得 ƛ ≈ 2 fm，即 E_lab ≈ 20 MeV。
O16 核半径约 3 fm，0.5 MeV 附近又有共振，l ≥ 1 的分波参与进来，所以前倾。

## 4. `load_thermal(sab_path, T_tag)`（`thermal.py` 第 22–53 行，11/1 写）

### 4.1 解决什么物理问题

热中子（< 约 1 eV）撞**水里的 H** 时，H 不是自由的：它被化学键拴在水分子上，分子还会转动、振动。中子能和这些运动交换能量。你的程序现在用「自由气体」模型（H 当成自由飞的气体原子），在水里不准：软组织里 D_B 峰值低估约 23%（M1 判据 5）。

S(α,β) 就是把这些分子运动全算进去的散射规律。NJOY 已经把它积分、离散好，存成「给定入射能量 E，出射能量 E′ 和角度 μ 的概率表」。`load_thermal` **只做一件事：把这些表从文件里读出来，切成 118 份小表放进内存**，让后面的 `sample_thermal` 每次碰撞时直接查。

### 4.2 每个键的物理意义

| 键 | 内容 | 物理意义 | `sample_thermal` 怎么用 |
|---|---|---|---|
| `"E_max"` | 10.0 | 10 eV 以上分子键的影响可以忽略，回到自由原子处理 | E < 10 eV 才走热散射 |
| `"xs_E"`、`"xs_sig"` | 118 个能量、118 个截面 | 水中 H 的**非弹热散射截面** σ(E)。0.0253 eV 是 51.69 b（自由 H 约 20 b、自由气体在这里约 30 b） | `lookup_xs` 里替换 H1 的弹性截面 |
| `"E_in"` | 118 个入射能量 | 每张出射表对应的入射能量 E_l。🆕 今天发现和 `xs_E` **逐个相等** | 选表：E 落在哪两个之间 |
| `"tables"[l]["E_out"]` | 第 l 张表的出射能量格点 E′ⱼ | 中子撞完以后可能的能量 | 抽 E′ |
| `"tables"[l]["pdf"]`、`["cdf"]` | 每个 E′ⱼ 处的概率密度和累积概率 | p(E′ \| E_l)；cdf 从约 0 升到 1 | 用 ξ₁ 在 cdf 里找区间、反解 E′ |

### 5.1 A1–A4（角分布，`lesson12_elastic_angle.py` 第 39–51 行）
