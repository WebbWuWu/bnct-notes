### 🔴 当天第三值钱：判据的两边不但要独立，还必须先确认在**比同一个量**

步骤 0 的对拍，Claude 给的规格是 `assert k_lin == k_bis`。**实测 59600 次里 23396 次不一致（39.3%），而两个实现都是对的。**

**真因**：二分版按**原始顺序**切 `[0,1)`，排序线性扫描版按**排序后顺序**切。

```
sigma=[3,0,7], total=10
   二分（原序）  : 道0 拿 [0,0.3)      道2 拿 [0.3,1.0)
   本版（排序）  : 道2 拿 [0,0.7)      道0 拿 [0.7,1.0)

   xi=0.20 -> 线性给 2，二分给 0      不一致
   xi=0.50 -> 线性给 2，二分给 2      一致
   xi=0.99 -> 线性给 0，二分给 2      不一致
```

**两版分布上等价**（各抽 20 万次都给 `[0.300, 0.000, 0.700]`），**逐点不等价**。
修法：给二分版喂排序后的 `sigma`，再把排名映射回原始下标 → **59600 次不一致 0 次。**

> 🔴 **9/7「一条 assert 要有两个独立算出来的量」缺的那一半，今天补上：**
> **两边不但要独立，还必须先确认它们在比同一个量。**
>
> **而同一个根因当天出现了两次** —— 下午做逐位对拍时它又来了一遍。

#### 🔴 但它实际拿到的是第二层的保护

写完之后实测发现：`searchsorted(side="right")` **会跳到所有相等元素的后面**，所以它返回的 `lo` 永远满足 `E[lo+1] > e >= E[lo]` —— **零宽格自动被跳过。**

```
E=[1,2,2,3] e=2.0  ->  lo=2, E[lo]=2.0 E[lo+1]=3.0   没响
E=[1,2,2,3] e=2.5  ->  没响
E=[1,2,2,3] e=1.5  ->  没响
E=[1,2,3,3] e=3.0  ->  响了 ✅       ← 只有这一种
E=[1,2,3,3] e=2.5  ->  没响
```

### 🔴 当天第一值钱：教科书结论在这里是错的 —— warp divergence

(6) 问「二分 vs 线性扫描，哪个在 GPU 上更糟」。用户答**线性更糟** —— **这是标准答案，而标准答案在这里给出了错误的结论。**

**关键**：一个 warp 32 个线程锁步走，**耗时 = 32 个线程里的最大值，不是平均值**：

```
排序后线性扫描 : 1.90 轮      ← 单线程平均 1.06
二分           : 6.00 轮      ← 每线程固定 log2(48)
```

**线性扫描快 3 倍。发散是真的（1.06 → 1.90，被拖慢 80%），但它发散完了还是更快。**

**第二笔账方向相同**：线性扫描 32 个线程**第一步全读 `sigma[0]`** → 广播；二分各读各的 → **不合并访存**。

> 🔴 **纪律：「会不会发散」和「发散的代价有多大」是两个问题。只答第一个，会把一个快 3 倍的方案毙掉。**

#### 🔴 NaN：范围判据免费附赠一个 NaN 判据

```python
assert 0 <= xi < 1, "xi 越界或是 nan: %r" % xi
```

**一条判据同时管三件事**：不小于 0、不大于等于 1、不是 nan。

> 🔴 **凡是「范围判据」，都免费附赠一个 NaN 判据，因为 nan 过不了任何一个比较。**
> （⚠️ **9/18 划出这条的边界**：能合并的前提是**错了之后要查的地方是同一个**。「能量越界」和「零宽格」查的不是同一处，必须分成两条。）

**NaN 表：**

| 写法 | `xi = nan` |
|---|---|
| 两个独立 `if` | 两个都不成立 → **死循环，卡住** |
| `if / else` | 走 else → **静默返回垃圾下标** |

> 🔴 **而这件事在第 13 课会变成今天刚记下的那个坑**：
> **一个 nan 引起的死循环，在 GPU 上不是「程序卡住」，是 Windows TDR 约 2 秒超时把 kernel 杀掉，表现成「显卡驱动崩溃」。**
> **你会以为是 CUDA 环境的问题去重装驱动。真因是某个截面插值吐了个 nan。**

### 第 4 课自测题 1–3 —— 欠 11 天，当天结案

**1. 误差为什么 ∝ 1/√N？** `Var(x̄)=Var(x)/N` → **开根** → `SE=σ/√N` → SE 减半要 N×4。条件：**样本独立**。
**后果（12 月最值钱的一句）：精度每提高一位小数要多算 100 倍。这不是实现不够好，是 MC 的数学天花板 —— GPU 的全部理由就在这一行。**

**2. 为什么除 N−1？** `x̄` 是从这批数据自己算出来的 ⟹ 平方和系统性偏小 ⟹ `E[Σ(xᵢ−x̄)²]=(N−1)σ²`。
**最直白的检验：N=1 时 `1/(N−1)` 给 0/0（诚实地拒绝回答），`1/N` 会自信地给 0。**

**3. 卡方分母为什么是 `E_j`？自由度为什么 M−1？** 两问都答对。⚠️ **一个口误**：「所有的数加起来就是 **M**」应为 **N**。
补上的半步：**泊松分布方差 = 均值 ⟹ σ_j = √E_j**。
**M−1 和第 2 题是同一件事** —— **同一概念一节课出现两次不是巧合，面试可主动把两处连起来说。**

### ③ 路径修复：cwd 只修了一半，另一半用 `__file__`
