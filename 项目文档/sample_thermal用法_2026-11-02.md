## 二、用到的写法（逐个，例子和项目无关）

### 1. 列表套字典取数
`thermal["tables"]` 是**列表**（118 份），每一份是**字典**。取数：先用位置拿到那一份，再用键。
```python
shelf = [{"title": "三体", "pages": 302}, {"title": "活着", "pages": 191}]
shelf[1]["pages"]      # 191
book = shelf[1]        # 先取出来存一个短名字，后面 book["pages"]、book["title"] 都短
```
你犯过：少一层下标（11/1 `thermal["tables"]["mu"]`）。建议先把选中的那张存进 `tab`，后面全用 `tab[...]`。

### 2. `np.searchsorted(有序数组, x, side="right")`
返回「x 插进去以后数组还有序」的位置。`side="right"`：和 x **相等**的格点算在左边。**结果减 1** 就是满足 `a[k] ≤ x < a[k+1]` 的 k。
```python
heights = np.array([2.5, 3.7, 4.1, 6.8])
np.searchsorted(heights, 3.9, side="right") - 1    # 1   → 3.7 ≤ 3.9 < 4.1 ✅
np.searchsorted(heights, 3.7, side="right") - 1    # 1   → 正好等于格点，算进第 1 段 ✅
np.searchsorted(heights, 3.7, side="left")  - 1    # 0   ✗ 等于时跑到了前一段
np.searchsorted(heights, 2.1, side="right") - 1    # -1  ← 比第一个还小：没有这一段
np.searchsorted(heights, 7.2, side="right") - 1    # 3   ← 比最后一个还大：没有 a[4]
```
两头会出 −1 和「最后一个下标」，所以**减 1 之后要夹进 [0, 长度 − 2]**（见第 3 条）。
你犯过：在 y 里找（10/25，下标跟着列表走）。**找谁就在谁的格点里找**：选表 → 在 `E_in` 里找 E；找区间 → 在**这张表**的 `cdf` 里找 ξ₁。

### 3. `min` / `max` 夹住一个数
```python
reading = 52.3
min(max(reading, -20), 45)    # 45     （-20 ~ 45 之外的读数夹回边上）
reading = -31.5  →  -20 ；  reading = 18.6  →  18.6（在范围内不动）
```
「最后一段的下标」= 点数 − 2：5 根柱子之间 4 个空，最后一个空的下标是 3 = 5 − 2。

### 4. `math.sqrt` vs `np.sqrt`
```python
math.sqrt(6.25)     # 2.5
math.sqrt(-0.3)     # ValueError —— 立刻停、告诉你哪行
np.sqrt(-0.3)       # nan + 一行警告，程序照跑 —— 静默错
```
用 `math.sqrt`（**文件头没有 `import math`，你自己在 import 那几行加一行**）。§5.3 的边角：ξ₁ 比 cdf[0]（1.2e-6）还小时，根号里可能是很小的负数 → 先和 `0.0` 取大再开方（OpenMC 也这么做）。

### 5. `rng.random()` —— 抽一次存进变量
每调一次给一个新的 [0, 1) 数。ξ₁ 今天找 E′ 用一次、**明天插 μ 还要再用一次** → 必须先存进 `xi1`，后面都用 `xi1`。
```python
r = gen.random()          # 0.6180...
a = r * 3.7 ; b = r + 0.25     # 两处用的是同一个数 ✅
a = gen.random() * 3.7 ; b = gen.random() + 0.25   # 两个不同的数 ✗
```
你犯过：漏写 `rng.`；`rng`（发生器）vs `rng.random()`（一个数）。

### 6. `if … else` 和浮点比较
- `f > 0.5`、`E_new < E_l / 2`：普通比大小。
- `s == 0.0`：浮点一般别用 `==`，**这里可以**：两个 pdf 值一模一样时，相减**精确**等于 0（同一个数减自己）。这时一次项公式要换（除以 s 会爆）。
```python
gap = top - bottom
if gap == 0.0:      # 两个数完全一样才进来
    ...
else:
    ...
```

### 7. `len(数组)`
点数。`len(E_in)` = 118（**别写死 118**，以后换温度 / 换库点数会变）；`len(tab["cdf"])` 每张表不一样（第 48 张 613）。
