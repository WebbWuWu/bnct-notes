## 0. 一句话原理

**第 6 课做的事，是把 `Σt` 从一个数变成一个函数。**
**第 7 课做的事，是把靶核从"钉死在原地"变成"自己也在动"。**

到第 6 课为止，你的靶核是静止的。静止靶核有一个致命后果：

> **中子每次碰撞只能变慢，永远不会变快。**

于是能量单调下降，一路降到 `E_cut = 0.0253 eV` 被你判死。**这不是物理，这是一个补丁。**
真实的中子不会消失，它会和介质里的原子核换能量换到**平衡**为止 —— 有时候丢能量，有时候**从热运动的靶核那里抢一点能量回来**（这就是**上散射**）。平衡的结果是一个固定形状的谱：**Maxwell 谱**。

**第 7 课就是把这个补丁拆掉，换成物理。**

### 2.1 `kT` —— 温度换算成能量

`k` 是玻尔兹曼常数。它的作用只有一个：**把温度这个单位换成能量这个单位。**

```
k = 8.617333262 × 10⁻⁵ eV/K      （这是定义值，2019 年 SI 改革后不带误差）
```

**算例（一步一步）**：你的截面库 `lib80x_hdf5` 是 **294 K** 的。

```
步骤 1   T = 294 K
步骤 2   kT = 8.617333262e-5 eV/K × 294 K
步骤 3      = 0.02533496 eV
步骤 4   四舍五入 → kT ≈ 0.02533 eV
```

**那么 v4 里写的 `kT = 0.0253 eV` 是哪来的？**

```
0.0253 eV / 8.617333262e-5 eV/K = 293.6 K
```

**它对应 293.6 K，不是 294 K。** 这个 293.6 K 是核数据界的一个历史约定：它让中子速度正好等于 **2200 m/s**，而所有热中子截面都是在这个点上报的。

**验一下 2200 m/s（这一步你自己算）**：

```
E = ½ m v²  →  v = c·√(2E / (m c²))
m c² = 939.565 420 MeV = 9.39565420e8 eV
2E / (mc²) = 2 × 0.0253 / 9.39565420e8 = 5.3855e-11
√ = 7.3386e-6
v = 7.3386e-6 × 2.99792458e8 m/s = 2200.2 m/s          ✅
```

> 🔴 **所以 `0.0253` 和 `0.02533` 是两个数，差 0.13%。**
> **判据里用哪一个，必须和你库的温度对齐。** 库是 294 K → 平衡谱的 `kT` 就是 **0.025335 eV**，
> 不是 0.0253。**拿 0.0253 去做卡方，在 N 大的时候会被判为不符合 —— 而代码没有任何错。**
> （这是第 6 课 §4.2「两条不同的路算同一个量」的第二次出现。）
>
> 🔴 **（9/30 改，Claude 的锅）上面「库是 294 K → kT 就是 0.025335」这个结论是错的。**
> 你 9/18 在《库结构说明》§3.2 实测过：**库里 `kTs/294K` 存的是 0.025301 eV** —— 库是按 293.6 K（kT = 0.0253 的室温惯例）做的展宽，"294K" 只是四舍五入的标签。

### 2.2 🔴 两个 Maxwell 分布 —— 这一课最容易翻车的地方

**"Maxwell 谱"这四个字有两个不同的东西，形状不一样。判据用错一个，你会花一整天去查一个不存在的 bug。**

| | 中子**密度**谱 `n(E)` | 中子**通量**谱 `φ(E)` |
|---|---|---|
| 形状 | `n(E) ∝ √E · e^(−E/kT)` | `φ(E) ∝ E · e^(−E/kT)` |
| 物理意义 | 单位体积里能量在 `E` 附近的中子**有几个** | 单位体积里能量在 `E` 附近的中子**走了多长的径迹** |
| 最可几能量 | `kT/2` = 0.01267 eV | `kT` = 0.02533 eV |
| 平均能量 | `1.5 kT` = 0.03800 eV | `2 kT` = 0.05067 eV |
| `E ≤ kT` 的占比 | **42.8%** | **26.4%** |

**两者差一个因子 `E^(1/2)`，来历是一行字：**

```
φ = n · v        （通量 = 密度 × 速度，第 3 课的定义）
v ∝ √E
⟹ φ(E) ∝ n(E) · √E ∝ √E · √E · e^(−E/kT) = E · e^(−E/kT)
```

**算例：`E ≤ kT` 的占比 26.4% 是怎么来的（通量谱，这个能手算到底）**

令 `u = E/kT`（无量纲化，以后全用 `u`）。通量谱 `φ ∝ u e^(−u)`。

```
分母（全部）  ∫₀^∞ u e^(−u) du
              分部积分：∫ u e^(−u) du = −(u+1)e^(−u)
              代 0 → ∞：  [−(u+1)e^(−u)]₀^∞ = 0 − (−1) = 1
分子（u ≤ 1） ∫₀^1 u e^(−u) du = [−(u+1)e^(−u)]₀^1 = −2e^(−1) + 1
              = 1 − 2 × 0.3678794 = 0.2642411
占比 = 0.2642411 / 1 = 26.42%                              ✅
```

密度谱那个 42.8% 要用误差函数（下一节讲 `erf`），公式是

```
P(u ≤ 1) = γ(3/2, 1) / Γ(3/2),   γ(3/2,x) = ½√π·erf(√x) − √x·e^(−x)
         = (0.886227×0.842701 − 1×0.367879) / 0.886227
         = (0.746824 − 0.367879) / 0.886227 = 0.378945 / 0.886227 = 42.76%
```

> 🔴 **判据要用哪一个？**
> 你的分层打分用的是**径迹长度估计器**（第 3 课），它天然测的是**通量**。
> 所以**如果你拿分层打分的能谱去比，应该比 `φ(E) ∝ E e^(−E/kT)`。**
> 但 §8 的卡方判据我建议你**不要**用径迹长度谱（理由见 §8.2，涉及"样本必须独立"），
> 而是**每条历史在同一个固定时刻 `t_cut` 记一个能量**，那记出来的是**密度谱** `∝ √E e^(−E/kT)`。
> **两条路不能混。§8 会把这件事钉死。**
> 🔴 **（9/28 改）原文写的是「每条历史记一个末态能量」，没说「末态」按什么定。按「第 n 次碰撞后」取，得到的既不是密度谱也不是通量谱（§8.2）。**

### 2.3 `erf` —— 误差函数

它就是"高斯曲线从 0 积到 x"的那个面积，没有初等闭式，所以人类给它起了个名字：

```
erf(x) = (2/√π) ∫₀^x e^(−t²) dt
```

要记的只有三条：`erf(0)=0`、`erf(∞)=1`、`erf(1)=0.842701`。
`np.math` 里没有，**`from math import erf` 或 `scipy.special.erf` 都有**。

### 2.4 `y` —— 中子速度用靶核热速度做的尺子（本课核心无量纲量）

靶核在 294 K 下自己在乱跑。它们速度分布的**最可几速度**是

```
v_T = √(2kT / M),     M = 靶核质量 = A × m_n
```

**把中子速度用这把尺子量一下，得到一个无量纲数 `y`：**

```
y = v_n / v_T
  = √(2E/m_n) / √(2kT/(A·m_n))
  = √( E·A / kT )                           ← 记住这一个就够
```

**`y` 的含义：中子比靶核快多少倍。**

- `y ≫ 1` → 中子快得多，靶核可以近似看成静止 → 退化回第 6 课
- `y ≈ 1` → 两者速度相当 → **上散射最猛，本课全部麻烦都在这里**
- `y ≪ 1` → 中子比靶核还慢 → 几乎每次碰撞都是**被撞快**

**算例（一步一步，H-1 和 O-16 各一次）**：

```
kT = 0.025335 eV（294 K）

H-1，E = 1 eV：      y = √(1 × 0.99917 / 0.025335) = √39.44  = 6.28
H-1，E = 0.0246 eV： y = √(0.0246 × 0.99917 / 0.025335) = √0.9702 = 0.985
O-16，E = 0.0246 eV：y = √(0.0246 × 15.858 / 0.025335) = √15.398 = 3.92
（9/30 注：kT 应为库里的 0.025301，y 全部乘 √(0.025335/0.025301) = 1.00067 —— 三个数到小数点后两位不变。）
```

> 🔴 **读出三件事**：
> ① H-1 在 1 eV 就已经 `y = 6.3`，靶核运动可以忽略 —— **自由气体处理只在低能区要紧。**
> ② H-1 在热能点 `y ≈ 1` —— **正好落在最麻烦的地方。而软组织 92.21% 的碰撞发生在氢上。**
> ③ **同一个能量下，重核的 `y` 更大**（O-16 是 H-1 的 √15.86 = 3.98 倍），
> 　 因为重核跑得慢。**所以重核比轻核更早可以当成静止的。**
>
> **一个常用的判断线（MCNP 的默认值）：`E > 400 kT` 时不做自由气体处理。**
> `400 × 0.025335 = 10.13 eV`。这条线的来历就是 ①：那里 `y = √(400A) ≥ 20`，靶核运动的影响小于 1%。

## 4. 自由气体模型

### 4.1 为什么抽靶核速度时要带一个 `|v_rel|` 权重（这一步是本课的地基）

**问题**：靶核速度服从 Maxwell 分布。那我直接按 Maxwell 分布抽一个靶核速度，不就完了吗？

**不对。而且错的方式很隐蔽。**

想一想第 1 课的那条地基：**均匀分布落在某个集合里的概率 = 那个集合的测度占比。**
这里要问的不是"靶核速度长什么样"，而是**"中子撞上的那个靶核，速度长什么样"**。这是两个不同的分布。

**来历（一行物理）**：单位时间里中子和某一类靶核的碰撞次数是

```
碰撞率 = n_靶 × σ × v_rel
```

**迎面飞来的靶核撞上的机会更大，同向跑开的靶核撞上的机会更小。** 所以：

```
P(抽到速度 v_T 的靶核) ∝ Maxwell(v_T) × |v_n − v_T|
                          ↑ 靶核本身的分布    ↑ 碰撞率权重
```

> 🔴 **漏掉 `|v_rel|` 这个权重，代码照跑，谱照出，一行不报错 —— 只是平衡谱的温度会偏。**
> **这正是 §8 判据 2 要抓的东西。**

### 4.2 抽靶核速度：舍选法的完整步骤

全部用 §2.4 的无量纲尺子。令

```
x  = v_T / v_T^th      靶核速度（无量纲）
y  = v_n / v_T^th      中子速度（无量纲）= √(EA/kT)
μT = 中子飞行方向 和 靶核速度方向 的夹角余弦
```

Maxwell 速率分布在这套单位下是 `p(x) ∝ x² e^(−x²)`（这就是 `4πv²` 那个体积因子乘上 `e^(−Mv²/2kT)`）。
相对速度（无量纲）用余弦定理：

```
v_rel = √( x² + y² − 2xy·μT )
```

于是目标分布是

```
P(x, μT) ∝ x² e^(−x²) · √(x² + y² − 2xy·μT)
```

**这个东西没法直接逆变换（根号里有两个变量），所以用舍选法。** 关键是找一个好用的上界：

```
√(x² + y² − 2xy·μT) ≤ x + y          （μT = −1 时取等，即迎面对撞）
```

把目标分布按这个上界拆开：

```
P ∝ [ x²e^(−x²)·(x + y) ] × [ √(x²+y²−2xyμT) / (x + y) ]
     └────── 好抽的建议分布 ──────┘   └──── 接受概率 ≤ 1 ────┘

而  x²e^(−x²)(x+y) = y·x²e^(−x²) + x³e^(−x²)      ← 两个分布的混合
```

两块的积分分别是 `∫₀^∞x²e^(−x²)dx = √π/4` 和 `∫₀^∞x³e^(−x²)dx = 1/2`，所以

```
选第一块的概率 = (y·√π/4) / (y·√π/4 + 1/2) = y√π / (y√π + 2)
```

**算例**：H-1 在热能点 `y = 0.985` → `0.985×1.77245 / (0.985×1.77245 + 2) = 1.74586 / 3.74586 = 46.61%`。
　 H-1 在 1 eV `y = 6.28` → `11.13 / 13.13 = 84.77%`。
　 **`y` 越大越偏向第一块 —— 第一块就是纯 Maxwell（靶核静止极限的方向）。合理。**

**完整算法（这是伪代码框架阶段要展开的，不是现在写码）**：

```
输入 y, A, kT
重复：
  1. 掷 ξ₁，以概率 y√π/(y√π+2) 走 A 路，否则走 B 路
     A 路（密度 ∝ x²e^(−x²)）：x² = −ln(ξ₂) − ln(ξ₃)·cos²(π·ξ₄/2)
     B 路（密度 ∝ x³e^(−x²)）：x² = −ln(ξ₂·ξ₃)
  2. μT = 2ξ₅ − 1
  3. 接受概率 P_acc = √(x² + y² − 2xy·μT) / (x + y)
     掷 ξ₆ < P_acc 则接受，否则回到 1
```

> **B 路那一行的来历（别背）**：令 `t = x²`，则 `x³e^(−x²)dx = ½ t e^(−t) dt`，
> 而 `t e^(−t)` 正是**两个独立指数分布之和**（Gamma(2,1)）。
> 两个指数分布 = `−ln ξ₂` 和 `−ln ξ₃`，加起来 = `−ln(ξ₂ξ₃)`。
> **这和第 1 课 `s = −ln(1−ξ)/Σt` 是同一条逆变换，只是用了两次。**
>
> A 路那一行的来历稍长（是把 `x²e^(−x²)` 拆成"一个指数 + 一个高斯投影"），
> **9/24 你要是想推，我当场推给你；不想推就当成一个查到的配方用，但要在注释里写清楚它是配方。**

### 4.3 散射运动学：四步变换（这一步取代第 6 课的 `[αE, E]`）

第 6 课那条 `E'` 均匀抽在 `[αE, E]` 的公式，**是"靶核静止 + CM 各向同性"两个条件下的闭式解**。
靶核一动，闭式没了，**只能老老实实做矢量变换**：

```
步骤 1  组装靶核速度 V_T（向量）
        大小 = x · v_T          ← v_T 就是刚才说的最可几速度；x 是舍选法抽出来的倍数
        方向：和中子飞行方向夹角的余弦 = μ_T
              绕中子方向转的方位角 φ，在 [0, 2π) 上均匀抽

步骤 2  质心速度 V_cm（向量）
        V_cm = (v_n + A · V_T) / (1 + A)

步骤 3  进 CM 系：   u = v_n − V_cm          （u 是中子在 CM 里的速度，向量）
        在 CM 里各向同性抽一个新方向，速率 |u| 不变 → 得到 u'

步骤 4  回 LAB 系：  v_n' = u' + V_cm        （向量相加）
        E' = ½ m |v_n'|²
        新方向 = v_n' / |v_n'|
```

> 🔴 **注意步骤 3 那一句"速率不变"**：CM 系里弹性散射**只改方向不改速率**，这是弹性散射的定义。
> **`E'` 之所以会变，全部来自步骤 4 那个矢量加法。** 第 6 课的 `[αE,E]` 就是把这四步在靶核静止时解出来的结果。
>
> 🔴 **这也是 §8 判据 1 的来历**：**令 `kT → 0`，这四步必须精确退化成第 6 课那条均匀分布。**
> 这是你唯一一条能把"矢量变换写错"和"上散射物理"分开来判的判据。

## 6. 上散射与细致平衡：Maxwell 为什么是终点

**为什么谱一定收敛到 Maxwell，而不是别的形状？**

因为自由气体散射核满足**细致平衡**：

```
M(E) · Σs(E → E')  =  M(E') · Σs(E' → E)
```

读法：**"处在 E 的中子跑到 E' 去"的总流量，等于"处在 E' 的中子跑到 E 来"的总流量 —— 当且仅当 `M` 是 Maxwell 分布时对一切 E、E' 成立。**

- 它的来历是**靶核速度服从 Maxwell**（§4.1）+ **微观可逆性**（碰撞的时间反演对称）。
- 它的后果是：**Maxwell 是这个散射核的不动点。** 任何初始谱，在纯散射介质里反复碰撞，都会趋向它。

**这就是 v4 那条交付判据的物理依据** —— 不是"看起来像"，是**唯一的平衡解**。

> 🔴 **反过来用，这一条就是最值钱的调试工具**：
> **如果你的平衡谱不是 Maxwell，那一定是细致平衡被破坏了。** 破坏细致平衡的方式只有三种：
> ① `|v_rel|` 权重漏了（§4.1）　② 运动学变换写错（§4.3）　③ 还有一个 `E_cut` 在偷偷杀中子（§7）。
> **这三个就是 §8 三条判据各自要抓的东西 —— 判据和 bug 是一一对应的，这不是巧合，是设计出来的。**
>
> 🔴 **（9/30 改，Claude 的锅）「一一对应」说过头了，① 这一条判据 2 看不见。** 9/30 容器实测（合成 H-1 库，截面按 §4.1 闭式展宽）：

**🔴 §8.2 为什么"每条历史只能取一个样本"**

卡方检验的前提是**样本互相独立**。而同一条历史里连续两次碰撞的能量是**强相关**的（第二次是从第一次那个能量出发的）。
**把一条历史的 50 次碰撞都塞进直方图，样本数虚高 50 倍，χ² 会被放大，p 值被压到 0 —— 而代码完全正确。**
**这和"SE 多除一次 N"是同一类错的两个方向：你以为你有 N 个独立样本，其实你只有 N/50 个。**

同理，**不要用分层打分的径迹长度谱做卡方** —— 那是加权和，不是计数，卡方公式 `Σ(O−E)²/E` 的分母压根不对。

**怎么取那一个样本（9/28 改）**：每条历史跑到时刻 `t_cut`，记下那一刻的 `E`（被 `t_cut` 截断的那一步飞行中 E 不变），这条历史就结束。

> 🔴 **原文写的是「跑满 `n_eq` 次碰撞后记下 E」—— 错。** 9/28 容器实测（H-1 自由气体、纯散射、无限介质、源 1 eV、各 20 万条，单位 kT = 1、Nσ₀ = 1）：
>
> | 取样方法 | 平均能量 | 是哪个谱 |
> |---|---|---|
> | 第 30 次碰撞后 | 1.743 kT | 都不是 |
> | 第 60 次碰撞后 | 1.753 kT | 都不是（预测 1.750 kT，见下） |
> | 时刻 t = 10 | 1.494 kT | 密度谱（1.5 kT）✅ |
> | 时刻 t = 20 | 1.504 kT | 密度谱（1.5 kT）✅ |
>
> 1.743 离 1.5 约 90 个 SE（密度谱 E 的标准差 √1.5 kT = 1.22 kT，N = 2×10⁵ → SE = 0.0027 kT）。
>
> **来历（一行）**：按碰撞序号取样 = 每撞一次点一次名，撞得勤的能量被点得多 → 取到的是**碰撞密度** `Σs(E)·φ(E) ∝ ⟨v_rel⟩(E)·√E·e^(−E/kT)`；
> 按时刻取样 = 拍一张照，每个中子算一次 → **密度** `n(E)`。
> 自由气体下 `Σs(E)·v = Nσ₀⟨v_rel⟩` 不是常数（低能 → 常数，高能 → v），所以碰撞密度既不是 n 也不是 φ。
> 按 `⟨v_rel⟩·√E·e^(−E)` 加权积分，平均能量 = 1.750 kT，和实测 1.743 / 1.753 对上。
> **这和 §4.1「撞上的靶核 ≠ 靶核本身的分布」是同一个道理 —— 我在 §4.1 警告过，§8 自己又犯了一次。**


**卡方一步一步的算例**（拿去照着核你自己的数）：
