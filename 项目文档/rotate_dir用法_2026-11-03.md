## 二、用到的写法（逐个，例子和项目无关）

### 1. `math.cos`、`math.sin` —— 吃的是**弧度**
```python
math.cos(1.2)             # 0.36236  → 1.2 弧度（约 68.8°）
math.cos(60)              # -0.95241 → 60 弧度，不是 60°！
math.cos(math.radians(60))   # 0.5   → 先把度换成弧度
```
φ 本来就是弧度（2π ξ₄），直接用。
你混过：φ 的范围 [0, 2π) vs μ 的范围 [−1, 1]。

### 2. `math.sqrt` 和「先和 0 取大」（复习）
```python
math.sqrt(1 - 0.6**2)                  # 0.8
math.sqrt(1 - 1.0000000000000002**2)   # ValueError：浮点误差让根号里成了 −4.4e-16
math.sqrt(max(0.0, 1 - 1.0000000000000002**2))   # 0.0 ✅
```
μ、w 理论上在 [−1, 1]，但浮点运算可能多出最后一位 → `a`、`b` 都先和 `0.0` 取大再开方（OpenMC 也这么做）。11/2 `d` 那里你写过同样的东西。

### 3. 浮点「接近 0」用门槛判断，**不用 `== 0`**
```python
gap = 1 - 0.9999999999999999**2      # 2.2e-16，不是 0
gap == 0.0                            # False
gap > 1e-10                           # False ← 用门槛才判得出「太小了」
```
§5.6：b > 1e-10 走一般公式；否则（旧方向几乎就是 ±z，除以 b 会爆）走特殊公式。
11/2 `s == 0.0` 那里能用 `==`，是因为两个 pdf 值**一模一样**时相减精确为 0；这里 b 是开方算出来的，差一点点也算「太小」，所以必须用门槛。

### 4. 先把重复用的量算好存起来
```python
r = 2.7
area = math.pi * r**2
c1 = 3 * area ; c2 = area / 4      # area 只算一次
```
cos φ、sin φ、a、b 各在三行公式里出现多次 → 函数开头各算一次存进变量。

### 5. 纯函数：只用参数，不碰随机数
```python
def tip(bill, rate):          # 结果只由参数决定；同样的参数永远同样的结果
    return bill * rate
```
`rotate_dir` 里**不出现 `rng`**：φ 在外面抽好传进来（框架 ⑦）。好处：判据能直接喂固定的 μ、φ 逐位对（T2）。

### 6. 返回三个值、接三个值（复习）
```python
def split3(total):
    return total * 0.5, total * 0.3, total * 0.2
x, y, z = split3(84.0)     # 三个名字按顺序接
```
你犯过：`for` 接的变量个数 ≠ 元组长度；`x` vs `x1`（接返回值和传参用了两个名字）。

### 7. 一般公式 vs 特殊公式（讲义 §5.6 + OpenMC `rotate_angle`）
**一般**（b > 1e-10），讲义 §5.6 三行：
  u′ = μ u + a (u w cos φ − v sin φ) / b
  v′ = μ v + a (v w cos φ + u sin φ) / b
  w′ = μ w − a b cos φ

**特殊**（b ≤ 1e-10）：改成绕 v 展开 —— **b 重新算成 √(1 − v²)**，三行变成
  u′ = μ u + a (u v cos φ + w sin φ) / b
  v′ = μ v − a b cos φ
  w′ = μ w + a (v w cos φ − u sin φ) / b
（OpenMC 0.15.3 `src/math_functions.cpp` `rotate_angle` 原样。注意 v′ 那一行没有除以 b；w′ 那一行是 **− u sin φ**。）
自己核一次：旧方向 (0, 0, 1) → 特殊分支 b = 1 → 新方向 (a sin φ, −a cos φ, μ)：长度² = a² + μ² = 1 ✅，和旧方向点乘 = μ ✅。
