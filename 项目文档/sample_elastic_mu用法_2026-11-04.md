## 一、它和你写过的 `sample_thermal` 有什么一样、有什么不一样

| | `sample_thermal`（11/2–11/3） | `sample_elastic_mu`（今天） |
|---|---|---|
| 表按什么分 | 入射能量 E_in（118 张） | 入射能量 `ang["E"]`（H1 153 张、O16 1636 张） |
| 每张表的横轴 | 出射能量 E′ | 质心系余弦 μ_cm ∈ [−1, 1] |
| **选表** | **f > 0.5 取右边**（最近的那张，不用随机数） | 🆕 **f > ξ 取右边**（随机选：离右边越近，越可能选右边；用 1 个随机数） |
| 表内抽样 | cdf 找 j → 二次反解 d | **完全一样的式子**（pdf 是线性的 → 积分是二次的） |
| 修正 | 缩放 / 平移 E′ | 🆕 没有修正；最后把 μ **夹进 [−1, 1]** |
| 随机数 | 3 个（ξ₁ ξ₂ ξ₃） | 2 个：选表 1 个、cdf 1 个 |

**为什么选表方式不一样**：两种都是 OpenMC 的做法，照抄（M3 框架 ⑥「全套照 OpenMC」）。随机选表叫**随机插值**：E 在两张表之间 30% 的位置，就有 30% 的次数用右边那张表 —— 抽很多次，平均出来的分布正好是两张表按 0.7 : 0.3 混合。热散射那边 OpenMC 是「最近的表 + 修正 E′」补能量差；角分布这边没有修正这一步，用的是随机插值。

## 二、名字（名字我起）

| 名字 | 是什么 |
|---|---|
| `ang` | 一个核素的角分布字典 = `angle["O16"]`（键 `"E"`、`"cm"`、`"tables"`） |
| `E` | 中子**实验室系**入射能量（eV）。OpenMC 也是拿实验室能量查这张表 |
| `E_g` | 这个核素的入射能量格点 = `ang["E"]` |
| `i` | E 落在第 i、i+1 个格点之间 |
| `f` | (E − E_i)/(E_{i+1} − E_i)，夹进 [0, 1] |
| `xi1` | 选表用的随机数 |
| `l` | 选中的表号（i 或 i+1） |
| `tab` | 选中的那张表（字典，键 `"mu"`、`"pdf"`、`"cdf"`） |
| `xi2` | 表内抽样用的随机数 |
| `j` | xi2 落在 cdf 第 j、j+1 个点之间 |
| `s` | 这一段 pdf 的斜率 |
| `d` | μ 离 μ_j 多远 |
| `mu` | 抽出来的 μ_cm（返回值） |

函数：`sample_elastic_mu(ang, E, rng)` → `mu`。**传一个核素的字典 `ang`，不传整个 `angle`**（`collide` 里撞到谁就传谁的）。

## 三、用到的写法（逐个，例子和项目无关）

### 1. 两层字典取一个核素
`angle` 外层键是核素名，里层是 `"E"`、`"cm"`、`"tables"`。函数只收里层那一份。
```python
zoo = {"panda": {"age": 7, "food": "bamboo"}, "koala": {"age": 4, "food": "eucalyptus"}}
one = zoo["koala"]       # 里层字典
one["food"]              # 'eucalyptus'
```
你犯过：两层字典少一层下标（10/23 `stodic[k]`）。在 `if __name__` 块里调用时写 `angle["O16"]`。

### 2. `np.searchsorted(有序数组, x, side="right") - 1` + 夹进 [0, 长度 − 2]
和 11/2 一样：找 `a[k] ≤ x < a[k+1]` 的 k；两头会出 −1 和最后一个下标，所以要夹。
```python
heights = np.array([2.5, 3.7, 4.1, 6.8])
np.searchsorted(heights, 3.9, side="right") - 1   # 1
np.searchsorted(heights, 2.1, side="right") - 1   # -1 → 夹成 0
np.searchsorted(heights, 7.2, side="right") - 1   # 3  → 夹成 2（= 4 − 2）
```
你犯过：在 y 里找（两次）。**选表在 `E_g` 里找 E；表内在 `tab["cdf"]` 里找 xi2。**

### 3. 夹一个**浮点数**：`min(max(x, 下限), 上限)`
11/2 你用它夹的是下标（整数），今天还要夹两个浮点数：`f` 夹进 [0.0, 1.0]，`mu` 夹进 [−1.0, 1.0]。写法一样。
```python
ratio = 1.37
min(max(ratio, 0.0), 1.0)    # 1.0
ratio = -0.042  →  0.0 ；  ratio = 0.58  →  0.58
```
**为什么 f 要夹**：E 比第一个格点还小时 i 被夹成 0，但 f = (E − E_0)/(E_1 − E_0) 是负数；E 比最后一个格点还大时 f > 1。夹完以后：太小一定用第 0 张，太大一定用最后一张（下面第 4 条的例子里有）。

### 4. 🆕 随机选表：`if f > xi1:` 取右边
```python
# 雨的概率 f = 0.2，抽一个 [0,1) 的数，比 0.2 小才算下雨 → 平均 20% 的天下雨
rain = 0.2
r = gen.random()
if rain > r:
    weather = "雨"
else:
    weather = "晴"
```
算例（和项目无关的格点）：`E_g = [1.0e3, 5.0e4, 2.0e5, 8.0e5]`
| E | i | f（夹之前 → 夹之后） | xi1 | 选中 l |
|---|---|---|---|---|
| 3.2e5 | 2 | 0.2 → 0.2 | 0.37 | 2（0.2 不大于 0.37） |
| 3.2e5 | 2 | 0.2 → 0.2 | 0.13 | 3 |
| 7.5 | −1 → 0 | −0.0203 → 0.0 | 任何 | 0 |
| 2.0e7 | 3 → 2 | 33 → 1.0 | 任何 | 3 |

注意：**先存 `xi1 = rng.random()` 再比**。别和 11/2 的「f > 0.5」混了 —— 今天比的是随机数。

### 5. 线性 pdf 的二次反解（11/2 你写过，同一个式子，横轴换成 μ）
在第 j 段里 pdf(μ) = p_j + s·(μ − μ_j)，从 μ_j 积到 μ_j + d 的面积 = p_j·d + s·d²/2，令它 = xi2 − c_j，解出
  d = ( √(p_j² + 2 s (xi2 − c_j)) − p_j ) / s；s == 0.0 时 d = (xi2 − c_j)/p_j。根号里和 0.0 取大。
算例（玩具表，不是库里的数）：μ = [−0.6, 0.2, 0.9]，pdf = [0.35, 0.80, 0.55]，cdf = [0, 0.46, 0.9325]
- xi2 = 0.61 → j = 1，s = (0.55 − 0.80)/0.7 = −0.357143，d = 0.196082，**μ = 0.396082**（核：0.80 × 0.196082 + s × 0.196082²/2 = 0.15 = 0.61 − 0.46 ✅）
- xi2 = 0.21 → j = 0，s = 0.5625，d = 0.442591，**μ = −0.157409**
你写完可以把这张玩具表拼成一个字典喂进去对这两个数。
你犯过（11/2）：公式少一项、`c_j = pdf[j]`（复制没改全）。今天别从 `sample_thermal` 复制，**自己再敲一遍**，名字也不一样（μ 不是 E′）。

### 6. `math.sqrt`（不是 `np.sqrt`）
负数立刻报错、不悄悄出 nan。⚠️ **`elastic_angle.py` 文件头没有 `import math`**，你在 import 那几行自己加。

### 7. `rng.random()` —— 抽一次存进变量
今天两个随机数 `xi1`（选表）、`xi2`（cdf），各抽一次、各存一个名字。
```python

```
你犯过：漏写 `rng.`；`rng` vs `rng.random()`。

### 8. `len(...)`
`len(E_g)`、`len(tab["cdf"])`，别写死 1636、153（每张表点数也不一样）。

## 五、要你今天定：μ_cm 怎么换到实验室系、放在哪（11/5 `collide` 接入时写）

先讲现在的程序：撞 H1 / O16 走 `free_gas_kinematics`，它的第 5+6 步是

**换到实验室系这件事，第 5+6 步本来就在做**；各向同性只是「q 怎么抽」那一行。
