## 一、今天学了什么

### 1【记】函数的参数是「外面传进来的」，函数里别再造一个盖掉它

```
geom(mat) 里第一行写 mat = mater()   →  传进来的材料被扔掉，换成一个新造的
run(…, inp, …) 里第一行写 inp = …     →  主程序传 j1 文件夹也没用，永远写进 run
```
同一个对象要在两处用（材料：放进集合 + 填进栅元）→ **只调一次 `mater()`，存进变量，两处都用这个变量**。调两次就是两个对象、两个编号，`geometry.xml` 里的材料在 `materials.xml` 里找不到。

### 2【记】tally = filter × score；name 只是标签

| | 是什么 | 写错会怎样 |
|---|---|---|
| `name` | 你起的名字，之后按它 `get_tally` | 两处不一样 → 找不到 |
| `scores` | OpenMC 认的关键词（`'flux'`、`'(n,gamma)'`、`'heating'`…） | 乱写 → 跑的时候报「不认识」；写成别的量（`'absorption'`）→ **不报错**，算的是另一个东西 |
| `dimension` | 三个整数，顺序固定 **(x, y, z)** | NL 放错位置 → 层切在 x 上，30 格几乎一样大 |
| `CollisionFilter([0])` | 只留「碰过 0 次」那一箱 | — |

### 3【记】判据 1 全过说明了什么

最大 |z| = 1.36（10 层）；SE 比值 1.021；Σt 故意错 3% 时 |z| = 6.8。
→ 材料（`'wo'` 归一化那个坑）、几何、源位置、**网格通量 = 整格径迹长度、不除体积**，这几件事你和 OpenMC 理解一致。
10 层里 8 层 z 是负的**不算系统偏差**：同一个中子穿过好几层，相邻层相关系数约 0.7，一起偏是正常的。也因为这个，判据 1 不用 χ²（χ² 要求各层独立）。

### 5【记】`else` 跟谁对齐，意思完全不同

| 写法 | 意思 |
|---|---|
| `for …:` … `break` … 下面 `else:` 和 **for** 对齐 | **循环跑满、一次都没 break** 才执行 |
| `if …:` 下面 `else:` 和 **if** 对齐 | 这一次条件不成立就执行 |

fgk 抄成了后一种（某一轮长度不够就直接 assert，不重抽）；interp 的第三个 `if e==E[mid]` 抄成 `else`，于是「大于」也走进去了。
