### 2【记】SE 用真数字算一遍（第 1 层 D_B，种子 1010）

x̄ = 4751.5 eV，σ₁ = 6568.1 eV（单条历史的散布，比均值还大），**SE = σ₁ / √N = 20.8 eV**，R = 0.44%。
σ₁ 和 SE 是两个量：σ₁ 描述「中子和中子差多少」，SE 描述「平均值本身抖多少」。

### 3【记】`find` 的两头

- n 个点 → n − 1 格 → 最后一格的下标是 **n − 2**。表外的 e 被「借用」最后一格，插值变成**外推**
- `>` 和 `>=` 在这里结果一样（e 正好等于 `E[-1]` 时，二分最后也停在 n − 2）—— 对拍测过
- `searchsorted(…, side="right")` 返回的是**右端点**的下标，`-1` 退到左端点（和下标从 0 开始无关）

### 4【记】log-log 插值 = 一格之内假设截面是幂律 σ ∝ E^p

双对数坐标里是直线，p 是斜率。1/v 区 p = −0.5，log-log 插值**精确**，线性插值反而差（例：e = 7.3，9.289 vs 10.128，差 9%）。

### 5【记】`1-xi` 不是讲究，是防 `log(0)`

`rng.random()` ∈ [0, 1)，**能取到 0、取不到 1**。`log(xi)` 在 xi = 0 时报错；`log(1-xi)` 的参数 ∈ (0, 1]，永远安全。（你 18:27 答对了）

### 6【记】今天的代码错误，一类一句

| 写成 | 应该 | 一类 |
|---|---|---|
| `def find_cell` | `def find` | 两个函数名字混了（`xs_lookup` 里那个才叫 `find_cell`） |
| `np.searchsorted_E_tab,e,…` | 左括号，不是下划线 | 函数调用的括号 |
| `.attrs("mt")` ×3 | `.attrs["mt"]` | 🔁 圆括号当方括号（老错） |
| `root["energy"][:]` | 再取一层 `[T]` | 少一层下标 |
| `rx.attrs["threhold.idx"]` | `int(xs_ds.attrs["threshold_idx"])` | 取错对象 + 拼写 + 少类型转换 |
| `return x,mu_T,k-1` | `k+1` | 🔴 静默：第 0 轮接受 = 第 1 轮 |
| `-log(xi1*xi2)` | `-log((1-xi1)*(1-xi2))` | 🔴 静默（且 xi = 0 时会崩） |
| `def __int__` | `__init__` | 拼写 |
