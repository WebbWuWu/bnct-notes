## 一、今天学了什么

### 1【记】σ₁²、Var(x̄)、SE —— 一条链，三个名字

```
σ₁²  ──÷N──▶  Var(x̄)  ──开根号──▶  SE
```

| | 是什么 | 复训那道题 | 代码里 |
|---|---|---|---|
| σ₁² | **单条历史**得分的离散 | 0.5344 cm² | `mean_se` 返回的 `var` |
| Var(x̄) | **均值**重跑一遍会晃多少 | 1.336e-5 cm² | 不单独存 |
| SE | 均值的误差棒 | 3.655e-3 cm | `mean_se` 返回的 `se` |

**自检**：Var(x̄) 一定比 σ₁² 小 N 倍；SE² 一定等于 Var(x̄)。哪一条不成立，就是两个 Var 混了。

### 2【记】0/1 得分的方差 ≤ ¼

得分只有 0 和 1 时 xᵢ² = xᵢ，所以 Σx² = Σx，代进 (1a) 那个公式：σ₁² = N/(N−1) · p̂(1 − p̂)。p̂(1 − p̂) 最大是 0.5 × 0.5 = ¼。
复训那题：p̂ = 0.2284 → σ₁² = 0.1763 → SE(p̂) = 0.002099（比例 0.23，相对误差约 1%）。

### 3【记】舍选法为什么对：g(x) 在乘法里约掉了

```
x 留下来的可能性 = 被抽到的可能性 × 被接受的概率
                 =      g(x)        ×   f(x) / (M·g(x))
                 =  f(x) / M   ∝  f(x)
```
图上看：在 M·g 曲线下面均匀撒点，只留下落在 f 下面的点 → 它们的 x 服从 f。平均每 M 轮接受一个（面积比 1 : M）。
`sample_target` 就是它的专用版：`pac = v_rel/(x+y)` 是接受概率。

### 4【记】1/v 外推：`sigma_at_ext`

库从 1e-5 eV 开始；自由气体能把中子撞得比这还慢（10 万条约 23 次）。低于表下限：σ(e) = σ(E₀) × √(E₀/e)，**所有道一起乘**（294K 表在 E ≪ kT 时弹性也是 1/v）。
算例：e = 3.1e-6 → 因子 √(1e-5/3.1e-6) = 1.79605。
