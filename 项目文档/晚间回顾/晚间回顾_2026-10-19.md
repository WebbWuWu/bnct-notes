## 一、今天学了什么

### 1【记】`uint32_t` 超出范围不报错、也不卡住，而是**回绕**

4000000000 + 400000000 = 4400000000，超过 2³² = 4294967296 → 存进去的是 4400000000 − 4294967296 = **105032704**。
如果它像你一开始以为的那样「卡在最大值 4294967295」，lcg 下一步 `a × state + c` 还是超，又卡回最大值 → **状态不前进**，每次抽出同一个数（10/18 默写里出过的同一类静默错）。

### 2【记】改了 `.cpp` 必须重新 `g++`

`./hello` 是**上一次编译出来的旧文件**。Python 每次运行都重新读 `.py`；C++ 不会 —— 不重编译，跑的还是旧逻辑（你今晚第一次跑出 `hello`，改完重编才是 `0.30000000000000004`）。

### 3【记】头文件里只有一行声明：`返回类型 名字(类型 参数, 类型 参数);`

| 你写过的 | 问题 | 一类 |
|---|---|---|
| 照着 `Counter` 写了 `struct { … }` | `ring_area` 是普通函数，不属于任何类 | 🔁 照抄例子里的结构（老问题「照抄例子里的占位」） |
| `ring_area{ double r_out; double r_in }` | 参数放**圆括号**、用**逗号**分隔 | 🔁 括号种类决定意思（老问题「圆括号当方括号」） |
| `…){return double;}` | 头文件不写函数体；`return` 后面要跟**值**，`double` 是类型名 | 声明 vs 定义 |

记法：**写在 `struct { }` 里的是对象的属性（≈ `self.r_out`）；写在函数名后圆括号里的是参数。**（你答对了后一半，是我理解错了你的回答。）

### 4【记】`apt` 报 **Hash Sum mismatch**：大小一样、内容被改 → 换 **https**

今晚的修法（以后 WSL 装东西如果再遇到同样的错，照这个来）：
1. `/etc/apt/sources.list.d/ubuntu.sources` 里的地址换成 `https://mirrors.tuna.tsinghua.edu.cn/ubuntu/`（原文件备份在同目录 `ubuntu.sources.bak`）
2. `sudo rm -rf /var/lib/apt/lists/*` 清掉坏缓存
3. `sudo apt update` → `sudo apt install -y 包名`
