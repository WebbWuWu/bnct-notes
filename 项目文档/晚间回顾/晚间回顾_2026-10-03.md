### 2【记】自由气体展宽闭式

```
σ̄ / σ₀ = (1 + 1/(2y²))·erf(y) + e^(−y²)/(y√π)，     y = √(E·A/kT)
y 很小时 ≈ (2/(√π·y))·(1 + y²/3)    ← 领头项就是 1/v；修正项 y²/3 就是 1/v 外推的误差
```
H-1：表下限 1e-5 eV 以下 1/v 外推的误差 ≤ E[0]·A/(3kT) = **1.3e-4**（判据 4 实测 3.1e-6 eV 处 8.6e-5）。

### 3【记】剂量单位链

```
1 eV  = 1.602e-19 J
1 MeV = 1.602e-13 J
1 MeV/g = 1.602e-13 J / 1e-3 kg = 1.602e-10 Gy
477 851 eV = 477.851 keV = 0.477851 MeV
```
一维平板：D_k / Φ₀ = ε_k / (ρ·dz·N)，**面积 A 消掉**，单位 Gy·cm²。
算例：15 ppm ¹⁰B、10¹² n/cm² 热中子 → D_B = 1.30 Gy（每 ppm 0.0867 Gy）。

### 4【记】隐式俘获下 D_H 用碰撞后的权重

| 结局 | 概率 | 留下的反冲能量 |
|---|---|---|
| 散射 | p | wt·(E − E') |
| 吸收 | 1 − p | 0 |

E[留下] = p·wt·(E − E') = **(wt·p)·(E − E') = wt碰后·(E − E')**。
**概率只看物理（p），权重乘在分数上** —— 两行概率加起来必须是 1。

### 5【记】测试参数取 1 的后果

Q = 1：`× Q` 漏写看不见。Σ = 1：`× Σ` 和 `/ Σ` 一样。**参数取 1，它在公式里乘、除、漏，全都看不见。**

### 6【记】`for … else` vs `if … else`

```python
for k in range(1000):
    ...
    if rng.random() < pac:
        return x, mu_T, k+1
else:                      # ← 和 for 对齐：1000 轮都没 return / break 才进来
    assert False
```
和 `if` 对齐就成了「这一轮没接受」—— 第一次被拒就停，舍选法走不到第二轮。**只差几格缩进。**
