### 2【记】按「第 n 次碰撞」取样 ≠ 按「时刻 t」取样

| 取法 | 平均能量 | 是哪个谱 |
|---|---|---|
| 第 30 次碰撞后 | 1.743 kT | 碰撞密度（都不是） |
| 时刻 t 时 | 1.494 kT | **密度谱**（理论 1.5 kT） |

**按碰撞取 = 每撞一次点一次名，撞得勤的能量被点得多；按时刻取 = 拍一张照，每个中子只算一次。**
和第 7 课 §4.1「撞上的靶核 ≠ 靶核本身的分布」是同一个道理。

### 3【记】A 路 / B 路 = 一个混合分布的两块

```
目标  x²e^(−x²) · √(x²+y²−2xyμT)        ← 根号里两个变量，抽不了
上界  √(...) ≤ x + y                     ← μT = −1（对撞）时取等
拆开  x²e^(−x²)(x+y) = y·x²e^(−x²)  +  x³e^(−x²)
                        └ A 块，面积 y√π/4 ┘  └ B 块，面积 1/2 ┘
选 A 的概率 = (y√π/4) / (y√π/4 + 1/2) = y√π / (y√π + 2)
    y = 0.985 → 46.6%        y = 6.28 → 84.8%
A 块 = 纯 Maxwell（不偏向快慢）；B 块多一个 x（偏向快的靶核）
B 路：x² = −ln((1−ξ₂)(1−ξ₃))   ← 两个指数分布之和，第 1 课那条逆变换用两次
```

### 4【记】μT：靶核方向和中子方向的夹角余弦（x = 1.192，y = 0.985）

| μT | 画面 | v_rel | 接受概率 v_rel/(x+y) |
|---|---|---|---|
| −1 | 对撞 | 2.177 | 1.000 |
| 0 | 横穿 | 1.546 | 0.710 |
| +1 | 追尾 | 0.206 | 0.095 |

### 5【记】两个「Var」—— SE 多除一次 N 的根子

| | 是什么 | N = 10⁶ | 求 SE |
|---|---|---|---|
| `mean_se` 里的 `var` | **单个样本**的方差 σ₁² | 2.697 | √(var / N) |
| ④ (2a) 的 Var(pi_hat) | **平均值**的方差 | 2.697 / 10⁶ | √Var(pi_hat)，**不再除** |

**N 只除一次，除在「单个 → 平均」那一步。写 SE 前问：这个方差里 N 除过没有？**
