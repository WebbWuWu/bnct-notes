## 一、今天学了什么

### 1【记】舍选法函数：5 个设计决定，每个都是你定的

```python
def sample_rejection(f, g, g_sample, M, rng):
    for k in range(Max):                # Max = 1000
        x = g_sample(rng)               # ① 按 g 抽 x
        y = rng.random() * M * g(x)     # ② y 均匀在 [0, M·g(x))
        if y < f(x):                    # ③ 严格 <
            return x, k + 1             # ④ 样本 + 用了几轮
    else:
        return None                     # ⑤ 撞满上限
```

| 决定 | 为什么 | 反过来会怎样 |
|---|---|---|
| `g` 和 `g_sample` 分开传 | 一个**算高度**，一个**抽样本**，是两件事 | 只传 g，第 ① 步抽不出 x |
| `rng` 由调用方传 | 纪律 18 | 函数里写 `lcg(2026)`，每次调用抽出同一个数 |
| 严格 `<` | `rng.random()` 取得到 0；f(x)=0 的点必须永远拒绝 | `<=` 在 ξ=0、x=0 时接受一个密度为 0 的点 |
| 返回 `k + 1` | k 从 0 数，第 1 轮接受时 k=0 | 返回 k，平均轮数少 1（栅栏桩） |
| 撞满返回 `None` | `None` 不是数，拿去运算就报错（纪律 16） | 返回 0.0：混进样本里，没人知道 |

### 2【记】M 给小了是**静默错**，封顶不是修复

M = 1.5（应为 2）时，x > 0.75 那一段的接受概率本该 > 1，实际被封顶在 1 → 分布右端被削平，**不报错**。
唯一正确的处理：**`assert f(x) <= M*g(x)`，当场响。** 这条 assert 两边来自两条独立的路（f 和 M·g），所以不是恒真的。
9/17 那条 `assert y < M*g(x)` 两边同源（y 就是从 M·g(x) 乘出来的），**恒真**。

### 3【记】判据的测试参数不能取「特殊值」

| 写错 | Σt = 1.0 时 | Σt = 2.0 时 |
|---|---|---|
| `s = -ln(1-ξ) * Σt`（应为 `/ Σt`），ξ=0.5 | 0.693 = 0.693，**完全一样** | 1.386 ≠ 0.347 |

Σt = 1 时乘除一样，判据**没有分辨率**（纪律 4）。今晚舍选法判据 1 用的假随机数是 0.3、0.9、0.8、0.5 —— 故意不整。
