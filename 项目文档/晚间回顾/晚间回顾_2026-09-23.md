## 一、今天学了什么

### 1【记】隐式俘获一句话

> **改变「事件发生的概率」，同时改变「事件发生时记多少分」，让两者的乘积保持不变。**

| | 类比（你现在的程序） | 隐式俘获 |
|---|---|---|
| 一次碰撞 | 抽随机数：概率 p 活、1−p 死 | **不抽**，必定活 |
| 活下来的代价 | 无 | 权重打折 `wt = wt × p` |
| 吸收去哪了 | 整个粒子死掉 | **每次碰撞吸收掉一部分**：`wt × (1−p)` |

### 2【记】无偏证明（⑩(1) 的标准答案）

一次碰撞，碰撞前权重 1。`S` = 碰撞后「活着、带权重 1」接着飞，还会拿到的总分。

```
类比：  结局        概率     之后平均还能拿
        散射（活）   p        E[S]
        吸收（死）   1−p      0          ← 历史 break 了，后面不再往 track_h 上加任何东西
        E[类比] = p·E[S] + (1−p)·0 = p·E[S]        用的性质：以概率 a 拿 X、以 1−a 拿 Y，平均 = aX + (1−a)Y

隐式：  结局        概率     权重     之后平均还能拿
        散射（必定） 1        p        p·E[S]      ← 权重乘在得分上，平均也跟着乘 p
        E[隐式] = 1 · p·E[S] = p·E[S]

⟹ E[类比] = E[隐式]，平均不变 ⟹ 无偏
```

🔴 你卷面上隐式那一行的「概率」写了 **p**，应为 **1**。按你的表乘出来是 p²·E[S]，和你写的式子打架。

### 3【记】权重在代码里只出现三处 —— 今天卡最久的就是这张图

```python
wt = 1.0                                        # ① 出生：权重 = 1
...
track_h[k] += wt * dz_step / abs(w)             # ② 飞行途中记账：乘【当前】权重
...
wt = collide_implicit(wt, sigma_s, sigma_t)     # ③ 碰撞：权重打折（只有这里会变）
```

**权重跟着「撞过几次」走，不跟「在哪一层」走。** 同一段飞行穿过 5 层，5 层乘的是同一个 wt。

| 事件 | 代码位置 | wt |
|---|---|---|
| 已撞 2 次 | — | 0.64 |
| 飞过第 3、4、5 层 | ② | 三层都乘 **0.64** |
| 撞第 3 次 | ③ | 变 **0.512** |
| 往回飞，又过第 4 层 | ② | 这次乘 **0.512** |

**为什么不写 `p**n`**：第 3 课 p 是常数，`p**n` 碰巧对；第 6 课起每撞一次能量变、p 也变（0.95、0.90、0.99……），
乘积不是任何数的 n 次方。**`wt` 这个变量存在的理由，就是替你记住一路上所有折扣的乘积。**

### 4【记】两个方差事实

- **每次都取同一个值的量，方差 = 0**（`E[X²] − E[X]² = c² − c² = 0`）。
- **指示变量（只取 0/1）的方差 `P(1−P)` 最大 0.25**（P = 0.5 时）。写出大于 0.25 的，一定错了 —— 今天 0.9587 就是这么抓出来的（应为 0.09587）。

玩具模型（p = 0.8，撞 10 次）：

```
类比  E = 0.1074   Var = 0.1074 × 0.8926 = 0.0958    R ≤ 5% 要 N = 0.0958 / (0.1074² × 0.05²) ≈ 3325
隐式  E = 0.1074   Var = 0                            1 条就精确
```

**真实程序里隐式方差不为 0**：飞行距离、散射方向仍随机 ⟹ **撞几次才飞出去是随机的** ⟹ `X = p^n` 里 n 在变。
（容器实测 d=5、c=0.8：隐式平均撞 11.2 次，2 万条里最多 168 次。）

### 5 换成隐式后，四条现有检查

| 检查 | 结论 | 理由 |
|---|---|---|
| `T+R+A=1` | **改写** | n_A 恒为 0；改成权重记账：`(W_T + W_R + W_A)/N = 1`，W_A = 每次碰撞 `wt(1−p)` 的总和。**它仍是记账判据，抓漏记/重记，抓不到物理错** |
| 随机数 4/2/1 | **改写** | 只少了「死活」那一个：散射 **3**（飞行 1 + 方向 2）、吸收分支没了、飞出 1 |
| 验证 B | **改写** | 径迹乘了权重、碰撞次数没乘，两边不再是同一个量 |
| `n_stuck` | 基本仍成立 | 薄板里远到不了 10000 次；厚板（d=1000）会到。加了⑪的轮盘赌之后重新判 |

🔴 **最危险的是验证 B**：那条 assert 两边来自同一批累加器，是记账恒等式，**换成隐式照样不响**，可它代表的物理关系已经不成立 —— **坏了不报错，数字还很正常。**

### 6 `collide_implicit` 的两种坏输入

- `sigma_t = 0` → `ZeroDivisionError`（当场炸）
- `sigma_s > sigma_t` → wt 撞一次反而变大，通量整体偏高，**不报错**。物理上 σt = σs + σa、σa ≥ 0，所以 σs 不可能大于 σt
