## 一、今天学了什么（原理层面）

### 1【记】立体角元为什么等于 `dμ·dφ`

```
dΩ = sin θ dθ dφ              立体角元的定义（几何，不用证）
μ = cos θ  ⟹  dμ = −sin θ dθ
θ: 0→π 对应 μ: 1→−1，积分方向反了；交换上下限再吃掉一个负号
⟹  dΩ = |dμ| · dφ
```

**这一步是「μ 均匀 + φ 均匀 ⟹ 各向同性」这个证明的承重墙。** 写证明时它必须被推出来，不能当已知。

### 2【记】均匀分布的那条地基

> **均匀分布落在某个集合里的概率 = 那个集合的测度（长度/面积/体积）占全体的比例。**

用处不止一处：**逆变换抽样、舍选法、命中法、离散抽样（累加比较）四个方法共用的就是它。**

### 3【记】两个能分辨「θ 均匀」这个错的数

```
正确（μ 均匀抽 [−1,1]）：  <w²> = ∫₋₁¹ μ²·(1/2) dμ = 1/3 = 0.3333
错法（θ 均匀抽 [0,π]）：   <w²> = <cos²θ> = (1/π)∫₀^π cos²θ dθ = 1/2 = 0.5000
<w> 两种都是 0 —— 所以 <w> 抓不住，<w²> 抓得住
```

判出这个错只要 **N ≈ 80 条历史**（Δ=1/6、s=0.298、要 5σ）。**错不在样本不够，在没去看这个量。**

### 4【记】判据管的是随机数流，不是物理量

一维平板里不抽 `φ`：

- **物理上**：通量结果不变（打分只依赖 `z`，`z` 只由 `w=μ` 推动，`u,v` 从不进入）。
- **判据上**：「逐位相同」**整条失效** —— 少抽一个随机数，两边的流从此错位一格。

> **一个物理上完全等价的改动，可以让判据整条失效。反过来也一样。**
> 所以「判据的适用条件要和判据一起写下来」：逐位相同的条件里必须写着「两边随机数消耗完全一致」。

### 5【记】夹紧值和原值是两个东西

```python
z1    = z0 + s*w          # 原值，可能在板外
z_end = 夹进 [0, d]        # 夹紧值，给记账用（板外没有介质，不能记）

track_h[...] += ... 用 z_end     ← 记账
if z < 0 / if z > d   用 z1      ← 判断有没有飞出界
```

**用 `z_end` 去判断出界，两个判断永远为假，而且一行不报错。** 今天最贵的一个错。

### 6 舍选法去掉三角函数：接受率与 warp 代价

```
接受率 = 圆面积/正方形面积 = π/4 = 0.7854
单线程平均轮数            1/0.7854 = 1.27
32 线程全部一轮通过的概率  0.7854³² = 4.4e-4
32 线程 warp 平均等       3.13 轮        ← 发散把代价放大 2.5 倍
```

**结论：不划算**（GPU 有 SFU 硬件算 `sinf`/`cosf`，很便宜）。
🔴 **适用条件**：SFU 只管 float。换 double、或换没有 SFU 的硬件，结论可能反过来。

### 7【记】类、实例、方法（Python，C++ 里是同一套概念）

```python
lcg               # 类 = 图纸
rng = lcg(2026)   # 实例 = 照图纸造出来的一台机器，自带 self.state
rng.random()      # 调用这台机器身上的方法，推进 state 并返回一个数
```

| 写法 | 报什么 |
|---|---|
| `1 - rng` | `TypeError` —— 机器不是数 |
| `rng()` | `TypeError: 'lcg' object is not callable` |
| `lcg.random(seed)` | `AttributeError: 'int' object has no attribute 'state'` |
| `rng.random()` | ✅ |

**关键是 `state`**：发生器必须记住走到哪了，下一个数才接得上。图纸上没有 state。

### 8 拆层记账的四步顺序

```
① 算这一步走到哪：z_step = min/max(层出口边界, z_end)
② 记账：track_h[当前的 k] += |z_step − cur| / |w|
③ cur = z_step
④ 到终点层（k == k1）就 break；否则 k 按 w 的符号 ±1
```

**②必须在④之前**（否则最后一段永远没记），**②必须在 k 更新之前**（否则整条曲线错位一格）。
