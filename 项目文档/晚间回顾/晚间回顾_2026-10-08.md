## 一、今天学了什么

### 1【记】表格抽样 = 份额 → 累积 → 找格子 → 箱内抽

```
edges  = [0.5, 1, 3, 10, 50, 200, 1000, 3000, 10000]      ← 9 条边界，8 个箱
shares = [0.06999, 0.11093, 0.12157, 0.16251, 0.13998, 0.16251, 0.11093, 0.12157]   ← 8 个
cdf    = [0, 0.06999, 0.18092, 0.30249, 0.465, 0.60499, 0.7675, 0.87843, 1.0]       ← 9 个
```
- `cdf[i]` = 能量低于 `edges[i]` 的占比 → **下标和 edges 对齐，所以开头必须有 0**
- ξ₁ = 0.37 → `find_cell(cdf, 0.37)` = 3 → 箱 [10, 50]
- ξ₂ → `E = 10·(50/10)^ξ₂`（**ln E 上均匀**；1/E 谱在箱内就是这个形状）
- 同一套用在**抽核素**上：份额换成 Σ_t,i/Σ_t（真吸收）或 Σ_s,i/Σ_s（隐式）

### 2【记】`find_cell` 返回的是「左边那条边界的下标」

`np.searchsorted(列表, x, side="right")` = 列表里 ≤ x 的数有几个；减 1 就是格子号。ξ = 0 → 0；ξ = 0.95 → 7（最后一个箱）。
⚠️ 有份额为 0 的箱 → cdf 有两个相等 →「不递增」那条 assert 会响（换真实谱表时注意）。

### 3【记】隐式俘获的「打折」

真吸收：以 Σ_a/Σ_t 的概率死。隐式：**一定活，权重 × Σ_s/Σ_t**。
例：Σ_s/Σ_t = 0.98531 → 1.0 → 0.98531 → 0.97084 → … 约 156 次后到 0.1 → 轮盘赌（`wt_c=0.1`、`wt_s=0.2`）。
**单核素隐式也要打折**；隐式模式**不再调用 `sample_reaction`**（否则吸收算两次）。
