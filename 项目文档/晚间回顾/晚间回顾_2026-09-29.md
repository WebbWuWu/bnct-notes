### 2【记】`free_gas_kinematics` 七步（你定的版本）

```
0  y = √(EA/kT)                                   ← 以 v_T 为尺，中子速率 = y，靶核速率 = x
1  中子速度 = y × (u, v, w)

2b e₁ = 剩余 / 长度
2c 靶核方向 = μ_T·d + √(1−μ_T²)·e₁                 ← 不抽 φ、不造 e₂：r 各向同性 ⟹ e₁ 方位已均匀

3  V_cm = (中子速度 + A·靶核速度) / (1 + A)
4  CM 速度 = 中子速度 − V_cm，记速率
5  CM 里各向同性抽方向 × 同一速率
6  v′ = CM 新速度 + V_cm → E′ = (kT/A)|v′|² → 方向 = v′/|v′|
```
