### 2【记】误差棒是对的 ≠ χ² 一定在 [13.79, 53.67] 里

`check_se` 用 10 个种子量出来：OpenMC 自报的 SE 和 10 次之间的实际散布之比 R = 0.99–1.08（**SE 对**），但 heating 的 30 层是**一起涨落**的（层间相关 ρ̄ ≈ 0.4）—— 同一个程序两次都对，互比 χ² 也能到 97、107，约 22% 出界。
→ 10/16 的 χ² = 74 不是错。判据 4 的 χ² 上限改用「OpenMC 自己 45 对里最大的那个」（你 17:38 定，**看新数据之前定的**）。

### 3【记】SE 也是估出来的 —— 样本里没有稀有事件，它就骗人

C12 第 26 层：你的 s1010 均值 0.0000066、SE 0.0000031（10 万条里一次快中子撞 C12 都没有），隔壁层撞上一次就是 3.92 ± 2.85 → z = −69。
判断 SE 能不能信：**相对误差 R = SE / 均值，> 0.2 就不能用**（MCNP 的经验）。🆕 下一课起：**判据之前先查 R**。
为什么 OpenMC 没这个问题：它的 heating 是「每段径迹都记 KERMA × 长度」（径迹长度估计），你的 D_H 只在真撞上时才记（碰撞估计）—— 估同一个平均值，方差差好几倍。

### 4【记】H(n,γ) 的反冲：一次很小，加起来不小

E_R = E_γ² / (2 M_d c²) = 2.2246² / (2 × 1875.6) MeV ≈ 1.32 keV（库里量出 1315.8 eV，公式 1317.3，差 0.1%）。

### 6【记】今天的代码错误，一类一句

| 写成 | 应该 | 一类 |
|---|---|---|
| `nam = nuclides[jn]` | 再取 `["name"]` | 列表取一格 → 字典取一个键，两层 |
| `for name in nuclides["name"]` | 先一格一格取字典，再取 `"name"` | 列表不能用字符串当下标 |
| `mean[i][r]` | `mean[r][i]` | 两层下标先外后内（外层 = 第几次运行） |
| `sum(mean_n)` / `sqrt(se2_n**2)` / `return res1,res1` | 直接除 / 先开根号 / 返回 `res2` | 公式和返回值逐项对 |
| `DBmean = my_run(…)` | 先接住，再 `append` | `=` 是换掉，`append` 是放进去 |
| `rat[i] = …`（`rat = []`） | `append`，或先造 30 个 0 | 空列表没有第 i 格 |
| OpenMC 那边还用 `my_run(…, "Bc", …)`（3 次）、D_N 放进 D_B 的数（2 次）、放进第 5 步的 `DHx` | 复制以后逐个名字改 | **复制没改全** —— 今天最多的一类 |
| `ax2.set_ylim=(0.7,1.3)` | `ax2.set_ylim(0.7, 1.3)` | 🔴 **静默错**：赋值不报错，只是什么也没设 |
| `(i+0,5)*dz` | `0.5` | 小数点写成逗号 = 一对数 |
| `shares=`、`fnt=`、`makersize=` | `sharex`、`fmt`、`markersize` | 参数名拼错 |
| `for name in out_class` | 名字叫 `d` 或 `run` | 同一个名字一会儿是文件名、一会儿是字典 |
