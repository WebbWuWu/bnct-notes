s1010 单独和 OpenMC 比，通量 1σ 内 28/30 —— z 散得比正态还窄。可能是 (A) 碰巧，也可能是 (B) 误差棒估大了。**分辨办法：同一个程序换种子独立跑两次，自己和自己比**（3-5）：

| 自比 | χ²（应 ≈ 30） |
|---|---|
| OpenMC 种子 1 vs 2 | 29.6 / 37.7 |
| 你的 s1010 vs s1200 | 22.2 / 18.0 |

两边 SE 都可信 → (A)，s1010 恰好离真值近。按「合并」判，门槛一个没改，只是把数据都用上。

### 3【记】判据 5：自由气体近似（#9）不是小近似

| 深度 | D_B：S(α,β) 比自由气体 |
|---|---|
| 0.25 cm | +7% |
| 1.75–2.75 cm（峰） | **+23%** |
| 6.5 cm | ≈ 0（交叉） |
| 14.75 cm | **−52%** |

峰的**位置**只移了 −0.06 cm（2.28 → 2.22），变的是**形状**：峰更高，深处掉得更快。机制就是你猜的那个：束缚氢在热区散射截面大好几倍 → 热中子扩散得近 → 留在出生地（前两三厘米）附近。
→ 讲义 §3 说「几个百分点」是我估错了一个数量级，已更正。

### 4【记】两次独立运行合并

均值 = (m₁ + m₂)/2，SE = √(SE₁² + SE₂²)/2。来历：Var(X/2) = Var(X)/4，独立时 Var(X+Y) = Var X + Var Y。

### 5【记】今天的代码错误，一类一句

| 写成 | 应该 | 一类 |
|---|---|---|
| `sigma_at[E,XS,e]` | `sigma_at(…)` | 调函数用圆括号，方括号是「取」 |
| `d.append(a)`（d 是字典） | `d[a] = 值` | append 是列表的 |
| `d[a]["mean"] = m` | `d[a] = {"mean": m, "se": s}` | 内层还不存在，取不出来 |
| `merge_two` 里 `mean2`、`se1`、`se2` | 都要 `[i]` | **下标跟着「从哪个列表取」走** |
| `mean_se(su, sq, his)` | `mean_se(su[i], sq[i], his)` | 同上；`[i]` 加在传进去那一侧 |
| `run(…, n_bat=10000, mat)` | `mat=mat` | 按名字传之后，后面全按名字 |
| `"%-8.2s"` | `"%8s"` | `.2` 用在字符串上 = 截断 |
| `"c_H_in_H20"` | `"c_H_in_H2O"` | 数字 0 vs 字母 O |
