## 0. 全文（照这个抄）

```python
import matplotlib.pyplot as plt
import os

HERE = os.path.dirname(os.path.abspath(__file__))


def read_flux_csv(path):
    """读 lesson03 吐出的通量 csv，返回 (z_mid, phi, err) 三个列表。"""
    z_mid = []
    phi   = []
    err   = []
    with open(path, "r", encoding="utf-8") as f:
        lines = f.readlines()
    for line in lines[1:]:
        parts = line.strip().split(",")
        z_mid.append(float(parts[3]))
        phi.append(  float(parts[4]))
        err.append(  float(parts[5]))
    assert len(z_mid) > 0, "csv 里一行数据都没读到（只有表头或文件为空）：%s  总行数=%d" % (path, len(lines))
    return z_mid, phi, err


CASES = [
    (os.path.join(HERE, "flux_case1.csv"), "case 1: d=2.0, $\\Sigma_t$=1.0, $\\Sigma_s$=0.0"),
    (os.path.join(HERE, "flux_case2.csv"), "case 2: d=2.0, $\\Sigma_t$=1.0, $\\Sigma_s$=0.8"),
    (os.path.join(HERE, "flux_case3.csv"), "case 3: d=5.0, $\\Sigma_t$=1.0, $\\Sigma_s$=0.9"),
]

ERR_SCALE = 1.0

fig, ax = plt.subplots(figsize=(7, 5))

for path, label in CASES:
    z, phi, err = read_flux_csv(path)
    ax.errorbar(x=z, y=phi, yerr=[e * ERR_SCALE for e in err], label=label,
                marker="o", markersize=3, capsize=2, linewidth=1)

ax.set_xlabel("depth (cm)")
ax.set_ylabel("flux (cm$^{-2}$ per source neutron)")
ax.set_title("Track-length flux in a 1D slab (N=1e6, seed=2026)")
ax.legend()
ax.grid(True, alpha=0.3)
ax.set_yscale("log")

fig.savefig(os.path.join(HERE, "lesson03_flux.png"), dpi=150, bbox_inches="tight")
plt.show()
```

## 3. `read_flux_csv` —— 把一个 csv 读成三个列表（第 7–20 行）

### 3.1 三个空列表

```python
    z_mid = []
    phi   = []
    err   = []
```

`[]` 是空列表，后面用 `.append(x)` 一个一个往末尾塞。
**为什么这里要把数全存下来**（`mean_se` 只存 Σx 和 Σx² 两个数）：画图要的是曲线上**每一个点**，不是一个统计量。画图是少数真的需要存全部数据的地方。

`phi   = []` 里多出来的空格只是为了三行的 `=` 对齐，Python 不在乎。抄不抄你定。

### 3.2 打开文件、读成一行一行

```python
    with open(path, "r", encoding="utf-8") as f:
        lines = f.readlines()
```

| 部分 | 意思 |
|---|---|
| `open(path, "r", ...)` | 打开文件。`"r"` = 只读。🔴 写成 `"w"` 会**先把文件清空**，csv 就没了 |
| `encoding="utf-8"` | 按 UTF-8 解码。Windows 上不写，默认按 GBK，碰到中文会乱码或报错 |
| `with ... as f:` | 把打开的文件叫 `f`；**缩进块一结束，文件自动关上**，中间出错也会关 |
| `f.readlines()` | 把整个文件读成一个**列表**，一行一个字符串，**每个结尾带着换行符 `\n`** |

读完以后：

```
lines[0] = 'k,z_lo,z_hi,z_mid,phi,err,R\n'                                     ← 表头
lines[1] = '1,0.000000,0.100000,0.050000,9.51532006e-01,1.73935836e-04,0.00018280\n'
...
```

`lines = ...` 写在 `with` 里面，`for` 写在外面：读完就关文件，处理在关了之后做。`lines` 已经在内存里了，关文件不影响它。

### 3.3 跳过表头，逐行处理

```python
    for line in lines[1:]:
```

`lines[1:]` 是**切片**：从下标 1 一直取到末尾，也就是「除了第 0 行（表头）全要」。
表头 `'k,z_lo,...'` 硬转 `float` 会当场报 `ValueError`，所以必须跳过。

> 你 10/8 问过切片 `[0:4]` 取几个：取下标 0、1、2、3 **四个**，右端不含。`[1:]` 右端省略 = 到末尾。

### 3.4 一行字符串 → 一个字符串列表

```python
        parts = line.strip().split(",")
```

从左往右读，**两步**：

| 步 | 结果（拿第 1 行数据举例） |
|---|---|
| `line` | `'1,0.000000,0.100000,0.050000,9.51532006e-01,1.73935836e-04,0.00018280\n'` |
| `.strip()` 去掉首尾空白（主要是结尾的 `\n`） | `'1,0.000000,0.100000,0.050000,9.51532006e-01,1.73935836e-04,0.00018280'` |
| `.split(",")` 按逗号切开 | `['1', '0.000000', '0.100000', '0.050000', '9.51532006e-01', '1.73935836e-04', '0.00018280']` |

🔴 `parts` 里**全是字符串**。`'0.050000'` 和 `0.05` 不是一个东西：字符串不能做加减、不能画图。

### 3.5 取三列，转成数，塞进列表

```python
        z_mid.append(float(parts[3]))
        phi.append(  float(parts[4]))
        err.append(  float(parts[5]))
```

- `float('0.050000')` → `0.05`：字符串转浮点数。`float('9.51532006e-01')` → `0.951532006`，科学计数法它也认。
- 下标对着第 1 节那张表数：z_mid 是 3、phi 是 4、err 是 5（**从 0 数**）。
- `phi.append(  float(...))` 括号后面的两个空格也只是为了对齐。

这一行跑完，第 1 行数据变成了：`z_mid[0] = 0.05`、`phi[0] = 0.951532006`、`err[0] = 0.000173935836`。

### 3.6 assert 和 return（学的时候认真看，默写时不写 assert）

```python
    assert len(z_mid) > 0, "csv 里一行数据都没读到（只有表头或文件为空）：%s  总行数=%d" % (path, len(lines))
    return z_mid, phi, err
```

- **这条抓什么**：读进来了但其实什么都没读到（文件是空的、只有表头）。不加的话，后面 `errorbar` 会画出一张空图，不报错。
- 消息里带了 `path` 和 `len(lines)`：响了以后，一眼就知道是哪个文件、有几行。
- `%s` 填字符串，`%d` 填整数。**两个值用括号包成一组** `% (path, len(lines))`（你的高频错「% 没把多个值包成一组」）。
- `return z_mid, phi, err`：一次返回三个，实际打包成一个元组；调用方 `z, phi, err = read_flux_csv(...)` 一次拆开（和 `mean_se` 一样）。

> 为什么不检查三个列表一样长？它们在同一个 `for` 里各 `append` 一次，长度**结构上**必然相等 —— 检查它是恒真 assert（你 9/18 那条「恒真 assert」）。

## 5. `ERR_SCALE` 和画布（第 29–31 行）

```python
ERR_SCALE = 1.0

fig, ax = plt.subplots(figsize=(7, 5))
```

- `ERR_SCALE`：误差棒放大倍数，平时 1.0。**9/8 的验法**：临时改成 100.0 跑一次，看误差棒是不是明显变长，再改回来。
  原因：SE 只有通量的万分之二，正常画出来短得看不见。「没见过它长出来的误差棒，不算画上了。」
- `plt.subplots(figsize=(7, 5))` 一次给两个东西：
  - `fig`：整张画布（最后存成 png 的就是它）
  - `ax`：一套坐标系（x 轴、y 轴，和画在里面的所有线）
  - `figsize=(宽, 高)`，单位英寸
- 🆕 **和 `plot_xs.py` 不一样的地方**：`plot_xs` 用 `plt.plot(...)`、`plt.xlabel(...)`，那套接口偷偷操作「当前那张图」；
  这里用 `ax.errorbar(...)`、`ax.set_xlabel(...)`，**每一句都说清楚画在哪套坐标系里**。
  第 9 课画「对拍曲线 + 残差」两张子图时，只有 `ax` 这套不会乱。**名字也不一样**：`plt.xlabel` 对 `ax.set_xlabel`，多一个 `set_`。

## 6. 循环：读一个 csv、画一条带误差棒的线（第 33–36 行）

```python
for path, label in CASES:
    z, phi, err = read_flux_csv(path)
    ax.errorbar(x=z, y=phi, yerr=[e * ERR_SCALE for e in err], label=label,
                marker="o", markersize=3, capsize=2, linewidth=1)
```

**`for path, label in CASES:`**：每一圈从 `CASES` 里取一个元组，**当场拆成两个名字**。第 1 圈 `path = ...flux_case1.csv`，`label = "case 1: ..."`。

**`ax.errorbar(...)` 的参数**：

| 参数 | 意思 | 这里的值 |
|---|---|---|
| `x=` | 横坐标列表 | 层中心深度 `z` |
| `y=` | 纵坐标列表 | 通量 `phi` |
| `yerr=` | **误差棒半长**：每个点往上、往下各画这么长 | `err` 逐个乘 `ERR_SCALE` |
| `label=` | 图例里这条线叫什么 | 从 `CASES` 拆出来的那个 |
| `marker="o"` | 每个数据点画个圆点 | |
| `markersize=3` | 圆点大小 | |
| `capsize=2` | 误差棒两端那条小横线的长度。0 就没有横线 | |
| `linewidth=1` | 连线粗细 | |

🆕 **`[e * ERR_SCALE for e in err]` —— 列表推导式**。读法：「对 `err` 里的每一个 `e`，算出 `e * ERR_SCALE`，排成一个新列表」。
为什么不直接写 `err * ERR_SCALE`：**列表乘数字不是逐个乘**。`[1.5, 2.5] * 2` 得到的是 `[1.5, 2.5, 1.5, 2.5]`（重复两遍），乘 1.0 直接报错。
（和你 10/8 写的 `[0.0]*n` 是同一个机制：`*` 对列表是「重复」。）

**误差棒画的是 ±1 SE**：每个点的竖线从 `phi − err` 到 `phi + err`。读图时说「误差棒是 1 倍标准误」，不是标准差。

## 7. 坐标轴、图例、网格、对数轴（第 38–43 行）

```python
ax.set_xlabel("depth (cm)")
ax.set_ylabel("flux (cm$^{-2}$ per source neutron)")
ax.set_title("Track-length flux in a 1D slab (N=1e6, seed=2026)")
ax.legend()
ax.grid(True, alpha=0.3)
ax.set_yscale("log")
```

| 行 | 做什么 |
|---|---|
| `set_xlabel` / `set_ylabel` | 轴标题，**写清楚是什么量 + 单位**。`cm$^{-2}$`：`^{-2}` 是数学模式里的上标，渲染成 cm⁻²。全用英文（默认字体显示不了中文，会变成方框） |
| `set_title` | 图标题。把 N 和种子写进去：别人看图就知道这张图怎么来的 |
| `legend()` | 收集所有带 `label=` 的线，画成图例。图例空 = `label=` 没给 |
| `grid(True, alpha=0.3)` | 淡网格。`alpha` 是不透明度：0 看不见，1 全不透明 |
| `set_yscale("log")` | **纵轴取对数** |

**为什么纵轴取对数**：case1 是纯吸收，通量按 `φ(z) ∝ e^(−Σt·z)` 衰减。两边取以 10 为底的对数：

```
log10 φ = 常数 − Σt · log10(e) · z = 常数 − 0.434 · Σt · z
```

是一条**直线**。所以对数轴上 case1 必须是直线，弯了就是错的 —— 这是看图就能用的一条判据。
⚠️ 图上量出来的斜率是 `−0.434 × Σt`（以 10 为底），不是 `−Σt`。拿 case1 前两层核一下：
`log10(0.861174525 / 0.951532006) / 0.1 = log10(0.905040) / 0.1 = −0.04333 / 0.1 = −0.4333`，Σt = 1.0 时就是 −0.434，对上了。

## 8. 存图、看图（第 45–46 行）

```python
fig.savefig(os.path.join(HERE, "lesson03_flux.png"), dpi=150, bbox_inches="tight")
plt.show()
```

- `dpi=150`：每英寸 150 像素，7 英寸宽就是 1050 像素。
- `bbox_inches="tight"`：裁掉四周多余的白边，不加的话轴标题常被切掉半截。
- 🔴 **`savefig` 必须在 `show` 前面**：关掉窗口后画布就清空了，再存会得到一张白图，而且不报错（`讲解_plot_xs.md` 第 7 段同一个坑）。
- `show()` 会让程序停在这一行，直到你关窗口。
- 用的是 `fig.savefig`（存这张画布）和 `plt.show()`（弹窗口）。`show` 没有 `fig.` 的版本，就写 `plt.show()`。
