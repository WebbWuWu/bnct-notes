## 1. `fly(p, xs, hist, rng, d, dz, NL, t_cut)` —— 飞一段（496–618 行）

**一句话**：抽一段飞行距离，按层拆开，每一层记「权重 × 路程 × 系数」，最后更新位置。**不改能量、不改方向**。

### 1.1 进来的东西

| 参数 | 是什么 |
|---|---|
| `p` | **粒子状态**字典：`z` 位置（cm）、`u v w` 方向余弦、`E` 能量（eV）、`wt` 权重、`t` 时间 |
| `xs` | `lookup_xs` 在**当前能量**查好的系数字典（见 1.2） |
| `hist` | **这条历史**的逐层计数器（见 1.3），每条新历史由 `start_history` 清零 |
| `rng` | 随机数发生器 |
| `d` / `dz` / `NL` | 板厚（cm）/ 层厚（cm）/ 层数 |
| `t_cut` | 时间截断；`None` = 不截断 |

**返回** `has_sign`：这一段是不是被时间截断了（`True` = 截断，`run_slab` 据此结束这条历史）。

### 1.2 `xs` 里取出来的 8 个系数（都是「每走 1 cm 记多少」）

| 名字 | 意思 | 单位 |
|---|---|---|
| `Sigma_t` | 总宏观截面 Σt = Σ 各核素 N·σ_tot | /cm |
| `B_reac` | D_B：B10 的 800、801 两支，各乘各自的 Q | eV/cm |
| `B_con` | D_B 对照：两支加起来 × 固定的 `Q_val` | eV/cm |
| `N_coe` | D_N：N14 (n,p) × Q | eV/cm |
| `a_coe` | 所有核素 (n,γ) 反应率之和 | /cm |
| `kerco` | **字典** {核素名: N·H(E)·BARN}，kerma 系数 | eV/cm |
| `gH_coe` | H1 (n,γ) 反应率 → 2.22 MeV γ 的个数 | /cm |
| `gB_coe` | B10 第 801 支反应率 → 0.478 MeV γ 的个数 | /cm |

### 1.3 `hist` 里取出来的计数器（都是长度 NL 的列表，一层一个数）

`track_h`（径迹长度 = 通量）· `B_r` · `B_c` · `N_ar` · `a_g` · `gH_h` · `gB_h` —— 和 1.2 的系数**一一对应**（`track_h` 对应系数 1）；
`kerma_h` 是**两层**：`kerma_h[核素名][层]`；
`tol_sigt_s`：这条历史累计的 Σt × 路程（方差统计用的一个数）。

### 1.4 分块

| 块 | 行 | 做什么（用到的变量） | 物理核心？ |
|---|---|---|---|
| ① 解包 | 500–520 | 从 `p` 取 5 个（E、w、wt、z、t），从 `xs` 取 8 个系数，从 `hist` 取 8 个计数器 | 记结构 |
| ② 抽距离 | 526–527 | `s = −ln(1 − ξ) / Sigma_t`（用 1 − ξ 防 ln 0）；`has_sign = False` | ✅ |
| ③ 时间截断 | 529–536 | 有 `t_cut` 时：这段要花的时间 `t1 = s / √E`；`t + t1 > t_cut` → 把 s 截短成 `(t_cut − t)·√E`，`has_sign = True`，`t = t_cut`；否则 `t += t1` | ✅ |
| ④ 终点 | 537–544 | 起点 `z0 = z`，终点 `z1 = z0 + s·w`；记账用的终点 `z_end` 夹在 [0, d] 里（出了板只记到边界） | ✅ |
| ⑤ `w == 0` | 546–560 | `seg = 0`；平行于层面飞时，整段 s 都记在起点层 `k0`（随机几乎走不到） | 记结构 |
| ⑥ 拆层循环 | 562–610 | `k0` 起点层、`k1` 终点层（= NL 时夹成 NL − 1）；笔尖 `cur`、当前层 `k`；**每一步**：出口边界 `k_o`（w > 0 是 (k+1)·dz，w < 0 是 k·dz）→ 这一步走到 `z_step` = 出口和 `z_end` 里近的那个 → 竖直距离 `dz_step` → **路程 = dz_step / \|w\|** → 8 种计数各加「wt × 路程 × 系数」（kerma 对每个核素一行）→ `seg += 路程` → `cur = z_step` → 到 `k1` 就 break，否则 k 加 1 或减 1；循环后 `expect = \|z_end − z0\| / \|w\|` | ✅ 最核心 |
| ⑦ 收尾 | 612–618 | 守恒检查 `seg ≈ expect`；`tol_sigt_s += Sigma_t × seg`；写回 `p["z"] = z1`（**是 z1 不是 z_end**：出了板的粒子位置在板外，`run_slab` 靠它判泄漏）、`p["t"] = t`；`return has_sign` | ✅ |

**最容易错的三处**：
- 路程是**斜着走的**，要除以 \|w\|；
- 出口边界的方向：w > 0 往深处走，出口在 (k+1)·dz；w < 0 往回走，出口在 k·dz；
- `kerma_h[核素][层]`：先核素、后层，和 `kerco[核素]` 配对。

## 2. `collide(p, xs, hist, tal, nuclides, order, rng, implicit, dz)` —— 撞一下（621–699 行）

**一句话**：选撞哪个核素；模拟模式抽是散射还是吸收，隐式模式只减权重；散射就用自由气体改能量和方向，并记 D_H。

### 2.1 进来的东西（和 `fly` 不一样的）

| 参数 | 是什么 |
|---|---|
| `tal` | **整个模拟**的计数：`n_i` 碰撞次数、`n_A` 吸收次数、`n_ki` 被轮盘赌杀掉的次数 |
| `nuclides` | 核素列表，每个是字典：`name`、`mts`（道号列表）、`dens`（数密度）、`awr`（A）、`kT`、`E`、`XS`… |
| `order` | 模拟模式抽道用的排序（隐式模式不用；进「精修清单」那条） |
| `implicit` | `True` = 隐式俘获 |

**返回**：`True` = 还活着（散射了）；`False` = 历史结束（吸收了，或被轮盘赌杀掉）。

`xs` 里这次用到的：`sig_ds[核素][道]`（各道微观截面，b）、`sig_al[核素]`（各核素宏观总截面 N·σ_tot，/cm）、`tot_ls[核素]`（各核素微观总截面）、`Sigma_t`。

### 2.2 分块

| 块 | 行 | 做什么（用到的变量） | 物理核心？ |
|---|---|---|---|
| ① 解包 | 625–634 | 从 `p` 取 E、u、v、w、wt、z；从 `xs` 取上面 4 个 | 记结构 |
| ② 份额 | 635–645 | `si[j] = Σ_j / Σt`（撞到核素 j 的概率，模拟模式用）；`pl = mts.index(2)` 找弹性道的位置 → `sig_s[j] = σ_el,j × N_j × BARN`（弹性宏观截面）；`sigma_s` 是总和；`share2[j] = sig_s[j] / sigma_s`（隐式模式用） | ✅ |
| ③ 模拟模式 | 646–655 | 抽核素 `jn`（`make_cdf(si)` + `find_cell`；只有一个核素就直接 0）→ 抽道 `k = sample_reaction(…)` → `is_scat` = 这个道是不是 MT=2 | 记结构 |
| ④ 隐式模式 | 656–672 | **存活权重** `wt *= sigma_s / Sigma_t`（吸收那一份直接从权重里扣掉）→ `wt < wt_lo`（0.1）就轮盘赌：`ξ < wt / wt_hi`（0.2）活下来、`wt = wt_hi`，否则 `n_ki += 1`、死 → 按 `share2` 抽核素 → `is_scat = True` | ✅ |
| ⑤ 写回权重 | 673 | `p["wt"] = wt` | — |
| ⑥ 散射 | 674–694 | `n_i`、`n_hist` 加 1；`E_be` 记下碰撞前能量；`awr` 是 `None`（老算例的假核素）→ 只换成各向同性方向；否则：A、kT → `y = √(E·A/kT)` → `sample_target` 抽靶核 `x1`、`mu_T` → `free_gas_kinematics` 出新 E 和方向；碰撞所在层 `k_hit = int(z / dz)`；**D_H 碰撞估计**：`D_H[k_hit] += wt × (E_be − E)`，按核素再记一份 `d_his[核素][k_hit]`；写回 E、u、v、w；`return True` | ✅ 最核心 |
| ⑦ 吸收 | 695–699 | `n_A`、`n_i`、`n_hist` 加 1；`return False` | 记结构 |

**最容易错的三处**：
- 隐式模式里**先减权重、再轮盘赌、再抽核素**，顺序不能换（换了随机数用量就变了，回归会挂）；
- 隐式模式抽核素用的是**弹性份额** `share2`，不是总截面份额 `si`：吸收已经从权重里扣掉了，剩下的一定是散射；
- D_H 记的是**碰撞前后能量差 × 权重**，在**碰撞点**那一层（`z` 不是飞行终点 `z1`：撞的时候粒子就在 z）。

⚠️ D_H 在 `collide` 里是**碰撞估计**；M2 的 kerma 在 `fly` 里是**径迹长度估计**。两个是同一个物理量（H 的反冲能）的两种估计法，期望值应该一样，只是涨落不同。
