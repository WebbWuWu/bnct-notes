## 0. 这个函数干什么（一句话）

中子撞上一个**正在热运动**的靶核（弹性散射），算出撞完以后的**能量和飞行方向**。
靶核跑多快、往哪跑（`x`、`mu_T`）已经由 `sample_target` 抽好，作为参数传进来；这个函数只做**几何**：拼向量 → 进质心系 → 转个方向 → 回实验室系。

```
sample_target(y, rng)  →  x, mu_T          （抽靶核：跑多快、和中子夹角多大）
free_gas_kinematics(E, u, v, w, A, kT, x, mu_T, rng)  →  E', u', v', w'   （本函数）
```

---

## 1. 🔴 先说单位：所有速度都用 `v_T` 量

`v_T` = 靶核的**最可几热速度** = √(2kT / M)，M = A × 中子质量。这个函数里**所有速度都是「几个 v_T」**，不是 m/s。

- 中子速度 = `y` 个 v_T，`y = √(E·A/kT)`（讲义 §2.4 推过）
- 靶核速度 = `x` 个 v_T（`sample_target` 抽的就是这个倍数）

所以最后换回能量要乘一个系数：

```
E' = ½ m_n (vl · v_T)² = ½ m_n · vl² · 2kT/(A·m_n) = (kT/A) · vl²
```

**这就是第 6 步 `El = (kT/A) * vl**2` 的来历。**

## 2. 变量表（按出场顺序）

### 2.1 参数（9 个，调用的地方传进来）

| 变量 | 含义 | 单位 / 范围 |
|---|---|---|
| `E` | 中子**碰撞前**的能量 | eV |
| `u, v, w` | 中子**碰撞前**的飞行方向（单位向量的 x、y、z 分量） | 无量纲，u²+v²+w² = 1。🔴 这个 `w` 是**方向余弦**，不是权重 `wt`（你混过） |
| `A` | 靶核质量 / 中子质量（库里的 `awr`） | H-1 是 0.999167，O-16 是 15.8575 |
| `kT` | 温度换成能量 | eV；294 K → 0.025301 |
| `x` | 靶核速率，几个 v_T | ≥ 0，`sample_target` 抽的 |
| `mu_T` | 靶核运动方向和中子飞行方向夹角的**余弦** | [−1, 1]，`sample_target` 抽的 |
| `rng` | 随机数发生器（调用方传进来，函数里用它抽两次方向） | `lcg` 对象 |

### 2.2 函数里造的变量

| 步 | 变量 | 含义 |
|---|---|---|
| 0 | `y` | 中子速率，几个 v_T（= √(E·A/kT)） |
| 1 | `vnx, vny, vnz` | **中子速度向量** = y × (u, v, w) |
| 2a | `k` | 重抽的轮数（只是计数，最多 100 轮） |

| 2a | `al` | 这个随机方向在中子方向上的**投影长度** = 两个单位向量的点乘 |
| 2a | `rx, ry, rz` | 随机方向**减掉**沿中子方向的那部分 → 剩下的部分**垂直于中子方向** |
| 2b | `e1x, e1y, e1z` | 把 r 除以自己的长度 → **垂直于中子方向的单位向量**（方位角是随机的） |
| 2c | `rbx, rby, rbz` | **靶核运动方向**（单位向量）：沿中子方向占 mu_T，垂直方向占 √(1−mu_T²) |
| 2d | `vbx, vby, vbz` | **靶核速度向量** = x × 靶核方向 |

| 6 | `El` | 散射后能量，eV = (kT/A) × vl² |

**名字的规律**（帮你记）：
- `vn…` = **v**elocity of **n**eutron；`vb…`、`rb…` 的 b = **靶**（bǎ）核；`vcm…` = **c**enter of **m**ass；`vncm…` = **n**eutron in **cm**；`vl…` = **l**ab
- 方向：输入 `u v w` → CM 里新方向 `u1 v1 w1` → 输出 `u2 v2 w2`（数字 = 第几个方向）
- 末尾 `x y z` = 向量的三个分量

## 3. 一组真实数字走一遍（就是 `check_fgk.py` 的第 0 组）

输入：H-1，`E = 0.0371 eV`，`A = 0.999167`，`kT = 0.025301`，方向 = (0.37, −0.48, 0.79) 归一化，`rng = lcg(9100)` 先抽靶核。

| 步 | 算什么 | 数字 |
|---|---|---|
| 入参 | (u, v, w) | (0.3716, −0.4821, 0.7934) |

| 0 | y = √(0.0371 × 0.999167 / 0.025301) | **1.2104** —— 中子只比靶核最可几速度快 21%，正是上散射最猛的区域 |
| 1 | 中子速度 = 1.2104 × (u, v, w) | (0.4498, −0.5835, 0.9604) |
| 2a | 第 0 轮抽到的随机方向 | (−0.5589, −0.6103, 0.5614) |
| 2a | al = 点乘 | 0.5320 |
| 2a | r = 随机方向 − al × (u, v, w) | (−0.7566, −0.3538, 0.1394)，长度 0.8468 ≥ 1e-6 → 一轮就跳出 |
| 2b | e1 = r / 0.8468 | (−0.8935, −0.4178, 0.1646)；和 (u, v, w) 点乘 = −8e-17 ≈ 0 ✓ 垂直 |
| 2c | 靶核方向 = −0.5460 × (u,v,w) + √(1 − 0.5460²) × e1 | (−0.9515, −0.0869, −0.2953)；长度² = 1.0 ✓；和中子方向点乘 = −0.5460 = mu_T ✓ |

| 3 | 质心速度 = (中子 + 0.999167 × 靶核) / 1.999167 | (−0.4957, −0.3577, 0.2567) |
| 4 | CM 里中子速度 = 中子 − 质心 | (0.9455, −0.2258, 0.7037)，**速率 vncm = 1.2001** |

自己用计算器核两步：
- 第 0 步：0.0371 × 0.999167 / 0.025301 = 1.46513，开根号 = 1.2104 ✓
- 第 6 步：0.025301 / 0.999167 = 0.025322；1.5381² = 2.3658；相乘 = 0.05991 ✓

## 4. 为什么 2a–2c 要这么绕？

**要做的事**：造一个单位向量，和中子方向的夹角余弦**正好是 mu_T**，绕中子方向转到哪个角度**随机**。

**做法**：
1. 先要一个**垂直于中子方向、方位随机**的单位向量 e1
2. 靶核方向 = mu_T × 中子方向 + √(1 − mu_T²) × e1
   —— 两个互相垂直的单位向量按 cos、sin 组合，结果自动是单位向量，和中子方向夹角的余弦自动是 mu_T（第 3 节第 2c 行两个 ✓ 就是在验这件事；原文紧跟着的那条 assert 也是）

**e1 怎么来**：随便抽一个各向同性方向，把它沿中子方向的分量减掉（`al` 就是那个分量），剩下的自然垂直于中子方向，而且方位是随机的；再除以长度变成单位向量。

**为什么要「长度 ≥ 1e-6 才跳出、否则重抽」**：万一抽到的随机方向几乎和中子方向平行，减完剩下的长度接近 0，再除以它就会把舍入误差放大成方向。这种情况概率约 1e-12，几乎碰不到，但碰到了要重抽。所以 `else:` 要和 **`for`** 对齐：**100 轮都没跳出**才 assert（今天下午你抄成了和 `if` 对齐，就是这里）。

**为什么不抽 φ、不造 e2**：e1 的方位本来就是随机的，等于已经抽过 φ 了（9/29 框架 ② 续，你定的乙）。
