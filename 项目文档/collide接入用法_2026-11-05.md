## 一、物理：撞一下以后，现在有三条路

散射时（`is_scat` 为真），按撞到的核素和能量分三条路，**从上往下，先满足哪条走哪条**：

| 路 | 什么时候 | 怎么算新能量、新方向 | 用几个随机数 |
|---|---|---|---|
| ① S(α,β) | `thermal` 开、撞的是 **H1**、E < 10 eV | `sample_thermal` 直接给 E′ 和**实验室系**的 μ；φ = 2π ξ；`rotate_dir` 转出新方向 | 3 + 1 = 4 |
| ② 旧的各向同性 | 核素没有 `awr`（只有假库的 O16 是这样） | 照旧 `isotropic_direction`，一字不动 | 不变 |
| ③ 自由气体 | 其余（H1 高于 10 eV、O16、B10 …） | 照旧 `sample_target` 抽靶核；**新**：`angle` 开、这个核素有表 → 先抽 μ_cm 再交给 `free_gas_kinematics` | 原来的 + 2（抽 μ_cm）+ 1（第 5 步的 φ） |

**为什么路 ① 不用抽靶核、不用换质心系**：S(α,β) 表本身就是「中子和整个水分子（含热运动、转动、振动）」散射以后的结果，直接给你**实验室系**里的 E′ 和 μ。自由气体那一套（抽靶核速度 → 质心系 → 换回来）是在**没有表的时候**自己模拟靶核运动；有表了就整个跳过。

**为什么路 ③ 的 μ_cm 要在质心系里转**：库里 MT=2 的角分布是**质心系**的（判据 A-4：`cm` 都是 True）。μ_cm 量的是「碰撞后中子在质心系里的方向」和「碰撞前中子在质心系里的方向」的夹角余弦。所以：
- 转的**轴**是碰撞前中子**在质心系里**的方向 = 第 4 步的 `vc` 除以它的长度 `s`，**不是**实验室系里的 `(u, v, w)`。这是最容易写错的地方：拿 `(u, v, w)` 当轴也能跑、不报错，但角分布就挂错了参照方向。
- 弹性散射在质心系里**速率不变**（能量守恒 + 动量守恒的结果），所以新的质心系速度 = 新方向 × 同一个 `s`；第 6 步「加回质心速度」一字不动 —— 这一步就是「换回实验室系」。
- 11/4 你算过：H1 质心系各向同性 → 实验室系 ⟨μ_lab⟩ = 2/3；O16 0.5 MeV 质心系前倾（μ̄_cm = +0.417）→ 每次碰撞丢的能量从 11.1% 降到 6.5%。路 ③ 就是让程序真的按这个前倾去抽。

**`D_H` 不用改**：三条路最后都是「新 E 存回 E」，`D_H += wt × (E_be − E)` 照记。路 ① 上散射时 E > E_be，记负数 —— 照记（框架 ⑨）。

**隐式俘获不用改**：选核素用的 `share2` 来自 `sig_ds`，`lookup_xs` 已经把 H1 的 MT=2 换成 S(α,β) 截面了，所以「撞的是 H1 的概率」已经跟着变了。

### 1. 从自己的另一个文件 import 函数
```python

from shop import price, discount      # 一行可以导好几个，逗号隔开
```

⚠️ 只导函数名，不加括号、不加 `.py`。

### 2. 参数默认值 `参数=None`、放最后（`lookup_xs` 那天讲过）
老的调用不传 → 自动是 `None` → 走老路。`run_slab` 第 795 行 `collide(...)` 的调用我最后再改，你写的时候它照样能跑。
`free_gas_kinematics` 也加一个：老的 `lesson07_check1.py` 第 80 行调用不传 `mu_cm`，照样各向同性。

### 3. `if / elif / else`：从上往下，**第一个成立的**才走
```python
if t < 0:
    s = "结冰"
elif t < 30:
    s = "舒服"
else:
    s = "热"
# t = −5：只走第一支（虽然 −5 < 30 也成立，但第一支已经走了，后面不看）
```

### 4. 字典里有没有这个键：`键 in 字典`
```python
stock = {"苹果": 12, "梨": 0}
"梨" in stock      # True（有这个键，值是 0 也算有）
"桃" in stock      # False
```
路 ③ 要判断「这个核素有没有角分布表」：`angle` 只有 `"H1"`、`"O16"`，撞 B10 时没有 → 照旧各向同性。
⚠️ 判断前 `angle` 本身得不是 `None`（`None` 不能用 `in`，会报 `TypeError`）→ 两个条件用 `and`，`is not None` 写前面（同 `lookup_xs`）。

### 5. `sample_thermal(thermal, E, rng)` → `(E_new, mu)`（你 11/2–11/3 写的）
- 给 S(α,β) 字典、入射能量、发生器；返回**两个**数：出射能量（eV）、**实验室系**散射角余弦。
- 内部用 3 个随机数（ξ₁ 选 E′ 并复用插 μ、ξ₂ 挑 k、ξ₃ 抹开）。
- 接返回值：`a, b = f(...)` 左边个数要和返回的个数一样（你犯过：`for` 接的变量个数 ≠ 元组长度）。
- 例子（和项目无关）：`q, r = divmod(17, 5)` → q = 3、r = 2。

### 6. `rotate_dir(u, v, w, mu, phi)` → `(u′, v′, w′)`（你 11/3 写的）
- 给**旧方向**的三个分量 + 夹角余弦 μ + 方位角 φ；返回新方向的三个分量。纯函数，不传 `rng`（框架 ⑦：φ 外面抽好再传）。
- 保证：新方向长度 1，和旧方向夹角余弦 = μ（T2 查过）。
- ⚠️ 它要的「旧方向」必须是**单位向量**（长度 1）。路 ③ 传 `vc` 之前要先除以 `s`。

### 7. `sample_elastic_mu(ang, E, rng)` → `mu_cm`（你 11/4 写的）
- 第一个参数是**一个核素**的那一层：`angle["O16"]`，**不是**整个 `angle`（你犯过两次：两层字典少一层下标）。今天用撞到的核素名 `nam` 去取。
- E 是**实验室系入射能量**（OpenMC 也是按这个选表），用 2 个随机数。

### 8. φ 的抽法：`2 * math.pi * rng.random()`
- `math.pi` = 3.14159…（`math` 文件顶上已经 import 了）。`rng.random()` ∈ [0, 1) → φ ∈ [0, 2π)。
- 你混过：φ 的范围 [0, 2π) vs μ 的范围 [−1, 1]；漏写 `rng.`。

### 9. 列表每个分量除以同一个数：列表推导
```python
prices = [12.0, 7.5, 30.0]
half = [prices[i] / 2.5 for i in range(3)]     # [4.8, 3.0, 12.0]
# prices / 2.5   ✗ 列表不能整体除（你 10/31 fgk 犯过 5 处：r/norm(r)）
```
`free_gas_kinematics` 里 `e1` 那一行（第 102 行）就是这个写法，照着它写 `dc`。

### 10. 元组也能用下标取
```python
pt = (0.6, -0.3, 0.74)       # 函数返回的 3 个数，没拆开接，就是一个元组
pt[1]                         # -0.3
```
`isotropic_direction` 和 `rotate_dir` 都返回 3 个数。第 6 步写的是 `q[i]`，所以第 5 步只要让 `q` 是「3 个数的元组或列表」，第 6 步**一个字不用改**。
