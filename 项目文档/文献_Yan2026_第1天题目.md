**先看记号**

| 记号 | 意思 |
|---|---|
| computational phantom（计算模体） | 电脑里的「人体模型」：每块地方是什么器官、什么材料。你的程序里那块 15 cm 水板，就是最简单的模体 |
| voxel-type（体素模体） | 把人体切成一样大的小立方块（体素），每块标一个器官号。你 M5 要做的「三维体素」就是这种 |
| mesh-type（网格模体） | 用曲面（多边形面片）描器官的外形，边界光滑、姿势可调 |
| tetrahedral（四面体模体） | 网格模体的内部再切成一堆四面体，粒子每次只跟所在四面体的 4 个面比距离 |
| external exposure / AP | 外照射；AP = 从身体前面平行照到后面 |
| Geant4 | 和 OpenMC、MCNP 同类的通用蒙卡程序（这篇里当基准，地位相当于你对拍用的 OpenMC） |
| photon–electron coupled | 光子-电子耦合输运（这篇算的是光子和电子，**不是中子**） |

**题 1（加速比到底比的是什么）**

摘要说：和 **Geant4 在 CPU 上单线程**跑的基准比，GPU 程序器官剂量的相对差大多在 5% 以内，计算时间缩短 **120 到 2700 倍**。

(a) 这个「120–2700 倍」里，其实混了两种不同的「快」：一种来自换了硬件（GPU vs CPU），一种来自换了程序（他们自己写的程序 vs Geant4，物理模型、截断参数、加速结构都可能不一样）。只看摘要这一句，你分得开吗？要只量出「GPU 本身带来的加速」，应该拿 GPU 程序和什么比？（提示：论文第 7–8 页说他们还写了一个东西，你先不用翻，猜一下是什么。）

(b) 对比对象是「单线程」CPU。一台服务器 CPU 通常有十几到几十个核。如果基准换成「同一台 CPU 开满 28 个线程」（假设完全线性加速），2700 倍会变成大约多少倍？120 倍呢？
你的技术报告第 1 节将来也要写 GPU 加速比，这道题算出来的东西，你写的时候要怎么避免被老师问住？

**题 2（为什么网格模体慢：拿你自己的程序比）**

Introduction 第 2 段：韩国汉阳大学的研究表明，**网格模体比体素模体慢 70–150 倍**；2014 年 Kim 等把网格切成四面体，速度提到和体素模体差不多。

(a) 先看你自己的程序。你的水板分 30 层、每层 dz = 0.5 cm。中子在 z = 7.3 cm 处、方向余弦 w = 0.6（往深处飞）：
  - 它在第几层（从第 0 层数）？你的程序是**怎么**算出来的？要不要把 30 层一层一层试一遍？
  - 它飞到这一层的下边界还要走多长路程？

(b) 推广到 M5 的三维体素：体素是 Δx × Δy × Δz 的小方块，模体左下角在 (x₀, y₀, z₀)。粒子在 (x, y, z)，写出它所在体素的三个下标怎么算（写公式，不写代码）。算一次要多少步？和体素总数有没有关系？

(c) 再看四面体模体：几百万个形状各不相同的四面体。粒子在 (x, y, z)，为什么**不能**像 (b) 那样一个公式算出「在第几个四面体里」？如果只能一个一个试，最坏要试多少次？（这就是第 2 天要读的「加速结构」要解决的问题。）
