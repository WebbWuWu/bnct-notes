## 一、物理：为什么换的是「H1 的 MT=2」、为什么只改这一处就够

- 自由气体把水里的 H 当成**自由的**氢原子，用的是 `H1.h5` 里的弹性截面（0.0253 eV 约 30.4 b）。实际上 H 绑在水分子上：能和分子转动、振动交换能量，截面大得多 —— `c_H_in_H2O` 在 0.0253 eV 给 **51.69 b**（讲义第 12 课 §1、§3）。
- `c_H_in_H2O` 只有一个「非弹」截面（`inelastic/xs`），它**整个替代** H1 的弹性散射（OpenMC 也是这么做：E < energy_max 时，H1 的弹性截面换成热散射截面，总截面跟着改）。
- 10 eV 以上：分子束缚的影响已经小到可以不管（10 eV 时 S(α,β) 20.54 b，自由 H 约 20.4 b，差不到 1%），照旧用 `H1.h5`。
- **为什么只改 `lookup_xs` 就够**：后面所有用到截面的地方都从它返回的字典里取：
  - `fly` 用 `Sigma_t` 抽飞行距离 → 跟着变大 → 热中子在水里走得更短 ✅
  - `collide` 用 `sig_ds[j][pl]`（pl = MT=2 的位置）算 `sig_s` → 选核素、隐式俘获扣的权重 σ_s/Σ_t 都跟着变 ✅
  - 俘获 MT=102（`gH_coe`、`a_coe`）不动 —— S(α,β) 只管散射 ✅
  - kerma 那一路的 H1 heating 不动 —— 近似候选（M3 框架「近似候选」第 2 条，量级 < 1e-4）

## 三、用到的写法（逐个，例子和项目无关）

### 1. 参数默认值 `参数=None`
```python
def greet(name, title=None):
    if title is None:
        return "你好，" + name
    return "你好，" + title + name
greet("陈")          # '你好，陈'          ← 不传就是 None，老的调用一个字不用改
greet("陈", "老师")   # '你好，老师陈'
```
**为什么要默认值**：`run_slab` 第 774 行 `lookup_xs(nuclides, idx, p["E"])` 今天不改，照样能跑；`thermal` 是 `None` 时和 M2 **逐位相同**（M3 框架 ①，明天 T4 用 `check_split.py` 查）。
默认值参数**放在最后**：`(nuclides, idx, E, thermal=None)`。

### 2. `is not None`
你代码里写的是 `!= None`（第 475、482、485 行），能用；判断「是不是 None」习惯写 `is None` / `is not None`。今天新写的用 `is not None`，老行不用改。

### 3. 三个条件同时成立：`and`
```python
if temp is not None and city == "南京" and temp < 5.0:
    print("加衣服")
```
**顺序有讲究**：`thermal is not None` 必须写在**最前面**。`and` 从左往右，前面是 False 就不往后算；要是 `thermal` 是 `None` 还先去算 `thermal["E_max"]`，会报 `TypeError: 'NoneType' object is not subscriptable`。

### 4. 列表的 `.index(值)` → 位置
```python
colors = ["红", "黄", "蓝", "绿"]
colors.index("蓝")     # 2（位置，不是值）
```
你犯过：`.index()` 返回位置 vs 值。今天用它找 MT=2 在 H1 的 `mts` 里排第几 → `pl`。

### 5. `np.interp(x, 横轴格点, 纵轴值)`
```python
hours = np.array([6.0, 9.0, 12.0, 15.0])
temps = np.array([11.2, 15.8, 21.4, 23.0])
np.interp(10.5, hours, temps)   # 18.6 （15.8 和 21.4 之间按 0.5 插）
np.interp(4.0,  hours, temps)   # 11.2 ← 比第一个格点小：取第一个值（不外推）
```
你犯过：少参数（11/1）。三个参数：要查的 E、`thermal["xs_E"]`、`thermal["xs_sig"]`（118 点，单位 b）。

### 6. 改列表里的一个元素：`列表[位置] = 新值`
```python
scores = [72.5, 88.0, 91.5]
scores[1] = 93.0         # 「改」第 1 个 → [72.5, 93.0, 91.5]
scores = 93.0            # ✗「换」：整个列表没了，变成一个数
```
你犯过：「换」当「改」（10/23 `kerma_sq=[…]`）。
⚠️ **改之前想一下：这个列表是不是别人的？** 改了一个和别处共用的列表，别处也会跟着变：
```python
base = [1.5, 2.5]
copy = base       # 不是复制，是同一个列表起两个名字
copy[0] = 9.9     # base 也变成 [9.9, 2.5]
```
你的 `Sig_j` 是 `sigma_at` 每次**新建**的列表（`xs_lookup.py` 第 59–61 行 `sig=[]` + `append`；低能外推那一支也是新建的），所以改它**不会**改坏 `nuclides` 里的截面库。我读过了，这一条你不用担心，只是要知道为什么安全。

### 7. 先改后用
`Sigma_j = dens × tot_j × BARN` 用到 `tot_j`。替换要放在**这一行前面**；放在后面的话，`tot_ls` 变了，`Sigma_t` 没变 —— 飞行距离用的还是旧截面，**不报错**（T5 专门抓这个）。
