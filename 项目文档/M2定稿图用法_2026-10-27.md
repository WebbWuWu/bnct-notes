### B. 算数

**④ `mean_se(s, sq, n)`（`mcstat.py` 第 3 行）—— 由 Σx、Σx²、n 算均值和 SE**
- 返回**三个**数：均值 x̄ = s/n；样本方差 σ₁² = n/(n−1) × (sq/n − x̄²)；标准误 SE = √(σ₁²/n)。
- 一步一步的例子：5 个数 2、3、5、7、4
  - s = 21，sq = 4 + 9 + 25 + 49 + 16 = 103，n = 5
  - x̄ = 21/5 = 4.2
  - σ₁² = 5/4 × (103/5 − 4.2²) = 1.25 × (20.6 − 17.64) = 1.25 × 2.96 = 3.7
  - SE = √(3.7/5) = √0.74 = 0.8602
- 用法：只要第 1、3 个 → `m, _, e = mean_se(...)`（`_` 是「这个我不要」，第 82 行就是这么写的）。
- 今天：s = 你的 `kerma_sum[核素][k]`，sq = `kerma_sq[核素][k]`，n = 100000。
- 坑：第 2 个返回值是**每条历史**的方差 σ₁²，不是 x̄ 的方差（x̄ 的方差 = σ₁²/n，开方才是 SE）。

**⑤ `math.sqrt(x)` —— 开方**

**⑥ `range(a, b)` —— 从 a 数到 b − 1**

**⑦ `%d` 拼字符串 + 列表推导 `[表达式 for 变量 in 范围]`**
- `"run_%d.txt" % 5` → `"run_5.txt"`（`%d` 的位置换成整数）。
- 列表推导：一行生成一个列表。

**⑧ `.append(x)` —— 往列表末尾放一个元素**

**⑩ 10 个种子求平均（你 M1 的 `merge_n`，第 33–45 行）—— 今天要在新文件里重写一个**
- 结构：外层循环每一层 i；内层循环每个种子 r，把均值加起来、把 SE **平方**加起来；内层结束后，均值和 ÷ n，√(SE 平方和) ÷ n，各 `append` 一个。
- 一步一步的例子：某一层 3 个种子，均值 4.0、4.4、3.9，SE 0.3、0.4、0.2
  - 平均 = (4.0 + 4.4 + 3.9)/3 = 12.3/3 = 4.1
  - SE = √(0.3² + 0.4² + 0.2²)/3 = √(0.09 + 0.16 + 0.04)/3 = √0.29/3 = 0.5385/3 = 0.1795
- 为什么是 √(Σse²) ÷ n，不是 ÷ √n：平均 = (x₁ + … + xₙ)/n，各种子独立 → 方差 = (se₁² + … + seₙ²)/n²，开方就是 √(Σse²)/n。（10 个 SE 差不多大时，它约等于单个 SE ÷ √10 —— 跑 10 倍粒子，误差小 √10 倍。）
- 坑：变量放在它所数的那一层循环开头（纪律 6）：「这一层的和」要在**内层循环之前**清零，不能放在函数开头。

**⑪ 比值和它的误差（你 M1 第 149 行）**
- r = a/b；σ_r = r × √((σ_a/a)² + (σ_b/b)²) —— 「**相对误差的平方相加**」。
- 来历：ln r = ln a − ln b，两边微分 dr/r = da/a − db/b；a、b 独立 → 相对误差的方差相加。
- 一步一步的例子：a = 5.0 ± 0.2，b = 4.0 ± 0.1
  - r = 5.0/4.0 = 1.25
  - 相对误差 0.2/5.0 = 0.04，0.1/4.0 = 0.025
  - √(0.04² + 0.025²) = √(0.0016 + 0.000625) = √0.002225 = 0.04717
  - σ_r = 1.25 × 0.04717 = 0.0590
- 坑：分子分母别拿反（主图是「你 ÷ OpenMC」，方案乙是「各向同性 ÷ 原版」）。

**⑫ 层中心深度 `(i + 0.5) × dz`（第 158 行）**
- 第 i 层（从 0 数）是 [i·dz, (i+1)·dz)，中点就是 (i + 0.5)·dz。
- 例：dz = 0.5 cm，i = 4 → 第 5 层 2–2.5 cm，中点 2.25 cm。

### ③ 一个程序出两张图

`plt.subplots(...)` 每调用一次，就新开一张图（返回一对新的 `fig, ax`）。两张图各存各的：

```python
fig1, ax = plt.subplots()          # 第一张：一格
ax.plot([1, 2, 3], [2, 4, 3])
fig1.savefig("a.png", dpi=150)

fig2, (bx1, bx2) = plt.subplots(2, 1, sharex=True)   # 第二张：上下两格
bx1.plot([1, 2, 3], [5, 1, 2])
fig2.savefig("b.png", dpi=150)

plt.show()                         # 最后一次性弹出两个窗口
```

注意两张图的变量名要不一样（`fig1` / `fig2`），否则第二张会把第一张的名字盖掉（又一次 `x` vs `x1`）。
