## 1. 物理：阈值为什么是 −Q·(A+1)/A，不是 −Q

**记号**：Q = 反应放出的能量（eV）；Q < 0 叫吸能反应，要从中子动能里「借」|Q| 才能发生。A = `awr`（靶核质量 / 中子质量）。

中子以动能 E 撞静止的靶核。**整个体系的动量不能凭空消失**，所以反应后的产物整体还要带着动量往前跑 —— 这部分动能是「借不出来」的。能拿去付 |Q| 的只有**质心系动能**：

```
E_cm = E × A / (A + 1)
```

（第 6 课质心系那一套：质心速度 = v_n / (A+1)，扣掉质心运动以后剩下的动能是 E·A/(A+1)。）
反应能发生 ⇔ E_cm ≥ |Q| ⇔

```
E_th = −Q × (A + 1) / A
```

**算例**（⚠️ Q 值待你读库核对）：O16 的 MT=51（第一激发态，非弹）Q ≈ −6.049 MeV，A = 15.858
E_th = 6.049 × (15.858 + 1)/15.858 = 6.049 × 1.0631 = **6.430 MeV**。比 |Q| 多 6% —— 靶核越轻，多得越多。
🔴 A vs A+1：写成 A/(A+1) 会得到 5.690 MeV，差 13%。这是你混名字清单里的老对。
