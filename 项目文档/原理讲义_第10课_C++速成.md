## 0. 一句话

**Python 是「边读边执行」，C++ 是「先整个翻译成机器码，再执行」。** 多出来的这一步（编译）就是 C++ 快几十到上百倍的来源，也是 CUDA 的前提 —— GPU 只认编译好的代码。

你现在的 Python 版 10 万条历史要 8–14 分钟（约 120–210 条/秒）。第 11 课把最简核心搬到 C++，第一件事就是测出 CPU 单线程的条/秒，那个数就是里程碑 2 加速比的**分母**。

## 1. 记号

| 记号 | 含义 |
|---|---|
| **源文件** `.cpp` | 你写的代码，相当于 `.py` |
| **头文件** `.h` | 只写「有哪些函数、长什么样」（声明），不写函数体。别的文件 `#include` 它就知道能调什么 |
| **编译器** `g++` | 把 `.cpp` 翻译成机器码的程序。在 WSL 里用 |
| **可执行文件** | 编译的产物，比如 `./hello`。运行它不再需要 `.cpp` |
| **声明 / 定义** | 声明 = 「有这么个函数，参数和返回值是这些类型」；定义 = 函数体本身 |
| **类型** | C++ 里每个变量**先说清楚是什么类型**再用：`int`、`double`、`std::uint32_t`… Python 里不用说 |
| **gdb** | 调试器：让程序停在某一行、看变量的值、一步一步走。和 VS Code 的 F5 是同一类东西 |
| `-g -O0 -Wall` | 编译选项：带调试信息 / 不做优化（gdb 里看到的顺序和你写的一样）/ 打开所有警告 |

## 2. 编译模型：三步

```
area.cpp ──编译──▶ area.o ─┐
                           ├──链接──▶ ./ring   （可执行文件）
main.cpp ──编译──▶ main.o ─┘
     ▲
     └── #include "area.h"（预处理：把头文件原样贴进来）
```

1. **预处理**：`#include "area.h"` 就是把 `area.h` 的内容复制粘贴到这一行
2. **编译**：每个 `.cpp` **单独**翻译成一个 `.o`。编译 `main.cpp` 时，编译器只需要知道 `ring_area` 的**声明**（从头文件来），不需要看到函数体
3. **链接**：把所有 `.o` 拼起来，把「`main` 里调用了 `ring_area`」接到「`area.o` 里的函数体」上

**两类错，长得不一样**：
- **编译错**（某一行写错）：报 `main.cpp:7:12: error: …`，有文件名和行号
- **链接错**（声明了但找不到定义，比如编译命令里漏了 `area.cpp`）：报 `undefined reference to 'ring_area(double, double)'`，**没有行号**

一行命令把三步都做了：
```
g++ -g -O0 -Wall main.cpp area.cpp -o ring
./ring
```

## 3. 和 Python 最不一样的五件事

| # | Python | C++ | 不注意会怎样 |
|---|---|---|---|
| 1 | 变量直接用 | 先写类型：`double r = 3.7;` | 编译错（好事，马上知道） |
| 2 | `7 / 2` 得 3.5 | `7 / 2` 得 **3**（两个整数相除 = 整数除法） | 🔴 **静默错**。要写 `7.0 / 2` |
| 3 | 缩进表示代码块 | `{ }` 表示代码块，每句以 `;` 结尾 | 漏 `;` 是编译错 |
| 4 | 整数没有上限 | `std::uint32_t` 只有 32 位，超过 2³² 会**自动回绕**（相当于自动 `% 2**32`） | 对 lcg 反而是好事（§5），但要知道它在发生 |
| 5 | `print(x)` 自动显示 | `std::printf("%.17g\n", x);` 要自己写格式 | 位数不够就看不出两边差在第 16 位 |

## 5. 为什么第一个搬进 C++ 的是 `lcg`

**判据最硬**：整数运算，Python 和 C++ 必须**逐位相同**。种子 2026 的前 5 个 `uint()`：

```
91264577  190675628  165328411  2847667390  2769032453
```

第 100 万个：`3107910954`（v4 第八节，10/18 晚 Claude 在 Python 里重新核过）。

**唯一的坑在乘法会不会溢出**：`a × state`，a = 1664525（约 2²¹），state < 2³²，乘积最大约 2⁵³。周二框架会问你选哪种：

| 方案 | 做法 | 代价 |
|---|---|---|
| 甲 | state 用 `std::uint32_t`，**靠自动回绕**代替 `% m` | 最短；但「取模」这一步在代码里看不见，读的人要知道回绕规则 |
| 乙 | state 用 `std::uint64_t`（放得下 2⁵³），显式写 `% 4294967296` | 和 Python 一行对一行，最好对拍；多一个常数 |

`random()` 返回 `state / 2³²`：整数转成 `double` 再除，两边都是同一种浮点数，**也应该逐位相同**。

## 6. 写新代码要用的用法清单（规则 13；周二写 lcg 前看，例子都和项目无关）

| 用法 | 小例子 | 一句话 |
|---|---|---|
| `#include <cstdio>` | 文件顶上一行 | 要用 `std::printf` 就得先 include |
| `#include <cstdint>` | 同上 | 要用 `std::uint32_t` / `std::uint64_t` |
| `int main() { … return 0; }` | 程序入口 | 相当于 Python 的 `if __name__ == "__main__":` 那一整块 |
| `std::printf("%u\n", n);` | `std::uint32_t n = 4096;` 打印 `4096` | `%u` 打无符号整数；打 `uint64_t` 用 `%llu` 并把变量写成 `(unsigned long long)n` |
| `std::printf("%.17g\n", x);` | `double x = 2.0 / 3.0;` → `0.66666666666666663` | 17 位有效数字，够判断逐位相同 |
| `struct` + 成员函数 | 见下面 `Counter` | Python 的 `class` 在 C++ 里可以写成 `struct` |
| 头文件里只写声明 | `double ring_area(double r_out, double r_in);` | 有分号、没有函数体 |
| `.cpp` 里写定义 | `double ring_area(double r_out, double r_in) { return 3.14159 * (r_out*r_out - r_in*r_in); }` | 和声明的类型、参数要一模一样 |
| `#pragma once` | 头文件第一行 | 防止同一个头文件被贴进来两次 |
| `类名::函数名` | `int Counter::step() { … }` | 在 `.cpp` 里写**成员函数**的函数体时要加 `类名::` |

`Counter` 的例子（和 lcg 无关：每次加 7、到 50 就绕回）：

```cpp
// counter.h
#pragma once
struct Counter {
    int value;                 // 相当于 Python 的 self.value
    explicit Counter(int start);   // 构造函数 = Python 的 __init__
    int step();                // 声明：返回 int、不带参数
};

// counter.cpp
#include "counter.h"
Counter::Counter(int start) : value(start) {}     // 冒号后面 = 把 start 存进 value
int Counter::step() { value = (value + 7) % 50; return value; }

// main.cpp
#include <cstdio>
#include "counter.h"
int main() {
    Counter k(13);                         // Python：k = Counter(13)
    for (int i = 0; i < 3; ++i) std::printf("%d\n", k.step());   // 20 27 34
    return 0;
}
```

⚠️ 成员函数里**直接写 `value`**，不用写 `self.value`（C++ 里叫 `this->value`，可以省略）。Python 那边你 10/11 把 `self.state` 写成过 `self.satet` —— C++ 里写错名字是**编译错**，不会悄悄新建一个属性，这是 C++ 帮你的地方。

## 7. gdb 最少要会的 8 个命令（周四水课读，周二周五实操）

| 命令 | 做什么 |
|---|---|
| `gdb ./ring` | 带着程序进 gdb |
| `break main` / `break area.cpp:5` | 在函数入口 / 某文件某行设断点 |
| `run` | 开始跑，停在第一个断点 |
| `next` | 走一行（遇到函数调用**不进去**） |
| `step` | 走一行（遇到函数调用**进去**） |
| `print r_in` | 看变量的值 |
| `watch value` | 这个变量一变就停下 —— 抓「状态不前进 / 被意外改掉」最好用 |
| `backtrace` / `quit` | 看是谁调到这里的 / 退出 |

编译时**必须带 `-g -O0`**，不然 gdb 里看不到变量名、行号也会乱跳。
