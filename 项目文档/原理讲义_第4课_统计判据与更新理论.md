## 一、为什么蒙特卡洛必须报误差棒

### 1.1 两条定理

MC 的合法性只靠两条定理。

**大数定律**:独立同分布样本 `x_1 … x_N`,样本均值 `x̄` 收敛到真实期望 `μ`。
→ 这条保证 MC **能**算对。

**中心极限定理(CLT)**:当 N 足够大,

```
x̄ ≈ 正态分布( 均值 μ , 标准差 σ/√N )
```

→ 这条告诉你 **离对还有多远**,而且给出了那个距离的**分布**。

**没有第二条,MC 就只是"跑了很多次然后信它"。** 误差棒不是装饰,它是 MC 唯一的可信度来源。

### 1.2 三个量,别混

| 量 | 符号 | 回答什么问题 | 随 N 怎么变 |
|---|---|---|---|
| 方差 | `var` | **一个样本**有多散 | **不变**(N 大只是估得更准) |
| 标准差 | `σ = √var` | 同上 | 不变 |
| **标准误** | `SE = √(var/N)` | **均值**离真值多远 | **∝ 1/√N** |

`Var(x̄) = Var(x)/N` —— 独立样本平均之后方差缩小 N 倍。开根就是 SE。

**判据永远用 SE,不用 σ。** 你判的是均值准不准,不是单个样本散不散。

> lesson03 的 bug 10 就是这个:误差公式少了 `/N`,报的是 σ 不是 SE,误差棒大了 141 倍。

### 1.3 为什么是 N/(N−1)(贝塞尔修正)

代码里写的是

```python
var = N/(N-1) * (x_sq/N - mean**2)
```

`x_sq/N − mean²` 这一项等于 `(1/N)·Σ(xᵢ − x̄)²`。

问题在于:`x̄` 是**从这批数据里算出来的**,它天然贴着这批数据。用它当中心,平方和会**系统性偏小**。可以严格证明

```
E[ Σ(xᵢ − x̄)² ] = (N−1)·σ²      ← 不是 N·σ²
```

少的那个 1 叫**自由度损失**:N 个数,估计了 1 个参数(均值),只剩 N−1 个自由度。所以除以 N−1 才无偏。乘 `N/(N-1)` 就是把 `/N` 改成 `/(N−1)`。

N=10⁶ 时这个修正只有百万分之一,**但它是免费的,而且提醒你"自由度"这件事**——卡方检验里同一个概念会以 M−1 的形式再出现。

### 1.4 灾难性相消(12 月要换 Welford 的理由)

`x_sq/N − mean²` 是**两个大数相减得小数**。当 `Var(x) ≪ E[x]²` 时,两项前几位完全相同,相减后有效位大量丢失,结果可能变成**负数**,`sqrt` 直接 `math domain error`。

> 9/2 bug 9、bug 10,9/4 bug C9、C10,全是这个。
> A 扫描到 A=10⁸ 时 `E[x²]` 公式返回 0 也是这个。

真实程序用 **Welford 在线算法**:一遍扫描、数值稳定、不存列表。第 8 周换。

## 二、判据的四种强度(核心方法论)

**同一个物理量,判据强度取决于你拿它对哪个公式。** 强度不能混,混了要么永远通过,要么永远失败。

| 强度 | 用在哪 | 容差 | 例子 |
|---|---|---|---|
| **① 恒等式** | 两个表达式在数学上严格相等 | `1e-12`,或由量级导出的 `abs_tol` | 两种写法算同一个 lethargy;标度不变性逐位相同 |
| **② 整数计数** | 计数必须精确相等 | `==` | 直方图总数 = N |
| **③ 统计量** | 实测均值 vs **正确**的解析期望 | `3·SE` | ξ、⟨μ_lab⟩、Wald、renew |
| **④ 工程估计 / 普适界** | 实测 vs **已知有偏**的近似公式 | 由模型误差定,不由 SE 定 | naive 慢化公式 |

### 2.1 什么时候不能用 3σ

看 4b:

- 统计误差 `n_se ≈ 0.01` 次碰撞(相对 0.05%)
- 模型误差:H 偏 **5.5%**,C 偏 **0.6%**

模型误差是统计误差的 **110 倍**。拿 3σ 判 naive,等于用 0.05% 精度的尺子去量一个已知偏了 5.5% 的东西——**必然失败,而且每次都失败**。那不是测试,是保证报错。

> **工程判据的容差不是误差棒,是模型误差预算。**
> 它必须 **> 已知模型误差**(否则永远炸),同时 **< 真 bug 造成的偏差**(否则什么都抓不到)。

### 2.2 判据必须标度不变

> **验证的判据只依赖被验证的物理,不依赖你今天随手设的参数。这是"验证"和"对答案"的区别。**

三次应用:

1. 9/2:`Σt=1,d=2` 与 `Σt=2,d=1` 通量表逐行相同 —— 一切只依赖光学厚度 `Σt·z`
2. 9/4:`E=1.0` 与 `E=2.0e6` 输出逐位相同 —— 累加器里装的是无量纲比值
3. 9/5:`E0=1.0` 与 `E0=2.0e6`,4a 输出逐位相同 —— `ln(E0/E_50)` 里 E0 约掉

**推论(4b 的判据形状)**:相对偏差 `⟨R⟩/(L/ξ)` 里含 `L = ln(E0/E_th)`,那是你随手设的能量范围。换 14.1 MeV 源,`L` 变大,相对偏差自动缩小,容差就失效了。

而**绝对偏差(以碰撞数为单位)与 L 无关**:

```
⟨n⟩ − L/ξ = E[x²]/(2ξ²)      只依赖 A
```

所以 4b 的判据写成**差**,不是**比**。

### 2.3 一条 assert 要有两个独立算出来的量

抄同一个表达式 = 同义反复。写完必须问两句:

- **什么样的 bug 会让它失败?** 答不上来就是废的。
- **什么样的错误能从它底下溜过去?**

> **实例(9/5 的活教材)**:`r50_sum` 初始化写进循环体内,和 lesson03 的 `v_sum` bug 一模一样。
> lesson03 那次判据是 `|x|/N < 3·|x|/N`,两边同源 → **恒真,静默通过两天**。
> 今天判据是 `|r50_mean − 50ξ|`,右边是独立的解析值 → **当场炸**。
>
> **同样的手滑,判据写对了就抓得住,写错了就藏两天。**

## 三、卡方检验

### 3.1 公式从哪来

M 个箱,每箱期望计数 `E_j = N/M`。每箱的实际计数 `O_j` 近似服从泊松/二项分布,**泊松分布的方差等于均值**,所以第 j 箱的标准差 ≈ `√E_j`。于是

```
(O_j − E_j) / √E_j   ≈ 标准正态
```

把 M 个这样的量平方求和:

```
χ² = Σ_j (O_j − E_j)² / E_j
```

**分母是 E_j 而不是别的,就是因为泊松的 σ² = 均值。**

### 3.2 自由度为什么是 M−1

M 个计数不是独立的,它们有一个约束:`Σ O_j = N`。知道前 M−1 个就能推出最后一个。**估计了 1 个参数(总数),损失 1 个自由度** —— 和贝塞尔修正的 N−1 是同一件事。

判据 `43.82` = 自由度 19 的 χ² 分布的 **0.999 分位数**,即误报率 0.1%。

### 3.3 为什么不逐箱做 3σ:多重比较

20 个独立 3σ 测试,每个误报率 0.27%,"至少一个误报"的概率

```
1 − 0.9973²⁰ ≈ 5.3%
```

**每 19 次就假警报一次。** χ² 把 20 个数压成 1 个统计量,只判一次,误报率 0.1%。

代价:χ² 只说"整体不对",不说哪个箱不对。**真实程序两个都做**——先 χ² 判整体,炸了再逐箱看。

### 3.4 卡方的盲区

χ² 看的是**边缘分布的形状**。它**看不见相关性**:把每次的 `μ_cm` 复用同一个随机数,分布对、卡方过,但样本之间相关。

抓相关性要靠方差恒等式(见 4.3)。

> **每条验证覆盖哪几行代码?剩下哪几行还没人管?**
> `scatter()` 有两行公式。验证 1/2/3 全部只验能量比那一行;`mu_lab` 那行在验证 5 写出来之前**零覆盖**。

## 四、慢化的数学:Wald 恒等式与更新理论

### 4.1 换变量:把乘变成加

中子能量是**连乘**的:`E_n = E_0 · r_1 · r_2 ⋯ r_n`。连乘的期望没法叠加,而且 A=1 时 50 步就掉到 10⁻²² 量级。

定义**勒让德变量(lethargy)**:

```
u = ln(E_0 / E)          E 越低，u 越大
```

每次碰撞让 u 增加

```
x_k = ln(E_{k−1}/E_k) = −ln r_k       独立同分布，⟨x⟩ = ξ
u_n = x_1 + ⋯ + x_n                   独立同分布的和
```

> **只有对数是可加的。这就是核工程用 ξ 而不用 ⟨E′/E⟩ 描述慢化的全部理由。**
> MCNP 内部记的就是 u。

**ξ 和 E[x²] 的解析值**(`r ~ U(α,1)`,用 `∫ln r dr = r(ln r −1)`、`∫(ln r)² dr = r[(ln r)²−2ln r+2]`):

```
ξ    = E[x]   = 1 + α·lnα/(1−α)                              α=0 时取 1
E[x²]         = [ 2 − α·((lnα)² − 2lnα + 2) ] / (1 − α)      α=0 时取 2
```

⚠️ **两个都要单独处理 α=0**,因为 `α·lnα` 和 `α·(lnα)²` 在 Python 里是 `0·(−inf) = nan`,不是 0。
⚠️ **E[x²] 在 α=0 的极限是 2,不是 0** —— 趋于 0 的是 `α·(lnα)²` 那一项,不是整个分子。

### 4.2 Wald 恒等式

`n` 固定时:`⟨u_n⟩ = n·ξ`。**只用到期望的线性性,不需要独立性。**

`n` 是随机停止时刻时(Wald 恒等式本体):

```
⟨u_n⟩ = ⟨n⟩ · ξ
```

要求 `n` 是**停止时刻**(是否在第 k 步停,只能依赖前 k 步的信息)且 `E[x] < ∞`。慢化到热能满足这两条。

### 4.3 方差恒等式:唯一能看见相关性的检验

```
Var(x_1 + ⋯ + x_n) = n · Var(x)       ⟸ 仅当各项不相关
```

均值恒等式对相关样本照样成立,**方差恒等式不成立**。所以

```
Var(u_50) / (50 · Var(x))  ≈ 1
```

是验证 1/2/3/5/4a 之外**唯一**能抓住"随机数复用/相关抽样"的判据,而且左右两边你都已经算过了,代价只是一次除法。

容差:`SE(s²)/s² ≈ √(2/N)`。N=50000 → 0.63%,3σ 带宽 ±1.9%。**拍 ±3%,不能拍 ±5%(那是 8σ,基本什么都抓不到)。**
要写成真 3σ 得再累加四阶矩:`SE(s²) = √((μ₄ − σ⁴)/N)`。

### 4.4 naive 和 renew

**naive(教科书公式)**:假装每次碰撞**恰好**降 ξ。

```
n ≈ L / ξ ,      L = ln(E_0/E_th)
```

**它错在哪:每次降多少是随机的,而且最后一次会冲过头。**

**renew(严格版)**:停止时 `u_n` 不等于 L,它跨过去了:

```
u_n = L + R ,      R ≥ 0  叫超越量 (overshoot)
```

代入 Wald:

```
⟨n⟩ = ( L + ⟨R⟩ ) / ξ
```

**naive 就是把 ⟨R⟩ 扔掉的 renew。差的那一项就是超越量,别的什么都没差。**

### 4.5 ⟨R⟩ 是多少:检查悖论

直觉说"平均跨过半步",`⟨R⟩ = ξ/2`。**错的。** 正确答案是

```
⟨R⟩ = E[x²] / (2·E[x]) = E[x²] / (2ξ)
```

两者只在 x 是常数时才相等。

**为什么**:跨过 L 的那一步不是随机抽的一步 —— **长的步更容易盖住 L**。你落在哪个区间上,概率正比于区间长度,所以你看到的那一步比典型的一步长。这叫**检查悖论**(inspection paradox),等价说法是"平稳超越分布"的密度 `f_e(r) = P(x>r)/E[x]`。

**A=1 的检验**:`x ~ Exp(1)`,指数分布**无记忆** —— 不管走到哪,剩下要走的还是 Exp(1)。所以 `⟨R⟩ = 1`,**整整一步,不是半步**。公式给 `2/(2·1) = 1` ✓

换成碰撞数:

```
⟨n⟩ − L/ξ  =  E[x²] / (2ξ²)        只依赖 A，不依赖 E_0 和 E_th
```

### 4.6 超越量的普适界 [2/3, 1]

| A | α | ξ | E[x²] | 超越量(碰撞数) |
|---|---|---|---|---|
| 1 | 0 | 1.000000 | 2.000000 | **1.000000** |
| 2 | 0.111111 | 0.725347 | 0.847219 | 0.805145 |
| 9 | 0.640000 | 0.206601 | 0.059118 | 0.692505 |
| 12 | 0.715976 | 0.157769 | 0.034142 | 0.685823 |
| 56 | 0.931056 | 0.035293 | 0.001671 | 0.670663 |
| 238 | 0.983334 | 0.008380 | 0.000094 | **0.667602** |

**上界 1**:A=1,`x ~ Exp(1)`,无记忆。
**下界 2/3**:A→∞,α→1,`x ≈ 1−r` 近似均匀分布,`E[x²]/(2ξ²) → (4ξ²/3)/(2ξ²) = 2/3`。
中间单调递减,**没有第三种情况**。

所以 4b 的判据可以完全不含任何 A 专属的数字:

```
2/3 − 3·n_se  ≤  n_mean − L/ξ  ≤  1 + 3·n_se
```

**判据里没有"答案",只有普适常数。**

## 五、物理:这一课真正的结论

### 5.1 教科书公式在 BNCT 最需要它的地方最不准

naive 对碳错 0.6%,对氢错 **5.5%**。

**核越轻,教科书公式越不准** —— ξ 越大 ⟹ 单步越粗 ⟹ 超越量占总 lethargy 的比例越高。

而 BNCT 打的是**富氢的人体组织**。那个每本教科书都印的 `n ≈ ln(E_0/E_th)/ξ`,**恰恰在 BNCT 最需要它的地方最不准**。

### 5.2 三件事叠加 = 为什么要 GPU(完整版)

人体富氢,于是同时发生三件事:

| | 数值(A=1) | 后果 |
|---|---|---|
| `c = Σs/Σt` 接近 1 | 平均碰撞数 ~ 1/(1−c) 暴涨 | 每条历史很长 |
| `α = 0` | 一次可损失**全部**能量 | 能量降落剧烈、方差大 |
| `⟨μ_lab⟩ = 2/3` | 强前向偏置 | 穿透比各向同性假设更深 |

**三件事叠加,没有任何解析近似能算准剂量深度分布。** 而且上面 5.1 刚证明了连最基本的慢化碰撞数估计都错 5.5%。

`Σ_tr = Σ_t(1−⟨μ⟩)`,`D = 1/(3Σ_tr)` —— ⟨μ⟩ 直接进扩散系数。

### 5.3 本课模型的边界(面试必答)

`E′/E` 与 E 无关,只在**靶核静止**假设下成立。中子降到 `kT ≈ 0.025 eV` 附近时靶核热运动不可忽略,会发生**上散射** —— 而 BNCT 关心的恰恰就是这个能区。

真实程序在 **~4 eV 以下必须改用 S(α,β) 热散射律(ENDF MF=7)**。

另外 14.1 MeV 的 DT 中子在 CM 系是**各向异性**的(高能下 s 波不再主导),要从 **ENDF MF=4** 读角分布。本课的各向同性 CM 假设到聚变算例就不成立了。
