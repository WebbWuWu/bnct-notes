文件 my_code\lesson07_freegas.py · 2026-10-23 拆分后的版本（行号以 10/23 18:10 那一版为准，加 kerma 以后会往下移）· 用途：每天读一遍，面试时能从头讲到尾

两分钟口述版（先背这段）

我的程序模拟的是：一块 15 cm 厚、分成 30 层的平板模体（M1 是软组织，M2 起是水加 15 ppm 的 10B），京都大学 KUR 的 BNCT 束流从表面垂直射入。我用连续能量的 ENDF/B-VIII.0 截面库，一个中子一个中子地跟踪，从出生跟到它漏出、被吸收或被轮盘赌杀掉，统计每一层的通量、硼剂量、氢反冲剂量和 (n,γ) 反应数。

主函数 run_slab 只负责调度，具体工作交给 8 个小函数：开工前查一次核素下标、开一本总账；每条历史先从源出生；每一步先在当前能量查截面，再飞一段并按层记径迹，然后判断有没有漏出，没漏出就撞一下（隐式俘获加自由气体散射）；历史结束时入账，最后对三条总账、交出结果。

拆分时我先用原程序存了 5 组基准，每拆一块都用同一个种子重跑，28 个结果必须逐位相同，并且故意把两个随机数的顺序对调过一次，确认这个检查会报错。

1 · 程序在算什么

项值
几何一维平板，厚 d = 15 cm，NL = 30 层（dz = 0.5 cm）；中子从 z = 0 出生，方向 (0, 0, 1) 垂直入射；两侧都是真空（漏出就不回来）
材料M1：ICRU-44 软组织（H、C、N、O）+ 15 ppm 10B，ρ = 1.06；M2 起：水 + 15 ppm 10B，ρ = 0.998，294 K
源KUR 临床束流三群：热 3.72% / 超热 90.46% / 快 5.82%；超热段按 1/E 分 8 箱；热群下限 0.01 eV，快群上限 2 MeV
截面LANL lib80x（ENDF/B-VIII.0）HDF5，线性插值；低于表下限按 1/v 外推
物理自由气体热运动（有上散射）；质心系各向同性弹性散射；隐式俘获 + 轮盘赌
输出每层的通量（径迹长度）、DB（逐道 Q 值 / 常数 Q 对照）、DN、(n,γ) 反应数、DH（碰撞估计器，总的 + 按核素），每样都有 sum 和平方和 → 均值和标准误

2 · 调用顺序和数据怎么流

run_slab(N, seed, d, nuclides, E_src, order, z_src, t_cut, implicit, NL, src) ├─ 入口检查（3 条 assert） ├─ idx = prepare_nuclides(nuclides) 开工前查一次下标 → idx 只读 ├─ rng = lcg(seed)；有源表就建 cdf ├─ tal = make_tallies(nuclides, NL) 整个模拟的总账本 → tal 只往里加 ├─ 对每条历史 i = 0 … N−1： │ p, hist = start_history(...) 中子出生；这条历史的小账本清零 │ 最多 Max = 10000 步： │ xs = lookup_xs(nuclides, idx, E) 在当前能量查好截面和系数 │ has_sign = fly(p, xs, hist, ...) 飞一段，按层记径迹 │ z < 0 → 反射；z > d → 透射；被截断 → 停 （记进 tal，这条历史结束） │ collide(p, xs, hist, tal, ...) 撞一下；返回 False = 吸收 / 被杀 │ end_history(tal, hist, ...) 小账本入总账（sum 和 sq） └─ return finish(tal, N, dz) 对三条总账，交出 28 个键

p粒子状态：z u v w E wt t（在哪、往哪飞、多少能量、多少权重、飞了多久）  hist这条历史的计数，每条历史开头清零  tal整个模拟的计数  idx核素下标，只读

记一句：idx 只读，tal 只往里加；p、hist、tal 都是在函数里「改」，不是「换」。

3 · 八个函数逐个讲

①prepare_nuclides(nuclides) 第 205 行

开工前查一次下标。算剂量要用几个特定的反应道：B10 的 800、801（(n,α) 到 7Li 基态 / 激发态两支）、N14 的 600（(n,p)），以及每个核素的 102（(n,γ)）。这个函数先查出「B10 是第几个核素、它的 801 是第几个道、Q 值多少」，装进字典 idx。之后每一步直接拿下标用，不用每步都去列表里找一遍。

交出idx：9 个键，材料里没有的核素记 None（M2 的水里没有 N14）

②make_tallies(nuclides, NL) 第 240 行

开一本整个模拟的账本 tal。里面记三类东西：

  • 结局计数：透射 n_T、反射 n_R、真吸收 n_A、轮盘赌杀掉 n_ki、时间截断 nt_cut、走满步数 n_sd / n_stuck；碰撞总数 n_i；透射、反射的权重和
  • 逐层的 sum 和 sq：通量、DB（Br 逐道 Q、Bc 常数 Q）、DN、(n,γ)、DH（总的 + 按核素的 sigma_x）
  • 「验证 B」总账：每条历史「∫Σt dl − 实际碰撞次数」的和与平方和

为什么每样都记 sum 和 sq：每条历史是一个独立样本。有了 Σx 和 Σx2，就能算出均值 x̄ 和标准误 SE = √(σ12/N)（第 4 课）。

③start_history(...) 第 394 行

一个中子出生。位置 zsrc，方向 (0, 0, 1)，权重 1，时间 0。能量有两种取法：单能；或者从 KUR 源表里抽，先按份额抽一个能箱，再在箱内按 ln E 均匀抽（sample_E_table）。同时给这条历史开一本自己的小账本 hist，每条历史开头清零（变量放在它所数的那一层）。

交出p（粒子状态）、hist（这条历史的计数）

④lookup_xs(nuclides, idx, E) 第 424 行

在当前能量查表。中子飞行中能量不变，所以每一步只查一次。

  • 每个核素每个道的微观截面 σ（单位 b，一个核）：线性插值，低于表下限 E[0] = 1e-5 eV 时按 1/v 外推（sigma_at_ext）
  • 宏观截面 Σj = Nj·σtot,j（单位 /cm，每走 1 cm 撞这个核素的概率）和总截面 Σt = ΣΣj
  • 「每走 1 cm 记多少」的系数：硼 B_reac = NB(σ800Q800 + σ801Q801)，氮 N_coe，(n,γ) a_coe = Σ Njσ102,j

M2kerma 系数 Ni·Hi(E)（H = MT=301）就加在这里。

⑤fly(p, xs, hist, rng, d, dz, NL, t_cut) 第 458 行

飞一段。

  • 抽飞行距离 s = −ln(1−ξ)/Σt。写 1−ξ：random() 在 [0,1) 里，ξ 能取到 0 而 1−ξ 永远大于 0，取对数不会炸
  • 开了时间截断（第 7 课看某一时刻的能谱用）：超过截止时刻就只飞到截止那一刻
  • 新位置 z + s·w，夹在板内；把这段路按层拆开，每穿过一层就在那层记「权重 × 这层里的路程 × 系数」。这是径迹长度估计器：不用撞，飞过就记
  • 核对：各层路程之和 = 整段路程（assert）；累计 Σt×路程，给「验证 B」用
改p 的 z、t；hist交出这一段是不是被截断了

M2kerma 按核素记账加在这里 · M5三维只改这个函数

⑥回到 run_slab：判结局

z < 0 是从表面反射出去，z > d 是从背面透射，被截断就停在截止时刻。三种都记进 tal，这条历史结束。结局放在总调度里，一眼能看全。

⑦collide(p, xs, hist, tal, nuclides, order, rng, implicit, dz) 第 569 行

撞一下。撞哪个核素按宏观截面的占比抽（Σj，不是按数密度 N）。

  • 模拟模式：核素按 Σj/Σt 抽；再按各道截面占比抽反应道（sample_reaction，道按 0.0253 eV 截面从大到小排，平均 1 次左右就抽中）。散射就继续；吸收就结束
  • 隐式俘获模式：不真吸收，权重乘「不被吸收的概率」Σs/Σt，一定散射，核素按散射截面份额抽。权重 < 0.1 时轮盘赌：以 wt/0.2 的概率活下来、权重提到 0.2，否则杀掉。活下来的期望权重 = (wt/0.2)×0.2 = wt，无偏，又不用一直跟着权重很小的中子
  • 散射 = 自由气体：先抽靶核的热运动（sample_target，舍选法），再在质心系各向同性散射、变回实验室系（free_gas_kinematics）→ 新能量和方向。热中子能被「踢」得更快（上散射），靠的就是这一步
  • DH 碰撞估计器：wt × (散射前能量 − 散射后能量) 记在碰撞所在那一层，总的一份、按核素一份
改p 的 E、u、v、w、wt；hist；tal交出还活着没有（False = 吸收或被杀）

M3S(α,β)、真实角分布改在这里

⑧end_history(tal, hist, nuclides, NL) 第 650 行

一条历史结束，入账。小账本每一层加进总账的 sum，平方加进 sq。「验证 B」：这条历史的 ∫Σt dl − 碰撞次数，期望为 0，也入账。

⑨finish(tal, N, dz) 第 305 行

收尾，对总账。三条总账必须对上：

  • 「验证 B」总账闭合（飞行距离抽样和碰撞计数是一致的）
  • 各种结局条数之和 = N（一条历史不漏、不重复）
  • 截断时刻记下的能量条数 = 被截断的历史数

然后拼出 28 个键的返回字典，这是 run_slab 对外的「说明书」。lesson08_dose、lesson09_* 都靠这些键名。

5 · 面试可能追问（自己先答，再看答案）

问答（要点）
为什么写 −ln(1−ξ)，不写 −ln ξ？两者同分布；但 ξ ∈ [0,1) 能取到 0，ln 0 = −∞ 会炸；1−ξ ∈ (0,1] 永远取不到 0
撞哪个核素按什么抽？按宏观截面 Σj = Njσj。热中子在水 + 15 ppm 硼里，按 N 抽 B 只占 0.0009%，按 Σ 抽是 0.23%，差 250 倍
隐式俘获为什么无偏？轮盘赌呢？每次碰撞的期望存活权重都是 wt·Σs/Σt，和模拟模式一样；轮盘赌活下来的期望权重 = (wt/0.2)×0.2 = wt。目的是减小方差、不浪费时间
径迹长度估计器和碰撞估计器差在哪？期望一样。径迹长度「飞过就记」，碰撞「撞了才记」。薄层、深处很少撞，径迹长度的误差棒小得多。M2 起 DH 改用径迹长度 × MT=301，碰撞那份留作对照
为什么要自由气体？热中子能量和靶核热运动（kT ≈ 0.025 eV）同量级，靶核不能当静止的，否则没有上散射、热谱会错。代价是只有自由原子、没有化学束缚（缺 S(α,β)，M3 补）
为什么每样都记 sum 和平方和？每条历史是一个独立样本：均值 = Σx/N，单条方差 σ12 = Σx2/N − x̄2（乘 N/(N−1)），SE = √(σ12/N)
截面低于表下限怎么办？按 1/v 外推：σ(E) = σ(E[0])·√(E[0]/E)。吸收截面低能区本来就是 1/v
为什么拆成小函数？M2–M5 要加 kerma、S(α,β)、光子、三维，都改在历史循环里；拆开以后改哪一块一目了然（kerma → lookup_xs/fly，S(α,β) → collide，三维 → fly），以后上 GPU 时 fly / collide 也正好对应两个核函数
