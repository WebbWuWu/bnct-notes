## 第 2 段 · `load_kT(nuc, T)`：从库里读 kT

### 2.1 kT 是什么、为什么从库里读

- **k** = 玻尔兹曼常数 = 8.617333262e-5 eV/K；**T** = 温度（K）。**kT** = 那个温度下热运动的「能量尺度」，单位 eV。
- 自由气体模型里，靶核速度的分布由 kT 决定（第 7 课讲义 §4）。kT 错了，抽出来的靶核速度整体偏快或偏慢，热区通量形状就跟着错。
- **为什么不直接拿 k × 294 算**：库是按 **293.6 K** 做的，标签「294K」是四舍五入后的名字。
  一步一步：
  ```
  按标签算：8.617333262e-5 × 294   = 0.025335 eV
  库里存的：                         0.025301 eV   ← 9/30 你读出来的
  相对差：  0.025301 / 0.025335 − 1 = −0.13%
  ```
  9/30 第 3 问你选的是「从库里读」—— 这样和 OpenMC 用的是**同一个数**（OpenMC 也读这一项），第 9 课对拍时这一格自动对齐。

### 2.2 逐行

和 `load_nuclide` 开头三行一模一样：`"H1"` → `E:\BNCT_GPU\lib80x_hdf5\H1.h5`，文件不在就停，消息里带完整路径。

- `"r"` = 只读。（🔴 你 10/10 混过：`"w"` 会清空文件 —— 对 `.h5` 也一样，`"w"` 会把 15 GB 库里这个核素整个抹掉。）
- `root = f[nuc]`：文件里最外层的组叫核素名，`f["H1"]`。

```python

```
这一行拆开看，从左往右一层一层往里走：

| 片段 | 拿到的是什么 |
|---|---|
| `root["kTs"]` | 组 `kTs`（注意有 **s**；你混过：字典键 `"kT"` vs HDF5 组名 `"kTs"`） |
| `[T]` | 组里名叫 `"294K"` 的那个**数据集**（dataset）。它只装一个数 |
| `[()]` | 🆕 把数据集里的值**读出来**。`[:]` 是读一整列（数组），`[()]` 是读一个「标量」（只有一个数、没有形状的数据集）。不写这个，拿到的是数据集**对象**，不是数 —— 9/30 第一稿缺的就是 `[T][()]` |
| `float(…)` | 转成 Python 的普通小数。h5py 读出来是 numpy 的 `float64`，转一下以后打印、存 json 都省事 |

```python
        T_label = float(T[:-1])
```
🆕 `T[:-1]`：字符串**切片**，「从头取到倒数第 1 个之前」，即去掉最后一个字符。`"294K"[:-1]` → `"294"`，再 `float` → `294.0`。

```python
        assert abs(kT / (8.617333262e-5 * T_label) - 1.0) < 5e-3, \
            "kT=%r eV 与温度标签 %s 对不上：按标签应约为 %.6f eV，差超过 0.5%%" % (kT, T, 8.617333262e-5 * T_label)
```
**这条抓什么**：读错了温度那一项（比如读成 600K）或者单位不对。
**两条独立的路**：库里存的 kT vs 玻尔兹曼常数 × 标签温度。
**容差 0.5% 的来历**：标签按整数 K 取整，最多差 0.5 K；最低温度 250 K → 0.5/250 = 0.2%，留一倍余量取 0.5%。294K 实际差 0.13%，过。
**改坏会不会响**（9/30 你亲手试过）：组名还写 `"294K"` 标签、却读了 `"600K"` 那一项 → 读出 0.051704 → 0.051704 / 0.025335 − 1 = **+104%**，响。

三个记号：
- 行尾的 `\`：🆕 **续行符**，「这一行没完，下一行接着」。assert 太长时折成两行用。`\` 后面不能再有任何字符（连空格都不行）。
- `%r`：按 Python 的「原样」打印（字符串带引号、小数给全位数），查错时比 `%s` 信息多。
- `%%`：格式串里想印出一个真的 `%` 号要写两个，否则 Python 以为后面跟着一个格式码。

```python
        return kT
```
`return` 在 `with` **里面**也可以：函数返回时 `with` 会自动把文件关上。

## 第 3 段 · `sigma_at_ext(E, XS, e)`：查截面，低于表下限按 1/v 外推

### 3.1 为什么需要它

库的能量网格从 **1e-5 eV** 开始。自由气体会**上散射也会下散射**：中子撞上一个朝它迎面跑来的 H 核，可能被撞得比 1e-5 eV 还慢。9/30 容器实测：10 万条历史里约 23 条会掉到表下限以下。原来的 `sigma_at` → `find_cell` 遇到 e < E[0] 会被它的 assert 停下（9/30 第 4 问你原选「杀掉」，当场纠正成外推）。

### 3.2 公式的来历：1/v 律

- 中子速度 v ∝ √E（动能 E = ½mv²）。
- 能量远低于 kT 时，中子几乎是「站着不动」，碰撞快慢由**靶核的热运动**决定：单位时间内撞上的次数和中子自己的 v 无关，是个常数。
- 截面 σ = 单位时间碰撞数 ÷ (中子密度 × v)。分子是常数 → **σ ∝ 1/v ∝ 1/√E**。
  （吸收道本来就是 1/v；294K 表里的**弹性**道在 E ≪ kT 时也是 1/v —— 这就是展宽的效果，所以**所有道**一起外推。判据 4 的改坏里「只外推 total」会响，就是这个原因。）
- 于是从表下限 E₀ = E[0] 往下：
  ```
  σ(e) = σ(E₀) × sqrt(E₀ / e)
  ```

**算例**（第 6 课那个假库：`E = [1e-5, 2e7]`，两道各 0.8、0.2 barn，处处为常数），查 e = 3.1e-6 eV：
```
E₀ / e           = 1e-5 / 3.1e-6          = 3.2258
sqrt(E₀ / e)     = sqrt(3.2258)           = 1.79605
道 0：0.8 × 1.79605                         = 1.43684
道 1：0.2 × 1.79605                         = 0.35921
总：  1.0 × 1.79605                         = 1.79605   （= 1.43684 + 0.35921 ✓）
```
（9/30 你订正时手算的 `[1.44, 0.36]`、1.8 就是这一行。）

### 3.3 逐行

```python
def sigma_at_ext(E, XS, e):
    assert e > 0.0 and math.isfinite(e), "要查的能量 e=%r 不是正的有限数（上游算错了），不能外推" % (e,)
```
**这条抓什么**：上游把能量算成了负数、`nan` 或 `inf`，却被这里当成「很低的能量」往下外推。
- 🆕 `math.isfinite(e)`：`e` 是普通的数就 True；是 `nan`（不是数）或 `inf`（无穷大）就 False。
- 不加的后果：负数 → 下面 `math.sqrt` 报 `math domain error`，报错位置离真正的错很远；`nan` → 外推出 `nan` 截面，一路传到 `run_slab` 那条「Sigma_t 为零」，消息说的是错的事。
- `% (e,)`：只有一个值也要写成「带逗号的括号」（元组）。万一 `e` 本身是个元组，不加逗号格式化会出错。

```python
    if e>=E[0]:
        sig,total=sigma_at(E,XS,e)
```
在表里（等于下限也算在表里）：直接用 `sigma_at`，和以前完全一样。**这一支保证了不外推的时候结果和第 6 课逐位相同。**

```python
    else:
        sig1,total1=sigma_at(E,XS,E[0])
```
低于表下限：先在**表下限 E[0]** 那一点查一次，拿到 σ(E₀)。
（`E[0]` 是方括号，9/30 第一稿写成了 `E(0)` —— 圆括号是「调用函数」，`E` 是数组不能调用，会报 `not callable`。）

```python
        sig=[0.0]*len(sig1)
```
先造一个和道数一样长、全是 0.0 的列表，下面一格一格填。
`[0.0] * 3` → `[0.0, 0.0, 0.0]`。（9/30 第一稿写的 `[]*len(…)`：空列表乘几都还是空列表 `[]`，下一行 `sig[i] = …` 就会越界。）

```python
        for i in range(len(sig1)):
            sig[i]=sig1[i]*math.sqrt(E[0]/e)
```
每个道都乘同一个外推因子 `sqrt(E₀/e)`。

```python
        total=total1*math.sqrt(E[0]/e)
```
总截面也乘同一个因子。**放在 `for` 外面**（9/30 第一稿放在循环里：结果碰巧一样，但每个道都白算一遍）。
等价写法是 `total = sum(sig)`；两种写法差最多最后一位（浮点加法顺序不同），你选的是「乘同一个因子」。

```python
    return sig,total
```
**两个分支都走到这里**，所以 `return` 和 `if` 对齐，不在 `else` 里面。返回值的形状和 `sigma_at` 完全一样（各道列表、总截面），`run_slab` 里把 `sigma_at` 换成 `sigma_at_ext`，别的一行都不用改 —— 这是 9/30 第 4 续问选「丙：包一层」的理由。
