## 1 背景与目标

### 1.1 BNCT 的剂量为什么难算

（10/27 压短：面试老师都懂原理，只留三句。）

BNCT 先让肿瘤细胞富集 ¹⁰B，再用超热中子照射；中子在组织里慢化成热中子后被 ¹⁰B 俘获，放出的 α 和 ⁷Li 合起来只走约 12–14 μm，和一个细胞直径相当。病人受到的是硼剂量、氢反冲剂量、氮剂量和 γ 剂量的混合，每一种都取决于中子在组织里怎么输运（热中子决定 D_B、D_N，快中子决定 D_H）。深度剂量曲线没有解析解，所以治疗计划靠**蒙特卡罗输运计算**。

### 1.2 为什么要自己写一个程序

通用蒙卡程序（MCNP、PHITS、OpenMC）精度高，但它们是为各种问题设计的，用在 BNCT 治疗计划上算得慢。COMPASS 的作者（Zhong 等，*Sci. Rep.* 2023）总结了这个领域的处境：

- **GPU + 多群截面**的方法很快，但多群近似带来的剂量误差约 4%，放疗上不能接受；
- **CPU + 连续能量**的专用程序（如 COMPASS）精度够，但仍要靠多核 CPU 并行才能提速。

**「GPU + 连续能量」兼顾速度和精度**，这是本项目最终要瞄准的方向。（⚠️ 国内已有工作在做 BNCT 剂量引擎加速，例如西安交大 NECP-MCX 的 BNCT 加速研究；这一段的对比要等读完那篇再定稿，见文末问题 3。）

在走到 GPU 之前，需要一个**每一步都清楚、每个近似都量过**的参考实现。GPU 版的每一个结果都要和它逐项对拍。本报告讲的就是这个参考实现。

### 1.4 本报告的范围与主要结果

本报告覆盖 M1 和 M2：一个用 Python 从零编写的连续能量蒙卡中子输运程序，几何是一维平板，截面用 ENDF/B-VIII.0 逐点数据（和 OpenMC 用同一份 HDF5 库），热化用自由气体模型，采用隐式俘获，用径迹长度估计记录通量和剂量。

2. **判据考虑了层间相关**。OpenMC 的 heating 30 层会一起涨落（层间相关系数平均 0.3–0.4），如果按「各层独立」去判，两个都对的程序也有约 1/4 的机会被误判为不一致。本工作把判据拆成「总量」和「形状」两条，门槛在看对拍数据之前就定死；每条判据都在故意写错的版本上试过，确认它会报错。
3. **两个主要近似量出了大小**：
   - 自由气体近似（不考虑水中氢的化学键）：D_B 峰值低估约 23%，深处高估约一倍（OpenMC 加 / 不加 S(α,β) 对比）；

   这两个近似分别是 M3 要修正的对象。

### 2.2 截面数据

- 截面库：ENDF/B-VIII.0（LANL 制作的 HDF5 版本，和 OpenMC 用的是**同一份文件**），294 K 的逐点（连续能量）截面。
- 查表：在能量格点之间**线性插值**；总截面 = 各个非冗余反应道之和（不单独插值总截面，保证两者自洽）。
- 能量低于表下限（1e-5 eV）时按 1/v 外推。
- 只保留源能量范围内可能发生的反应道（阈值高于源最高能量 2 倍的道去掉）。

### 2.3 中子输运

每个中子从源抽出能量后，重复「飞一段 → 撞一下」，直到漏出平板或被轮盘赌终止：

1. **飞行距离**：s = −ln(1 − ξ) / Σ_t(E)，ξ 是 [0, 1) 均匀随机数。中子飞行中能量不变，所以一段飞行只查一次截面。
2. **按层拆开**：一段飞行可能斜着穿过好几层，每一层里的路程 = 竖直距离 ÷ |w|（w 是方向余弦），分别记账。
3. **碰撞**：
   - **隐式俘获**：碰撞时不做「吸收还是散射」的抽样，而是让权重乘以存活份额 Σ_s / Σ_t，被吸收的那部分从权重里扣掉。这样每条历史都能走完，热中子区的统计更好。权重低于 0.1 时做俄罗斯轮盘赌：以 wt / 0.2 的概率存活，权重提到 0.2，否则终止（期望权重不变，所以结果无偏）。
   - **选核素**：按各核素弹性宏观截面的份额抽。
   - **热化（自由气体模型）**：靶核不是静止的，而是按麦克斯韦分布热运动。先按「麦克斯韦分布 × 相对速度」抽出靶核的速率和方向（迎面运动的靶核更容易被撞上），再在质心系里各向同性散射，最后变换回实验室系，得到新的能量和方向。这一步让热中子能从靶核那里**得到**能量，最终和介质达到热平衡。

     靶核速度的抽样分布（10/27 定加；面试要能当场推）：

     p(V, μ_T) ∝ v_rel · V² · exp(−β²V²)，  v_rel = √(v² + V² − 2vVμ_T)，  β² = A·m_n / (2kT)

     其中 v 是中子速率，V 是靶核速率，μ_T 是**靶核运动方向和中子入射方向夹角的余弦**（不是散射角），A 是靶核与中子的质量比（`awr`）。V² exp(−β²V²) 是麦克斯韦速率分布；乘 v_rel 是因为单位时间内撞上的概率正比于相对速率（截面在热能区按 σ ≈ 常数处理）。⚠️ 推导和抽样步骤待你过一遍再定稿（第 7 课讲义 + fgk 精简版）。

### 2.4 打分与统计

- **径迹长度估计**：一段路程 ℓ 在某一层里，往这一层的计数加上 wt × ℓ × 系数。系数取 1 得到通量；取 Σ_反应 得到反应率（如 H(n,γ)、¹⁰B(n,α)）；取 Σᵢ Nᵢ·Hᵢ(E) 得到 kerma（M2）。
- **kerma**：Hᵢ(E) 是库里第 i 个核素的加热数（MT=301，单位 eV·b），它已经包含该核素所有反应道放出的带电粒子动能（弹性反冲、(n,α)、(n,γ) 的反冲核等），**不包含光子带走的能量**。带电粒子在组织中的射程 ≤ mm，远小于 0.5 cm 的层厚，所以 kerma ≈ 吸收剂量（带电粒子平衡）。M2 按核素分别记 H、O、B 三份 kerma。
- **碰撞估计**（M1 的 D_H）：每次和 H 碰撞，记 wt × (碰前能量 − 碰后能量)。和径迹长度估计是同一个物理量的两种估计法，期望值相同、涨落不同。
- **统计**：每条历史结束时，把这条历史在每一层的贡献 x 累加到 Σx 和 Σx²（**一条历史内先加、后平方**，这样同一条历史多次穿过同一层时的关联被正确计入）。均值 = Σx / N，标准误 SE = √(样本方差 / N)。
