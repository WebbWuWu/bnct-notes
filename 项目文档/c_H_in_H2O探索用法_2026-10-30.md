### 1.2 新的

**(a) `数据集.shape`、`数据集.dtype`：不读数据，只看「多大、什么类型」**

```python
# 和项目无关的例子：一张 3 行 4 列的成绩表
import numpy as np
scores = np.zeros((3, 4))
print(scores.shape)   # (3, 4)
print(scores.dtype)   # float64
```
h5py 的数据集也有这两个属性，**而且不会把数据读进内存** —— 629 MB 的文件只能这样看。对比：`[()]`、`[:]` 会真的读。

**(b) `.attrs.items()`：一次拿到所有属性的「名字, 值」**

```python
# 和项目无关：字典也有 .items()
price = {"apple": 3.5, "pear": 4.0}
for name, value in price.items():
    print(name, value)
```
`组.attrs.items()` 用法一样。你不知道属性叫什么名字时用它；知道名字就直接 `.attrs["名字"]`。⚠️ 10/25 的错：`for` 接的变量个数要等于每一项的长度（这里是 2 个）。

**(c) 字节串 `b'...'` 和 `.decode()`**

h5py 读出来的字符串属性常常是**字节串**，打印出来带个 `b`：`b'H1'`。它和 `'H1'` **不相等**。
```python
city = b'Nanjing'
print(city == 'Nanjing')            # False
print(city.decode() == 'Nanjing')   # True
```
有时还是一个装着字节串的 numpy 数组（打印成 `[b'H1']`），那就先取 `[0]` 再 `.decode()`。今天只是打印，不用转；以后拿它做比较时才要转。

**(d) `组.visititems(函数)`：把组下面**每一层**的东西都走一遍**

你自己写一个**带两个参数**的函数：第一个参数是**路径名**（字符串，比如 `"inelastic/xs"`），第二个是**那个对象本身**（组或数据集）。h5py 会对组里的每一个东西（包括更深层的）各调用它一次。
```python
# 和项目无关的同一种思路：把「怎么处理一个」写成函数，交给别人去对每一个调用
def show(name, size):
    print(name, size)

files = [("photo.jpg", 2048), ("notes.txt", 12)]
for n, s in files:
    show(n, s)          # 这里是你自己调用；visititems 是 h5py 替你调用
```
🔴 传进去的是**函数名本身**，不加括号：`组.visititems(show)`。写成 `show()` 就变成「先调用一次、把返回值传进去」，会报缺参数。

**(e) `isinstance(对象, h5py.Dataset)`：判断它是不是数据集**

```python
print(isinstance(3.0, float))   # True
print(isinstance("3", float))   # False
```
在 (d) 的函数里用：是数据集就打印 `shape`、`dtype`；不是（那就是组）就只打印名字。

**(f) `np.interp(x, xp, fp)`：在表上线性插值**

```python
# 和项目无关：一天里 6 点 12°C、12 点 20°C，9 点大约几度？
import numpy as np
print(np.interp(9, [6, 12], [12, 20]))   # 16.0
```
`xp` 必须从小到大。你自己写过 `interp`（第 5 课），这是 numpy 现成的线性版。今天只用它估「0.0253 eV 时截面多少」，不进程序本体。
