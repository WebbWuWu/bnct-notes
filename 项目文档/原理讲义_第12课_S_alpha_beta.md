## 0. 一句话原理

热中子（约 0.025 eV）的能量和水分子转动、振动的能量差不多大，所以它撞到的不是一个孤立的 H 原子，而是**整个绑在分子里的 H**：会交换转动、振动能，截面也比自由 H 大。S(α,β)（散射律）就是把「这个分子能吸收 / 给出多少能量和动量」做成一张表。

## 1. 为什么自由气体模型在水里不够

### 1.1 先比能量：热中子 vs 水分子的「台阶」

| 水分子里的运动 | 典型能量 | 和 kT = 0.0253 eV 比 |
|---|---|---|
| 整个分子平动、扩散 | 几 meV | 小 |
| 受阻转动（摆动，librations） | 约 0.05 – 0.1 eV | **同一量级** |
| 弯曲振动 | 0.205 eV | 约 8 倍 |
| 伸缩振动 | 约 0.45 eV | 约 18 倍 |

**意思**：自由气体模型（第 7 课）把 H 当成一团各自乱跑、互不相连的原子，靶核只有「平动」。真实水里，热中子一撞，能把分子「踢」得转起来（丢掉约 0.06 eV），也可能从已经在转的分子那里**拿回**能量（上散射）。振动台阶 0.2 eV、0.45 eV 比热中子能量高，热中子激发不了，但 eV 量级的中子会去激发它们 —— 所以慢化的最后一段（约 1 eV 以下）和自由气体不一样。

### 1.2 再比长度：中子波长 vs 分子尺寸

中子波长 λ = 0.286 / √E（λ 单位 Å，E 单位 eV）。0.0253 eV：λ = 0.286 / 0.159 = **1.80 Å**。
水里 O–H 键长 0.96 Å，分子之间约 2.8 Å —— **一样大**。中子「看」到的不是一个点，而是一片绑在一起的原子。

### 1.3 束缚原子截面：为什么是自由的 4 倍

把核「钉死」（无限重的晶格里），和中子相撞的有效质量从约化质量变成中子质量本身。散射截面按约化质量的平方变化：

σ_束缚 = σ_自由 × ((A + 1) / A)²

H：A = 0.99917 → ((1.99917)/0.99917)² = 4.00 → σ_束缚 = 20.44 × 4.00 = **81.8 b**。
O-16：((16.86)/15.86)² = 1.13 → 只多 13%。所以**只有 H 的化学键要紧**，O 照用自由气体（这也是为什么库里只有 `c_H_in_H2O`，没有 `c_O_in_H2O`）。

真实水里的 H 介于「自由」（20.4 b）和「钉死」（81.8 b）之间，而且和能量有关：
- 能量 ≫ 0.5 eV：中子太快，分子来不及反应 → 回到自由原子 20.4 b
- 热能附近：每个 H **51.69 b**（0.0253 eV，294K；✅ 10/31 实测，原写约 49 b）；1 eV 21.50 b、10 eV 20.54 b（✅ 10/31 实测，已接近自由的 20.4 b）
- 对比你的程序（自由气体，294 K）：0.0253 eV 处 H 约 30 b（README 第 5 课：自由原子 20.44 b 判 294 K 数据差 48%）

**→ 热区 H 的散射截面，S(α,β) 比你的自由气体大约 70%（51.69 / 30.4 = 1.70；原写约 60%）。** 这一条就够解释第 9 课判据 5 的方向：散射截面大 → 热中子扩散得慢、走不远 → 热中子更集中在峰附近 → D_B **峰更高、深处更低**（第 9 课判据 5 实测，以 S(α,β) 为基准：自由气体峰值低 23%、深处高约一倍）。

### 1.4 算一笔：一个热中子在水里扩散多远

热中子扩散长度 L 是热中子从「变成热中子」到「被吸收」平均走开的直线距离量级。
L² = D / Σ_a，D = 1 / (3 Σ_tr)，Σ_tr ≈ Σ_s (1 − μ̄)。散射截面大 70% → D 变成原来的 1/1.7（μ̄ 也会变，先不管）→ L 变成原来的 1/√1.7 ≈ 0.77 倍，短约 23%。
水的热中子扩散长度实测约 **2.7 cm**（⚠️ 教材值，反应堆物理课本里有）；用自由气体算会偏大。B10 剂量 ∝ 热通量，深处那部分正是靠「扩散得远」过去的，所以深处对 L 最敏感。

## 2. S(α,β) 是什么

### 2.1 两个无量纲量

一次散射：中子从能量 E、方向 Ω 变成 E′、Ω′，散射角余弦 μ = Ω·Ω′（**实验室系**；热散射全在实验室系里算，不用质心系）。

| 记号 | 定义 | 物理意思 |
|---|---|---|
| **β** | (E′ − E) / kT | **能量转移**，以 kT 为单位。β > 0：中子从分子那里**拿到**能量（上散射）；β < 0：中子把能量交给分子 |
| **α** | (E′ + E − 2μ√(E E′)) / (A·kT) | **动量转移的平方**，以 A·kT 为单位（A = 0.99917，H 对中子的质量比） |

α 的来历：中子动量变化 Δp = p′ − p，|Δp|² = p² + p′² − 2pp′μ；p² = 2mE，代进去再除以 2m·A·kT 就是 α。

### 2.2 双微分截面

散射到 (E′, μ) 附近的截面（单位：b / eV / 单位 μ）：

σ(E → E′, μ) = σ_b / (2kT) × √(E′/E) × e^(−β/2) × **S(α, β)**

- σ_b：束缚原子截面（H 是 81.8 b，§1.3）
- √(E′/E)：出射中子跑得快，单位时间离开得多（相空间因子）
- e^(−β/2)：把「细致平衡」单独提出来。热平衡时，从低能往高能跳（β > 0）要比反过来少 e^(−β) 倍 —— 不然水的温度就不平衡了。提出来以后，**表里存的 S(α,β) 对 β 是偶函数**，只存 β ≥ 0 那一半
- **S(α,β)：散射律**，只和物质（水分子怎么动）有关，**和中子能量无关**。这就是它好用的地方：一张二维表，管所有入射能量

### 2.3 一个算例（用自由气体的 S，先看懂量级）

自由气体也有 S(α,β)，是一个闭式：S_自由(α,β) = (4πα)^(−1/2) × exp(−(α² + β²)/(4α))。
真实水的 S 就是把这条「光滑的鼓包」换成在转动、振动能处有台阶和峰的一张表。

取 E = 0.0253 eV → E′ = 0.0400 eV（上散射），μ = 0.3，kT = 0.02533 eV：

| 步 | 算 | 结果 |
|---|---|---|
| β | (0.0400 − 0.0253) / 0.02533 | **0.580** |
| α | (0.0400 + 0.0253 − 2 × 0.3 × √(0.0253 × 0.0400)) / (0.99917 × 0.02533) = (0.0653 − 0.01909) / 0.02531 | **1.826** |
| S_自由 | (4π × 1.826)^(−1/2) × exp(−(1.826² + 0.580²)/(4 × 1.826)) = 0.2088 × e^(−0.502) | **0.126** |
| 双微分截面 | 81.8 / (2 × 0.02533) × √(0.0400/0.0253) × e^(−0.290) × 0.126 | **约 192 b/(eV·单位μ)** |

这个数本身不用记。要记的是**链条**：(E, E′, μ) → 算 α、β → 查 S → 乘前面三个因子。

### 2.4 自由气体是 S(α,β) 的一个特例

第 7 课的自由气体模型 ⇔ S 取上面那个闭式。所以 M3 不是「推翻」第 7 课，而是**把 H 的那张 S 从闭式换成测出来 / 算出来的表**。O-16、B10 照旧用自由气体。

## 5. 怎么抽样：给定入射能量 E，抽出 (E′, μ)（🆕 10/31 晚 Claude 写）

> 依据两样：① 10/31 你的探索脚本实测的存法；② OpenMC 0.15.3 源码 `src/secondary_thermal.cpp` 第 247–332 行 `IncoherentInelasticAE::sample`（Claude 10/31 从 GitHub 拉的 v0.15.3 原文）。M3 对拍的对象就是 OpenMC，所以**照它的做法抽**，两边才在比同一件事（纪律 2）。
> 这一节只讲「每一步做什么、为什么」，**不是代码**；怎么写进你的程序，框架第二轮一起定。

### 5.0 记号表

| 记号 | 意思 | 你探索脚本里叫什么 |
|---|---|---|
| E | 中子这次碰撞的入射能量（eV） | — |
| E_i | 库里第 i 个入射能量格点（118 个，1e-5 ~ 10 eV） | `E_in[i]` |
| l | 这次实际用的那张出射能量表的表号 | `j0` / `j` |
| E′_j、p_j、c_j | 第 l 张表里第 j 个出射点的能量、pdf、cdf | `Eo[j]`、`po[j]`、`co[j]` |
| μ_{j,k} | 第 j 个出射点那张 μ 表里的第 k 个余弦（k = 0…19，等概率） | `mu_val[k]` |
| ξ₁、ξ₂、ξ₃ | 这次碰撞用的三个随机数，各自在 [0, 1) 均匀 | `rng.random()` 三次 |

10/31 实测要点（§5 全靠它们）：出射能量表 lin-lin（`interpolation` 全 2）；μ 表每个出射点 **20 个等概率离散值**（pdf 全 0.05，`energy_out` 第 3 行全 0）；第 4 行 = 该点 μ 表在 `mu` 数组里的起点（= 全局出射点序号 × 20）。

### 5.1 整体流程（一次 H1 热散射碰撞）

1. **选表**：E 落在 E_i 和 E_{i+1} 之间 → 选**离得近的那一张**（不在两张表之间插值）
2. **抽 E′**：用 ξ₁ 在这张表的 cdf 里找区间 j，再在区间里解一个二次方程
3. **修正 E′**：E 和选中的表的能量 E_l 不完全相等，把 E′ 挪一下
4. **抽 μ**：用 ξ₂ 等概率挑 k，在出射点 j、j+1 两张 μ 表之间插值，再用 ξ₃ 「抹开」
5. **转方向**：μ 是新旧方向夹角的余弦（实验室系），配一个均匀的方位角 φ，用旋转公式得新方向

和你现在的 `free_gas_kinematics` 比：那边是「抽靶核速度 → 变到质心系 → 散射 → 变回来」，E′ 和 μ 是**算出来**的；这边 E′ 和 μ 直接**从表里抽**，不再有靶核速度、质心系。

### 5.2 第 1 步：选表 —— 取近的那张

OpenMC：先算插值因子

  f = (E − E_i) / (E_{i+1} − E_i)

f > 0.5 就用第 i+1 张，否则用第 i 张（源码第 256 行）。

**算例**：E = 0.0265 eV。格点里 E_48 = 0.0253、E_49 = 0.0280（你 10/31 打印的）→ f = (0.0265 − 0.0253) / (0.0280 − 0.0253) = 0.0012 / 0.0027 = **0.444** < 0.5 → 用**第 48 张**（E_l = 0.0253）。

为什么不插值：两张表点数不同（第 48 张 613 点、第 49 张 576 点），出射能量格点也不对齐，没法逐点插。代价是 E 和 E_l 有一点差 → 第 3 步补。

### 5.3 第 2 步：抽 E′ —— 分段线性 pdf 的反函数

**① 找区间**：从 j = 0 往后找，找到第一个满足 ξ₁ < c_{j+1} 的 j，于是 c_j ≤ ξ₁ < c_{j+1}。j 最大取到「点数 − 2」（最后一个区间）。

**② 区间里解方程**。lin-lin 的意思是：在 [E′_j, E′_{j+1}] 里 pdf 是一条直线

  p(E′) = p_j + s · (E′ − E′_j)，斜率 s = (p_{j+1} − p_j) / (E′_{j+1} − E′_j)

cdf 是 pdf 的积分，从 E′_j 积到 E′（记 d = E′ − E′_j）：

  c(E′) = c_j + p_j · d + (s/2) · d²

令 c(E′) = ξ₁，这是 d 的一元二次方程 (s/2)d² + p_j d − (ξ₁ − c_j) = 0，取正根：

  **d = ( √(p_j² + 2 s (ξ₁ − c_j)) − p_j ) / s**，E′ = E′_j + d

s = 0（pdf 在这段是平的）时退化成 d = (ξ₁ − c_j) / p_j（源码第 285–292 行，两种情况都有）。

**算例**（⚠️ 示意数，不是第 48 张表的真值，挑的是这个量级上不特殊的数）：E′_j = 0.0240、E′_{j+1} = 0.0250 eV，p_j = 9.2、p_{j+1} = 9.6 /eV，c_j = 0.4180，ξ₁ = 0.4225。

| 一步一步 | 数 |
|---|---|
| 先核区间对不对：c_{j+1} = c_j + (p_j + p_{j+1})/2 × 0.0010 | 0.4180 + 9.4 × 0.0010 = 0.4274 > 0.4225 ✅ 落在这段 |
| s = (9.6 − 9.2) / 0.0010 | 400 /eV² |
| ξ₁ − c_j | 0.0045 |
| p_j² + 2 s (ξ₁ − c_j) | 84.64 + 3.60 = 88.24 |
| √ − p_j | 9.39361 − 9.2 = 0.19361 |
| d = 上一行 / s | 4.840e-4 eV |
| **E′** | **0.024484 eV** |
| 回代核：p_j d + (s/2) d² | 0.0044528 + 0.0000469 = 0.0044997 ≈ 0.0045 ✅ |

**两个边角**：
- 10/31 实测 cdf 第一个数是 1.2e-6 不是 0：ξ₁ < c_0 的概率 1.2e-6，这时 j = 0、ξ₁ − c_j 是个很小的负数 → 根号里可能 < 0。OpenMC 在根号里套了「和 0 取大」（第 289 行 `max(0.0, …)`），结果 E′ ≈ E′_0。你照做就行，不必特殊处理。
- cdf 末尾 = 1（实测）→ ξ₁ < 1 一定能找到区间。

### 5.4 第 3 步：修正 E′ —— E 不等于 E_l 时挪一下

表是在 E_l 上做的，中子的真实能量是 E。OpenMC（源码第 295–300 行）：

- E′ < E_l / 2：**按比例缩放** E′ ← E′ × (2E / E_l − 1)
- E′ ≥ E_l / 2：**平移** E′ ← E′ + (E − E_l)

两段在 E′ = E_l / 2 处接得上：缩放给 (E_l/2)(2E/E_l − 1) = E − E_l/2，平移给 E_l/2 + E − E_l = E − E_l/2，同一个数。低能段用缩放是为了 E′ 不会被平移成负数。

**算例**（接 5.2：E = 0.0265、E_l = 0.0253）：系数 2 × 0.0265 / 0.0253 − 1 = 1.0949；E_l / 2 = 0.01265。
- 抽到 E′ = 0.0080（< 0.01265）→ 0.0080 × 1.0949 = **0.008759 eV**
- 抽到 E′ = 0.0300（≥ 0.01265）→ 0.0300 + 0.0012 = **0.0312 eV**

⚠️ 这是 OpenMC 的工程做法，不是从 S(α,β) 推出来的 → **近似候选 #29**（编号进近似表时你定）。格点在热区很密（0.0253 → 0.0280 只差 11%），影响应该很小。

### 5.5 第 4 步：抽 μ —— 等概率挑一个，插值，再抹开

**① 挑 k**：k = ⌊ξ₂ × 20⌋（向下取整），k ∈ {0, …, 19} 等概率（第 303–304 行）。

**② 在出射点 j 和 j+1 之间插 μ**（第 310–313 行）：插值因子用的**不是能量**，是 ξ₁ 在 cdf 区间里的位置

  g = (ξ₁ − c_j) / (c_{j+1} − c_j)，μ = μ_{j,k} + g · (μ_{j+1,k} − μ_{j,k})

（ξ₁ 第 2 步已经用过，这里**再用一次**，不另抽。）

**③ 抹开**（第 306–331 行）：只用 20 个离散值，μ 就只能取 20 个数，角分布是一根根「梳子齿」。OpenMC 把它在两边邻居之间均匀撒开：
- 左邻 μ_左 = 第 k−1 个（同样按 g 插值）；k = 0 时没有左邻，取 μ_左 = −1 − (μ + 1)（关于 −1 的镜像）
- 右邻 μ_右 = 第 k+1 个；k = 19 时取 μ_右 = 1 + (1 − μ)（关于 +1 的镜像）
- 半宽 h = min(μ − μ_左, μ_右 − μ) / 2，μ ← μ + 2h × (ξ₃ − 0.5)，也就是在 [μ − h, μ + h] 里均匀

镜像保证抹完不出 [−1, 1]：k = 0 时 μ − μ_左 = 2(μ + 1)，h ≤ μ + 1 → μ − h ≥ −1。

**算例**（用你 10/31 打印的第 48 张表第 300 个出射点那张 μ 表；为了先看懂，设 g = 0，即不插）：ξ₂ = 0.17 → k = ⌊3.4⌋ = 3 → μ = −0.2266782；左邻 μ_2 = −0.3944622、右邻 μ_4 = −0.0857239。

| 一步一步 | 数 |
|---|---|
| μ − μ_左 | 0.167784 |
| μ_右 − μ | 0.140954 |
| 取小的 → 2h | 0.140954 |
| 抹开的范围 [μ − h, μ + h] | [−0.29716, −0.15620] |
| ξ₃ = 0.73 → μ + 0.140954 × 0.23 | **μ = −0.194259** |

### 5.6 第 5 步：转方向 —— 教科书旋转公式

μ 只给了「新方向和旧方向夹角的余弦」，绕旧方向转多少还没定 → 方位角 φ = 2π ξ₄（第四个随机数），均匀。旧方向 (u, v, w)（单位向量），记

  a = √(1 − μ²)，b = √(1 − w²)

**一般情况**（b > 1e-10）：

  u′ = μ u + a (u w cos φ − v sin φ) / b
  v′ = μ v + a (v w cos φ + u sin φ) / b
  w′ = μ w − a b cos φ

**来历**：新方向 = μ × 旧方向 + a × （一个和旧方向垂直的单位向量）。和 (u, v, w) 垂直的平面里取两根互相垂直的单位向量：e₁ = (u w, v w, −(1 − w²)) / b、e₂ = (−v, u, 0) / b，垂直分量 = cos φ · e₁ + sin φ · e₂。逐分量写出来就是上面三行。

**特殊情况**（b ≤ 1e-10，旧方向几乎就是 ±z）：上面除以 b 会爆。OpenMC（`src/math_functions.cpp` 第 763–792 行 `rotate_angle`）这时改成**绕 v 展开**（公式里 v 和 w 的角色对调，b 换成 √(1 − v²)）。

**算例**：旧方向 (0.36, 0.48, 0.80)（0.1296 + 0.2304 + 0.64 = 1 ✅），μ = −0.194259（接 5.5），φ = 2.1 rad（cos φ = −0.50485，sin φ = 0.86321）。

| 一步一步 | 数 |
|---|---|
| a = √(1 − μ²) | 0.98095 |
| b = √(1 − w²) | 0.60000 |
| u′ = −0.194259 × 0.36 + 0.98095 × (0.36 × 0.80 × (−0.50485) − 0.48 × 0.86321) / 0.6 | **−0.98506** |
| v′ = −0.194259 × 0.48 + 0.98095 × (0.48 × 0.80 × (−0.50485) + 0.36 × 0.86321) / 0.6 | **0.09787** |
| w′ = −0.194259 × 0.80 − 0.98095 × 0.6 × (−0.50485) | **0.14173** |
| 核 1：u′² + v′² + w′² | 1.0000 ✅ 还是单位向量 |
| 核 2：u u′ + v v′ + w w′ | −0.19426 = μ ✅ 夹角对 |

这两条「核」就是判据的好材料（都是独立于抽样的几何恒等式）—— 框架第二轮讨论判据时再定用不用。

### 5.7 一次碰撞用几个随机数

ξ₁（E′，μ 插值复用）、ξ₂（挑 k）、ξ₃（抹开）、ξ₄（φ）= **4 个**。和自由气体那一支比是少还是多，你写完对一下；随机数判据 R4（一条历史最多约 1150 个数、步长 152917）离上限很远，不用担心。
