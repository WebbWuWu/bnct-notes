**先看记号**

| 记号 | 意思 |
|---|---|
| safety distance（安全距离） | 粒子到所在四面体**任意一个面**的最短距离（不管往哪个方向飞）。走的步长比它短，就一定不会出这个四面体 |
| geometric step length（几何步长） | 沿**当前飞行方向**，粒子到四面体表面的距离 |
| physical step length（物理步长） | 按材料的平均自由程抽出来的「下一次碰撞前飞多远」 |
| secondary particle stack（次级粒子栈） | 一次相互作用产生的新粒子先存起来，主粒子走完再一个个拿出来跑；后放的先拿（LIFO） |
| kernel function（核函数） | CUDA 里在 GPU 上并行执行的函数；每个线程跑一份 |
| coherent scattering（相干散射） | 也叫瑞利散射：光子被整个原子弹开，**不丢能量**，只改方向 |
| condensed history（压缩历程） | 电子一路要撞几千上万次，不一次次模拟，而是把一小段路上的许多次小角度散射合成一步抽 |
