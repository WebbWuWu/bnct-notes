## 二、用到的写法（逐个，例子和项目无关）

### 1. 二维 numpy 数组取一个数：`a[行, 列]`
`mu_tab` 是一个二维数组：**行 = 第几个出射点 j，列 = 第几个 μ（k）**。
```python
seats = np.array([[11.5, 12.0, 12.5],
                  [21.5, 22.0, 22.5]])
seats.shape        # (2, 3)  → 2 行 3 列
seats[1, 2]        # 22.5    → 第 1 行第 2 列
seats[1][2]        # 22.5    → 也行，但先取出一整行再取，慢一点
seats[2, 1]        # IndexError —— 行列写反了，这次碰巧报错；方阵就不报错（静默）
```
你犯过：`XS[道][格点]` 行列反（10/10 两次）；列表套列表少一层下标（`sig_ds[pl]` vs `sig_ds[j][pl]`）。
**今天的口诀**：先 j（哪个出射点）后 k（第几个 μ）。

### 2. 负数下标：`a[-1]` 是**最后一个**，不报错
```python
temps = np.array([3.1, 4.7, 5.2, 6.8])
temps[-1]       # 6.8   → 最后一个
i = 0
temps[i - 1]    # 6.8   ← i = 0 时 i − 1 = −1，拿到的是最后一个！静默错
temps[3 + 1]    # IndexError —— 越过右边会报错（响）
```
**这就是讲义里 k = 0、k = 19 要单独处理的原因**：k = 0 时「第 k − 1 个」在 Python 里会悄悄拿到第 19 个（最右边那个 μ，接近 +1），抹开宽度一下子变成接近 2，没有任何报错。k = 19 时「第 k + 1 个」会报 IndexError。
你犯过：`[-1]`（最后一个）vs `[:-1]`（除了最后一个）（11/1）。

### 3. `int(x)`：正数向下取整
```python
int(0.83 * 6)    # 4      （4.98 → 4，不是四舍五入）
int(5.0)         # 5
int(-0.5)        # 0      （负数是向 0 截，不是向下 —— 今天 ξ₂ ≥ 0，碰不到）
```
k = ⌊ξ₂ × 20⌋，ξ₂ ∈ [0, 1) → k ∈ {0, …, 19}，正好 20 个等概率。**用文件头的常量 `N_MU`，别写死 20。**
你犯过：`int(数组)` vs `.astype(int)`（11/1 —— 今天是**一个数**，用 `int()` 对）；70/15 取整成 4（10/31，心算）。

### 4. 两个**互不相干**的判断 → 两组 `if … else`，不是一串 `if / elif`
左邻要不要镜像，只看「k 是不是第一个」；右邻要不要镜像，只看「k 是不是最后一个」。这是两个独立的问题。
```python
# 一张票：既要定「要不要早鸟折扣」，又要定「要不要学生折扣」—— 两件事各管各
if day < 10:
    early = 0.85
else:
    early = 1.0
if is_student:
    stud = 0.7
else:
    stud = 1.0
```
如果写成 `if 早鸟 … elif 学生 … else …`，早鸟的人就拿不到学生折扣了 —— 第一个条件成立，后面整串都跳过。
你犯过：`else` 挂错对象（10/14：第三个 `if` 抄成 `else`）。

### 5. `min(a, b)`
```python
min(0.167784, 0.140954)    # 0.140954
```
抹开的总宽 = 「离左邻多远」和「离右邻多远」**取小的**，这样抹开以后不会越过邻居的一半。

### 6. 同一个 `rng.random()` 的数用两次 → 先存变量（复习）
ξ₁ 11/2 已经存进 `xi1`：找 j、反解 d 用过；今天算 g **再用它**，不另抽。ξ₂、ξ₃ 各自是**新抽**的。
**抽的先后顺序要照框架**：ξ₁ → ξ₂ → ξ₃（→ ξ₄ 在 `rotate_dir` 外面抽 φ）。顺序换了，同种子跑出来就和对拍对不上。
你犯过：漏写 `rng.`；`rng`（发生器）vs `rng.random()`（一个数）。

### 7. 一个函数返回两个值：`return a, b`
```python
def split_bill(total, people):
    each = total / people
    left = total - each * people
    return each, left          # 实际返回的是一个元组 (each, left)

share, rest = split_bill(97.5, 4)    # 左边写两个名字，按顺序接 ✅
result = split_bill(97.5, 4)         # 接成一个元组：result[0]、result[1]
a, b, c = split_bill(97.5, 4)        # ValueError: not enough values to unpack
```
你犯过：`for` 接的变量个数 ≠ 元组长度（10/25）；接返回值和传参用了两个名字（`x` vs `x1`）。
⚠️ **改成返回两个值以后，旧的调用会坏**：`if __name__` 块里的 `check_T3E(…)`、`check_T3E_selftest(…)` 现在按「返回一个数」写的 → 今天写到最后一步时**先把这两行注释掉**，T3 完整版（我写，兼容两个返回值）第 2 项给你。
